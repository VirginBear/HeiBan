# 黑板：六個介面方向

這批是供討論的視覺概念，使用內建 image_gen 產生。功能是否可用仍以實際程式與驗收結果為準；圖中的作品、日期與帳號文案皆為示意。

**最新選擇（2026-10-08）：使用者選擇 03 筆記本，並要求左側欄可收合。** 請參照 [已選方向與收合規格](../2026-10-08/README.zh-TW.md)，下方「建議組合」保留為選擇前的討論紀錄。

| --- | --- | --- | --- |
| [01](01-codex-workspace.png) | Codex 工作區 | 左側切換作品；中央畫布；底部工具；右側屬性書籤 | 最容易建立統一工作區，但常駐側欄佔用寬度 |
| [02](02-focus-canvas.png) | 專注畫布 | 收起作品側欄；左側直排工具；小型標題列 | 畫布最大；切換作品需要展開側欄 |

| [06](06-home-library.png) | 首頁作品庫 | 真實作品縮圖；三種新建格式；選取、刪除、釘選與帳號入口 | 適合作為首頁，編輯時仍進入其他工作區布局 |

## 建議組合

- 主介面採 01 的資訊架構，保留作品切換與帳號入口。
- 繪圖時可切換 02 的專注模式，工具列仍支援左右直排、上下橫排。
- 筆記本採 03 的頁面導航；這是文件模式，與無邊界畫布共用物件與工具。
- 04 的詳細屬性與圖層放進使用者手動開啟的側欄，預設收合。
- 05 的圖釘導航放進可切換的側欄分頁，深綠底色保留為畫布主題。
- 首頁採 06；縮圖讀取真實作品，不自動建立示範黑板。

## 後續互動設計需明確定義

1. 作品側欄開關、寬度，以及畫布視角是否保持。
2. 工具列停靠與拖曳；選取工具、一次建立圖形後回到選取的狀態。
3. 屬性側欄只由使用者開啟；快捷屬性是否顯示亦需可選，避免再造成自動彈出的困擾。
4. 便簽與文字完整寬度輸入；完成／取消／換行及中文輸入法操作。
5. 圖層、物件鎖定、右鍵選單與圖釘改名／移動。
6. 尺規刻度、角度輸入與旋轉支點；筆寬與兩種橡皮擦的游標範圍。
7. 新建格式、背景修改、頁面切換與首頁作品選取／刪除。
8. 帳號入口、Google 登入與雲端狀態需依實際完成的功能提供，不由概念圖視為已實作。
