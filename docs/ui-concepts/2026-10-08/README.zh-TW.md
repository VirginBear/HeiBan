## 收合操作規格

1. 側欄開關固定在左上方標題列、黑板名稱旁。使用 macOS 常見的側欄圖示，開啟時提示「收合側欄」，關閉時提示「展開側欄」。按鈕不能放在會消失的側欄內容內。
2. 收合時左側筆記列表、頁面縮圖與新增頁面區完整隱藏，釋出實際畫布空間；不留下同寬空白。
3. 展開時恢復原筆記、選中頁面與列表捲動位置，不切換作品或重建頁面。
4. 記住使用者的開關狀態，下次啟動沿用；使用者可隨時切換。
5. 筆記紙張依可用區域重新置中，保留縮放比例及內容的世界座標；切換側欄不能當成內容修改或污染復原歷史。
6. 頂端保留當前筆記與頁面資訊，紙張下方保留頁碼與上一頁／下一頁入口。側欄收起仍能知道位置及切換頁面。
7. 開關可用鍵盤聚焦，具有清楚的可及性名稱與開啟狀態；遵守 macOS 減少動態效果設定。

## 與先前需求一起保留

- 此視覺方向適用於原生 Mac 介面；有邊界、無邊界與多頁筆記本仍是三種可用文件形式。
- 筆記本側欄顯示頁面；其他畫布形式可顯示作品／導航，不要求每個作品都變成筆記本。
- 工具列仍能停靠左右直排、上下橫排。概念圖的上方工具列是其中一種狀態。
- 右側屬性預設收合為書籤入口，由使用者點開；左欄收合不會讓屬性自動彈出。
- 保留 T 文字工具、便簽完整輸入區、圖層、可改名／移動的圖釘、右鍵選單、曲線與可調頂點。
- 保留尺規自適應配色、可移動、0.1° 角度輸入，以及一致的筆刷與橡皮擦範圍。
- 側欄縮圖須讀取真實頁面內容，不建立示範作品污染作品庫。
