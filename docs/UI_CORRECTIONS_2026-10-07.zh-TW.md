# 2026-10-07 首頁、尺寸與畫布形式修正

## 本次需求與處理

| 使用者提出的問題 | 實際原因與修改 |
| --- | --- |
| 首頁出現大量混亂範例 | 原生測試 35 的預設 BoardEngine 使用正式作品庫，累積 33 張「社群正方形貼文」與 11 張「無邊界思維導圖」。44 張皆無物件與圖釘，且 metadata 與該測試建立規格一致；已移至可還原封存。原本兩份「未命名黑板」保留。功能導覽改放問號入口。 |
| 筆寬圈圈與畫布不一致 | 舊設定圓圈被縮小，未套用筆刷倍率與縮放。新增 `CanvasToolMetrics`，讓原生設定預覽、游標、即時筆跡與提交筆跡共用筆寬換算；移除游標最小直徑。選項數字顯示實際筆寬，大筆刷可捲動預覽而不縮小。Web 同步移除游標的尺寸下限並提供實際大小預覽。 |
| 橡皮擦未按下滑鼠時沒有範圍 | 開啟原生視窗的 mouseMoved 接收，以 tracking area 與局部事件監聽更新游標；兩種模式共用半透明範圍。重開橡皮擦設定不再切回選取。 |
| 橡皮擦尺寸不一致 | 原生範圍採螢幕直徑 `eraserSize`，實際世界座標半徑為 `eraserSize / (2 × zoom)`；移除隱藏的最小擦除範圍。Web 維持其世界座標半徑設計，但預覽直接依同一半徑乘縮放。 |
| 有邊界與無邊界不明確 | 首頁收斂為三種主要格式，額外尺寸放進「尺寸與背景…」。有邊界與筆記本顯示紙張、陰影與外圍灰色工作區，格線／內容限制於紙張顯示，灰色區不能開始新增筆跡與圖形。原有超出紙張的物件資料仍保留。 |
| 背景需要後續修改 | 頂端底色選單新增自訂背景顏色，底色、主題與格線修改走可復原的命令並自動保存。 |
| 新增筆記形式 | 筆記本作為主要入口：多頁 A4 橫線紙，頂端可新增、切換與刪除頁面；保留既有頁面資料模型。 |

另修正自動保存回授：`writeAutosaveSnapshot` 成功後更新 `board.revision`，原本 `MainWindowView.onChange(board)` 會將該更新再次排程保存。現在純修訂編號更新不會觸發新保存；實際內容、背景、標題等修改仍會保存。這是程式碼可確認的重複保存原因，尚未量測修正後的互動效能。

## 後續：尺規配色、拖曳與角度輸入

- 預設 `HeiBan.rulerColorMode = adaptive`：白底用深色刻度／文字，暗底用淺色；尺身、邊框與角度底色一起調整。原本的自訂文字色保留，選「自訂刻度與文字」才套用。尺身透明度只影響底板，刻度不再被整體透明度削弱。
- 拖曳的程式碼負擔：原本 `@Published BoardEngine.ruler` 在每筆事件分別更新 X/Y，會通知所有觀察 BoardEngine 的畫布物件與面板；尺身亦使用移動中的背景模糊材質。現在由 `RulerStateStore` 單獨通知尺 overlay，每筆事件一次更新完整狀態；只有顯示／隱藏尺才通知主引擎。尺身改成半透明色板，靜態刻度快取，取消拖曳中的隱式動畫。
- 點尺上的角度數字可開「尺規設定」，輸入角度後按 Return 或「套用」；也可按 ±0.1° 微調。拖曳旋轉、鍵盤輸入、數字顯示統一為 0.1°。輸入超過一圈時轉為等效的 −180.0° 至 180.0°；拒絕非數字、NaN、Infinity。更改角度保留使用者選定的固定點。
- 工具列尺圖示右鍵也能開啟相同設定。
- Swift debug 與 release App build 通過。在獨立暫存作品庫的實際 Mac 介面確認白底深色／暗底淺色刻度切換、角度 12.5° 用 Return 套用、+0.1° 調至 12.6°，以及尺的移動把手可拖到新位置。設定增加明確關閉按鈕，彈出位置以角度按鈕為錨點。
- 未跑自動測試或進行大量物件／高刷新率下的 frame-time 量測；不能由這次查看宣稱所有卡頓已消除。驗收查看使用獨立資料庫，沒有新增範例到使用者作品庫。

## 後續：便簽與文字輸入面板

- 原因：面板至少 520 pt 寬，文字捲動區卻按物件原始尺寸配置為約 300 pt；捲軸因此出現在中央，右半邊空白。改成填滿面板寬度的單一輸入區，取消與完成移到標題列，格式、字體與透明度分列；顯示 Enter／⌘Enter／Esc 操作提示。
- 原生 `NSTextView` 的文件寬度與文字容器隨最終捲動區寬度同步；禁止橫向捲動、保留垂直伸展，避免長段落使行首橫向移出可見區。內容超出才顯示右側垂直捲軸，空白區也可點擊輸入。
- 面板大小使用畫布實際可見尺寸，不隨畫布 zoom 放大；開啟位置限制在畫布內，為上方導覽列與四邊停靠工具列保留空間。文字輸入區採畫布底色，便簽採該物件的底色。
- 文字工具用明確的 Latin「T」，避免 `textformat` SF Symbol 在中文環境顯示「格式」。保留工具列選取狀態、停靠排版與可及性標籤。
