## 3. 瓶頸分析與優化總結

1. **主層重畫瓶頸**：
   - 舊版原生畫布在每次指標移動時，會為所有物件執行 `VectorMath.worldToScreen` 點迴圈，在 1,000 物件下耗時 >50 ms，導致每秒幀數暴跌。
   - **解決方案**：
     1. 建立世界座標路徑快取 `BoardPathCache`，僅當物件幾何或筆跡變更時才失效。
     2. 渲染時對快取路徑套用單一 $2\times 3$ 仿射變換矩陣（`applying(transform)`），GPU/RenderServer 極速輸出。
2. **長筆跡尾段延遲瓶頸**：
   - 舊版未做分段，長筆跡隨點數增加呈 $O(N)$ 線性退化。
   - **解決方案**：
     - 採用 64 段塊隔離 + 局部平滑尾段（`tailPath`），單點追加耗時穩定在 0.005 ms，增幅為 0%。
3. **可見區空間索引 (AABB Culling)**：
   - 在 10,000 個物件的超大無限畫布下，空間裁切於 3.9 ms 內即過濾掉 9,967 個螢幕外物件，將繪圖開銷降低 99.6% 以上。
