# 第一次使用黑板

## 1. 建立作品

首頁點「＋」：筆記本用於多頁筆記，無邊界筆記可自由延伸，有邊界黑板適合固定尺寸內容。設定名稱與背景，之後仍可調整。點首頁作品縮圖開啟，更多選單可改名、複製或移到垃圾桶。

## 2. 寫、畫與修改

選畫筆並調整顏色、粗細；使用螢光筆、直線、箭頭、矩形與圓等工具。幾何物件完成後會回到選取，選物件可移動或調整。三角形／四邊形逐點建立；物件與像素橡皮擦只處理支援的筆畫／形狀，圖片與文字應用物件刪除功能處理。

文字與便簽在畫布上輸入。把截圖或圖片檔拖入畫布，或使用置入圖片功能；不要將圖片匯入誤認為可以修改其原始向量物件。

屬性面板預設可收起；選取物件後調整線色、填色、透明度與線型。尺身可拖動、兩端可旋轉，角度可輸入小數。圓規先準備位置／半徑／起點，再鎖定中心畫弧；計算機與計時器從輔助工具開啟。平台支援狀態以各自手冊為準。

## 3. 導覽

| 操作 | Mac | Windows |
| --- | --- | --- |
| 平移 | 空白鍵＋拖曳、中鍵拖曳、觸控板雙指 | 中鍵拖曳；一般滾輪平移 |
| 縮放 | 一般滑鼠滾輪以游標為中心；觸控板捏合 | Ctrl＋滾輪 |
| 復原／重做 | ⌘Z／⌘⇧Z | Ctrl+Z／Ctrl+Y |
| 複製／貼上 | ⌘C／⌘V | Ctrl+C／Ctrl+V |
| 螢幕畫布開始／作畫切換 | ⌘⌥⇧D | 尚未提供 |
| 螢幕畫布結束 | ⌘⌥⇧X | 尚未提供 |

工具列可拖曳，左右停靠直排、上下停靠橫排；可收起側欄與屬性面板，保留畫布空間。

## 4. 保存與備份

原生作品自動保存在各自平台資料夾；換電腦或分享可編輯內容，請另存 `.heiban`。PNG 是合成圖，不保留所有物件。Mac 的 PDF／SVG 匯出仍應同時保留 `.heiban`；不要期待外部 PDF 能還原原始物件。
