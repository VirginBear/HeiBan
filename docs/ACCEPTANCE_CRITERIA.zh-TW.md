# HeiBan 驗收目標

日期：2026-10-02。這是驗收規格，不是已通過報告。所有新案例起始狀態為「待驗收」；已有的部分證據見 [FEATURE_PARITY_CHECKLIST.md](FEATURE_PARITY_CHECKLIST.md)。

## 驗收規則與環境

- 功能必須能從產品介面操作，保存後重新開啟仍正確，且該操作的復原／重做語意合理。
- 使用同一版 App、同一份文件與固定步驟錄製證據。每個 A 編號的子條件全部成立才可標為通過。
- macOS 本機基準：本機讀取到 Apple M4、16 GB RAM、macOS 27.0.1（26A434）。此資料只是環境記錄，未在本次測性能。
- 性能基準先使用 60 Hz 顯示模式、Release build；記錄視窗尺寸、輸入裝置、顯示縮放與是否接電。macOS 14 最低版本及其他硬體另有相容性驗收，不由本機結果推定。
- 以下數值為**提議的工程門檻**，不是已有量測。完成第一次基線後，以記錄修訂門檻；不能為了通過而默默降低。
- 「超過網頁版」以原生 Release build 與 Web production build，在同機、同文件、同操作下量測比較；需同時通過品質標準。功能數較多或使用 Swift 都不能單獨證明性能更佳。

## 性能與可靠性

### A01 筆跡流暢與低延遲

- 步驟：在空白板、F01 與 F02 各畫快慢 S 線／小圈／折返；以 100%、400%、800% 檢查，放開後再保存與重開。
- 通過：沒有因曲線拼接產生的可見折痕、透明度接縫或端點跳移；使用者有意畫的尖角需保留。預覽末點與最後輸入點誤差 ≤1 個螢幕 point；預覽與完成結果不得突變。
- F01：輸入事件被 App 收到至預覽提交的 p95 ≤20 ms，單次 ≤50 ms；此為軟體管線延遲，不宣稱是螢幕實際顯示延遲。
- 使用高速錄影量測移動到首次可見筆跡時，端到端 p95 目標 ≤50 ms。沒有相應錄影設備就標為待驗收。
- F02 最後 10 秒相對最初 10 秒的預覽管線 p95 增幅 ≤20%；新增取樣不遍歷或複製整份文件。
- 與網頁版比較至少 5 輪，記錄每輪及中位數；日常筆跡／平移兩項至少一項改善 ≥20%，另一項不退步，才能宣稱本輪「性能超越」。

### A02 大文件與資源

- 步驟：F01／F03 連續平移、縮放、選取、擦除、保存與重開；持續 10 分鐘。
- 通過：F01 互動呈現間隔 p95 ≤16.7 ms，F03 p95 ≤33.3 ms；沒有 >100 ms 的主執行緒停頓。記錄 profiler 與 frame pacing，而非只看平均 FPS。
- F03 開啟至可操作 ≤5 秒；保存過程可繼續操作。峰值 App 記憶體目標 ≤1.5 GB；重複開關文件後不持續成長。記錄 decode、快取與歷史各項占用。
- F01 的 Web／native 使用相同圖片、內容與測試步驟，記錄比較結果。

### A03 保存、切換與恢復

- 步驟：畫完立即換板／返回首頁／Cmd+Q；在自動保存期間終止驗收 App；模擬寫入失敗與損壞副本，再重開。
- 通過：已顯示「保存成功」的修訂完整保留；中斷寫入仍有上一個完整版本。失敗顯示錯誤且不切走／清除當前文件；未成功保存不得顯示成功時間。
- 防抖保存與使用者選的每幾分鐘快照／雲端備份分別顯示；改頻率不影響立即手動保存。正常退出會 flush 最新修訂。
- legacy `current.blackboard.json` 可還原／遷移而不丟失物件；恢復入口能辨認損壞文件並保留原件。

### A04 編輯交易與歷史

- 步驟：依序新增、變形、文字編輯、改樣式、擦除、改圖層、改圖釘與畫布設定；逐步復原、重做、保存與重開。
- 通過：一個完成手勢是一個交易；沒有每個輸入點一筆歷史。內容與相關 metadata 可正確回復；視角／選取等暫時狀態不誤標為作品修改。
- 清空畫布可一次復原；保存檔案不把編輯歷史混到另一份文件。歷史有記憶體預算，淘汰前仍可保存正確的當前文件。

## 文字與便簽

### A15 中文原地編輯與格式

- 在點擊位置出現區域框與閃爍游標，直接輸入；空白取消不留下物件。雙擊既有文字原地再編輯。
- 繁中注音與至少一種拼音輸入法選字時不提早送出；完成／取消與多行換行有清楚操作。
- 字體、字級、色彩、透明度、對齊可調；選取部分字句可改粗體、斜體、底線、刪除線與高亮，而非只能整框一種格式。
- 富文本片段在文件、復原／重做與輸出中保持一致。現有單一物件欄位不足以證明局部富文本完成。

### A16 可愛便簽與文字邊界

- 可選經典、和紙、貓咪、筆記、格紙、柔和卡片等樣式與色系；樣式切換保留內容。
- 中文、英文長字、Emoji、多行皆在便簽內自動換行；縮放與改字級不跑出卡片。內容超出時提供明確提示／捲動或調整大小，不能無提示截掉而造成內容遺失。
- 可縮放、原地再編輯、改字體與字級；保存、重開與輸出結果一致。

每個 A ID 建立一筆記錄，失敗／待驗收也要記錄。

```text

日期／執行者：
App 版本／Git commit／build configuration：
macOS／設備／顯示器 Hz 與縮放／輸入設備：
Fixture 名稱／hash／種子：
前置條件與操作步驟：
預期結果：
實際結果與原始量測（p50／p95／max／峰值記憶體）：
證據路徑（截圖／錄影／trace／fixture diff）：
結論（通過／失敗／待驗收）：
關聯 W ID／缺陷 ID：
```

進入「可正式推出」前，適用的 A01–A31 全數通過；本機里程碑的範圍見開發計畫。線上服務或支援的外部格式尚未完成時，保留待驗收，不用虛擬數據代替。
