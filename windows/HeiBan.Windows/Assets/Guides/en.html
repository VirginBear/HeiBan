01Interface and guide language

At the bottom of the home sidebar, choose Language (the 文/A icon when collapsed). The ten languages are Traditional Chinese (default), Simplified Chinese, English, Japanese, Korean, Spanish, French, German, Brazilian Portuguese and Arabic. A saved choice applies immediately and is remembered at startup. Existing work names and text are not translated; new default names use the current language.

Help opens in the current interface language. The selector on this page changes only the guide, not the app preference. All guide pages, navigation and search work offline. Arabic menus and help read right to left; canvas coordinates are not mirrored. System file dialogs and original error messages may use another language; some built-in controls may require an app restart.

02Getting started

On the home page, press + to create a notebook, infinite canvas or bounded board. Enter a name and choose a background color and pattern. Use Pen to draw and Selection (V) to move or adjust objects.

Auto-save is OFF by default. Use Ctrl+S to save manually; leaving a work or exiting normally also saves. Export .heiban for an editable backup.

03Home and work library

Click a card once to highlight it without showing batch actions. Double-click, or right-click and choose Open work, to enter. Right-click also offers favorites, rename, duplicate and move to trash. Trash retains the editable original; double-click a trashed card to restore.

Use the dashed circle beside Import to enter multi-select; a checked circle identifies a selected work. Select all current results or choose individual cards, then move them to trash; Done exits multi-select. Search by name, filter by format, sort by modification, creation or name, and choose 160/190/250 pt thumbnails. Import opens .heiban or .blackboard.json; the sidebar switches between all works, favorites and trash. The toolbar defaults to icons with text. Brush and Line style are already in Favorites; customize them in toolbar settings. On first use, an editable infinite note, User guide · All tools, is added with every tool and practice objects. Pan with the middle button or Space+drag, zoom with the wheel, and use the pin list to jump to chapters. Existing examples and edited works are preserved; editing or deleting this guide does not recreate it on every launch.

04Canvas types and pages

A notebook has independent pages. The bottom page number and previous/next arrows navigate; + adds a page. The page menu can jump, rename, duplicate, reorder or delete pages. An infinite canvas extends in any direction. A bounded board has a fixed page boundary for presentations or structured layouts.

An infinite canvas has no size selector. A new bounded board initially uses a 16:9 presentation (1920×1080); A4 portrait, A4 landscape and 1:1 remain available. Switching types remembers that dialog's chosen sizes. Creation and Canvas background offer plain, ruled, dotted, square grid and staff paper plus color. Apply changes an existing background; Cancel leaves it unchanged; one undo restores it.

05Pan, zoom and view lock

The wheel zooms around the pointer; Ctrl+wheel also zooms. A horizontal wheel pans. Drag with the middle button or hold Space and drag with the left button to pan. In reading mode, left-drag pans. The zoom control offers presets, fit content and reset view.

View lock prevents panning and wheel zoom during explanations. Both the toolbar and corner lock indicators change together. Unlock to move the view again.

06Navigation and toolbars

The upper navigation contains Home, reading/editing mode, pins, + insertion, More, save status and a pin to keep navigation visible. Otherwise it collapses when the pointer leaves. A check marks saved work; a dashed circle means pending, saving or incomplete saving.

Drag a toolbar grip to any of the four sides: horizontal at top/bottom, vertical at left/right. More → Customize toolbar lets you show, hide and reorder tools; hidden tools remain in More tools. Object layers is a toolbar entry and a separate panel. Screen toolbar layout adapts to the available area without scrollbars.

Home Settings or More → Customize toolbar offers icons only or labeled tabs: Common, Draw, Insert and Organize. Selection (V) stays available. Tools occupy one row or column; when space is short, the arrows switch tool groups without adding rows. Check the left box to show a tool and Common to choose favorites. Select all, Defaults and ordering remain available. App-owned panels and dialogs use a fixed paper-white and green HeiBan design independent of Windows light/dark mode. System file pickers remain controlled by Windows.

The toolbar defaults to icons with text. Brush and Line style are already in Favorites; customize them in toolbar settings. On first use, an editable infinite note, User guide · All tools, is added with every tool and practice objects. Pan with the middle button or Space+drag, zoom with the wheel, and use the pin list to jump to chapters. Existing examples and edited works are preserved; editing or deleting this guide does not recreate it on every launch.

07Pen and brush choices

Choose Pen, then the color circle for color, thickness, opacity and brush type: vector pen, fountain pen, pencil, watercolor, highlighter, crayon, calligraphy or paint. Preferences are remembered. Strokes use smoothed vectors; brush names do not imply physical material simulation. Finished strokes can be moved or recolored.

With the vector pen, draw an approximately straight stroke and keep pressing without moving for one second to snap it straight. Moving more than 12 pt restores the original stroke preview. Releasing commits one undo operation. Cover tape in More tools hides a question; double-click or use object settings to reveal/hide it, with undo support. Pen, highlighter and paint strokes are not automatically selected or boxed when finished. Press V and select an object to move, resize or rotate it; double-click opens detailed properties. The board eraser keeps its upper-left to lower-right angle, with 20% less length and unchanged thickness.

08Lines, arrows, shapes and curves

Create a line or arrow by dragging, or clicking A then B. Move the shaft or adjust endpoints independently. In Properties, choose a segment, extend toward A or B, or extend both ways without changing the original endpoints. Arrow head length and width are separate controls; stroke thickness also changes the head outline.

Drag rectangles, circles, diamonds, pentagons and stars. Triangles and quadrilaterals use successive points. A curve uses three points: first starts the preview, second fixes the bend, third commits. Selection edits vertices or control points. Esc cancels unfinished geometry. Color and Properties control applicable stroke, fill, gradient and opacity.

Drawing tools remain active after creation. Triangles and quadrilaterals preview straight segments; only Curve previews a curve. Circles, diamonds, pentagons and stars are dragged from their center, rectangles from a corner. Magnet works from the first point, with a green ring within about 10 screen DIPs. A rectangle has nine references: four corners, four edge midpoints and center. Triangles have three vertices and three midpoints; other polygons also include edge midpoints, and lines/arrows include both ends and midpoint. Circles and compass arcs provide center and four cardinal points; arcs also provide endpoints. Hidden objects are excluded, locked shapes remain references, and existing objects never move.

09Selection and transformations

Use V to select. Ctrl+click toggles objects; lasso selects an enclosed region. Drag a box left to right to select only fully enclosed objects (blue solid border), or right to left to select touched objects (green dashed border). Ctrl/Shift-drag adds selection. Multiple objects can move, copy, paste, change style or delete together.

A single shape has eight resize handles and a rotation handle; the pointer shows the corresponding direction or rotation arrow. Lines/arrows have A/B handles and arcs have start/end handles. Image corners preserve proportions by default; Shift allows free resizing. Shift while rotating snaps to 15°. Locked objects are excluded from batch move/delete; hidden objects stay in the layer panel.

Creating or single-clicking an object shows only resize, rotation or endpoint handles. Detailed controls appear on double-click; double-clicking text starts editing. Choose V to manipulate an object and another tool to resume drawing. Drawing tools do not return to V after each object.

10Properties, colors and styles

The Properties panel shows only settings applicable to the selected object. Adjust stroke color, thickness, applicable fill/gradient/opacity, text or geometry values. Solid, dashed, dotted and dash-dot choices show line samples; the toolbar reflects the current style. Drawing defaults can be set before drawing; selected-object changes also update subsequent drawing settings.

Dock the panel by its Dock control or drag its title to an edge: vertical at left/right, horizontal at top/bottom. Layers, eraser and ruler settings have their own entries instead of cluttering an unrelated object's properties. Line extension and arrow head dimensions are in the line/arrow properties.

11Text and sticky notes

Choose Text (T) or Sticky note, then click the canvas and type. Enter inserts a line break; Ctrl+Enter or leaving the editor finishes; Esc cancels. Composition input does not trigger tool shortcuts. The color circle provides font, bold, italic, underline, strike-through and alignment. Sticky notes have folded-corner, tape, cat, notebook, grid and soft styles.

Edit partial text formatting opens an editor: select text, then apply format, text color or highlight and save as one undo operation. Right-click text or its draft for whole-box style. More text settings applies only changed fields to unlocked text/notes on the current page, skipping other objects. Screen text supports 8–144 pt, custom #RRGGBB, font, alignment and opacity.

12Eraser

Select Eraser; click it again to choose object erasing or partial stroke erasing and adjust diameter. A translucent circle previews its range in both the regular and screen canvas.

Object erasing removes an entire touched stroke or geometric object. Partial stroke erasing removes only the crossed part of a stroke. Text, sticky notes and images are protected; select them and press Delete to remove them.

The regular canvas has an original paper-white and sage magnetic eraser viewed straight from above at bottom right. Drag it to erase the matching angled, rounded felt footprint; releasing returns it to its dock and commits one undoable action. Esc or lost pointer capture cancels the whole wipe. Right-click to choose object or partial-stroke mode, or hide it. Home Settings → Show board eraser restores it. Its screen size is converted into document coordinates at the current zoom. Partial/pixel mode cuts ink only; it does not alter image pixels or original PDF/presentation elements. The screen canvas keeps its circular toolbar eraser. Use toolbar More → Show board eraser to toggle it and remember the choice. The eraser slopes from upper left to lower right; grabbing and erasing follow the mirrored outline.

13Ruler

Enable the ruler, drag its body to move it and drag endpoint handles to rotate. Move the gold pivot onto either drawing edge or either end; rotation stays around that pivot. Right-click the ruler, or use its settings, for the edge, 0–100% pivot position, 0.1° angle, opacity and length.

Length is 20–150% of canvas width, initially 90%, and adapts to window size. A pen stroke started near an edge snaps along that edge for the whole stroke; drawing beyond the ruler still follows the same axis.

14Compass: prepare, lock, draw

Prepare by dragging the center, radius handle and pen tip to position the circle and starting angle. These guides create no object. Click the center to turn it bright orange and lock center/radius.

Drag the tip around the circumference to preview an oriented arc; crossing 0° remains continuous. Release to create one editable arc and one undo operation. A stationary click creates nothing. The arc has proportional resize/rotation controls and start/end angle handles.

15Laser pointer

Choose Laser from the toolbar or More tools. Click the active laser again for settings; choose a dot, short trail or line, color, diameter, width, fade time and white core. The screen canvas also provides these settings.

Laser marks are temporary pointers. They do not create saved objects or add undo operations.

16Calculator and timer

Open Calculator or Timer from the upper + menu. Drag the title to move or collapse the panel. Calculator supports parentheses, scientific functions, π, e, Ans and keyboard/Enter; only Insert expression creates a text object.

Timer offers a stopwatch, 5/15/25-minute countdowns and custom seconds. Closing its panel keeps it running and it notifies when time is up; reopening shows the current state.

17Images, screenshots and cropping

Use Screenshot in + or the toolbar, then drag an area. Esc or right-click cancels; switching work/page or a timeout also cancels. The result becomes an image at the current view center with its original proportions; it is not saved into a separate screenshot folder. Win+Shift+S results can instead be pasted with Ctrl+V.

Drag PNG/JPG/BMP files from Explorer onto the canvas. Images can move, resize and rotate. Select an image and use Crop image / Restore original in its color menu; enter a rectangle in original image pixels. Cropping preserves the source image. The built-in capture uses its own result, not unrelated clipboard images.

18View pins and colors

The upper pin control saves the current view center and zoom. Select an entry to return to it. Double-click a pin or its name to rename; Enter or clicking elsewhere saves, Esc cancels. Right-click names also offers rename, and edits support undo.

Right-click a pin for Pin and text colors, or choose Colors in the pin list, to set each separately. Windows saves these optional colors; an older Mac version may remove them when resaving the work.

The pins dialog opens with Add and focuses the new name; search and existing pins follow below. The list draws the same pin as the canvas, using each pin’s body and text colors.

19Screen canvas

Start from the home sidebar, the screen icon or More tools; Ctrl+Alt+A also opens it. The current work saves and the main window hides. The desktop remains live beneath an independent transparent annotation canvas. Drag the toolbar grip to four edges; icon-only mode wraps without scrollbars, while labeled tabs stay in one row/column with arrow paging, keeping clear/close accessible. Color, layers and palette have entries; set shape fill in the Shapes menu. click Eraser or Laser again for settings. Supported shared tools follow the main toolbar visibility and order; pins and view lock are omitted. The Shapes menu contains the same nine shapes. With Pen, a nearly straight stroke snaps to a line after holding still for one second; moving more than 12 pt restores the freehand preview.

Draw/Operate or Ctrl+Alt+D switches between annotation and passing input to the app below. Right-click an object to change style, copy, duplicate, delete, lock or reorder; clicking an already selected object preserves the group. Right-click empty space cancels only the unfinished gesture. Shift-click or box selection adds objects; box direction follows the same enclosed/touched rule. Lasso selects intersecting objects. Selection moves, resizes, rotates and adjusts endpoints. Shift constrains lines/arrows to horizontal/vertical.

Choose T and click to type; Enter makes a new line, Ctrl+Enter/Done commits, Esc cancels. Double-click text or use More → Selected objects → Edit text. Switching tool/mode, capturing, exporting or ending commits a draft. Styles apply only changed values to unlocked selected objects and continuous slider edits undo together.

Screenshot or Ctrl+Alt+S captures an area with annotations as an image at its original screen position, without a separate screenshot folder. More → Export annotations saves a transparent PNG or editable .heiban. More → Save annotations saves manually. × or Ctrl+Alt+Q saves the independent session and restores the main window; reopening resumes it. Trash or Ctrl+Alt+K clears all annotations without another prompt; Undo restores them. Shortcuts may be occupied by other apps; use the toolbar then. Screen annotations never automatically merge into the main work.

20Saving, data and export

Home Settings or More → Settings controls Auto-save, OFF by default. A saved choice persists. ON keeps regular canvas saves around every 15 seconds and screen saves about one second after changes stop; unfinished gestures postpone saving. OFF stops periodic work saves. Ctrl+S saves a regular work; More → Save annotations saves the screen canvas.

Returning home, switching works/screen canvas and normal exit save and wait, showing a spinning progress indicator. A save failure keeps the window and content. With auto-save OFF, a crash, power failure or forced termination may lose unsaved changes.

For export, select all content on the current page, selected objects or the current view, then .heiban, JSON, PNG, SVG, PDF or HTML. Editable work/JSON always keeps all pages; images and reading formats follow the chosen scope. PNG uses the canvas renderer; SVG includes vectors/images and rich-text foreignObject (viewer support required). PDF needs Windows Edge WebView2 and includes editable source data; HTML reads offline and includes editable JSON.

Installed builds store data under %LOCALAPPDATA%\HeiBan\Windows\; portable builds use Data/ beside the app. Store builds use their own app data location. Close the app and back up the complete data folder, including works, trash and settings, before migration. Keep the portable folder together; do not run directly inside a ZIP.

Home → Import accepts PDF, PPTX and PPT. Each page becomes a locked background image on a separate notebook page for annotation. Choose a page range, up to 200 pages and 100 MB of rendered images per import. Cancelling creates no partial work. Original text and shapes do not become editable elements.

PPT/PPTX needs desktop PowerPoint on this computer; otherwise convert to PDF first. Missing fonts can alter layout. Animation, video, transitions and interactivity are not preserved; encrypted or damaged files may fail. For a complete notebook PDF, choose current page/all content and enable Export all pages to PDF. Selected objects/current view continue to export only that scope.

21Keyboard reference

Ctrl+S — save; Ctrl+N — new work; Ctrl+Z / Ctrl+Y — undo/redo; Ctrl+C / Ctrl+V — copy selected objects / paste objects or clipboard images; Delete — delete selection; Esc — cancel a gesture/capture/unfinished shape.

Space+drag or middle-drag — pan; wheel or Ctrl+wheel — zoom; V / P / E / T — Selection / Pen / Eraser / Text; Win+Shift+S then Ctrl+V — Windows capture and paste. Screen: Ctrl+Alt+A — start; D — Draw/Operate; S — capture; K — clear; Q — end (each with Ctrl+Alt). Use toolbar controls if another app reserves a shortcut.

Undo and Redo step backward or forward through edits. Clear page asks for confirmation, removes objects on the current page and can be undone; other pages are unchanged. Delete removes selected objects.

22App updates

GitHub builds offer update settings under Home → About → Update settings or More → Check for updates and update settings. Background checks begin about ten seconds after startup and repeat every six hours while the app runs. Disable automatic checks or preview versions, or check manually. This is separate from auto-save.

Downloads match architecture/install type and verify size/SHA-256. After saving succeeds and all windows of the installation close, a separate updater installs for the next launch, without forcing close or reopening. Interrupted/offline downloads or occupied files keep the current version for a later retry. Disabling auto-update also prevents a staged update from applying.

Portable updates preserve Data, portable.dat and unknown files; installed updates keep the data location. Backups are retained. Update staging/results are under %LOCALAPPDATA%\HeiBan\Updates\; works are not uploaded. Do not remove a drive or interrupt power during installation. Microsoft Store builds update through the Store, never by GitHub file replacement. Hash checks are not Authenticode signatures; Windows may still warn on first installation. Older builds need a one-time manual upgrade to gain the updater.

23Scope and known limits

Windows 1.0.15 is approved by the product owner for a Microsoft Store update package. Availability depends on Store certification and publication; consult the development records for device compatibility and known limitations.

Cloud/Google sync, collaboration, dedicated mind maps, tables, formulas, frames and editing external PDF/SVG as original works are not delivered features. Unknown document JSON fields are retained. A shared .heiban can contain user text in its original language; changing the UI does not translate it.

24Background settings in practice

For a new work, choose the canvas type before size and background. Infinite canvases do not need dimensions; bounded boards start at 16:9 but can be changed. Plain, ruled, dots, grid and music staff patterns can be selected at creation or later through Canvas background.

For an existing work, use Apply to commit or Cancel to keep the original; the change is undoable. Background settings change the paper, not the color of existing strokes or text.

25Layer order and editing feedback

Open Object layers from the toolbar or More. Top rows are in front. Drag the gray double bar to the left of an icon onto the upper/lower half of another row to insert above/below it. The original row fades, a name/icon preview follows the pointer and a green insertion line marks the drop location. Rename layers without changing object identity; an empty name restores automatic naming.

Hidden objects remain available in the panel; locked objects resist batch move/delete. Properties and Object layers are separate panels. Directional resize/rotation cursors, saved/pending indicators, checked multi-select circles and eraser range previews help explain the current action. Report unexpected behavior from this trial before a formal update is approved.
