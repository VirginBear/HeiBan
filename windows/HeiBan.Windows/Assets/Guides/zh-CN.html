01介面与手册语言

首页侧栏下方「语言」（收合时为文/A图示）提供繁体中文（默认）、简体中文、英文、日文、韩文、西班牙文、法文、德文、葡萄牙文（巴西）、阿拉伯文。保存成功立即应用，下次启动沿用。既有作品名称与文字不翻译，新建的默认名称采当时语言。

使用说明随目前介面语言开启；本页语言选单只切换手册，不改程序偏好。全部手册、章节与搜寻均可离线使用。阿拉伯文介面与手册从右向左阅读，画布座标不镜像。系统选档与原始错误讯息可能使用其他语言，部分内建控制项可能需重新启动。

02开始使用

首页按＋新增，选笔记本、无边界画布或有边界黑板，输入名称并设定背景色与样式。画笔用来手写，选择工具（V）用来移动及调整物件。

自动存档默认关闭。Ctrl+S可手动保存，离开作品或正常退出也会保存。导出.heiban可作为可编辑备份。

03首页与作品库

单击卡片只反白，不显示批次操作列；双击或右键「开启作品」进入。右键亦可收藏、改名、副本与移到垃圾桶。垃圾桶保留原稿，双击垃圾桶卡片可还原。

按导入旁虚线圆进入多选，圆圈打勾表示已选；可全选目前结果或逐张选择，再移到垃圾桶，「完成」离开多选。可搜寻名称、筛选格式、依修改／建立／名称排序及选160／190／250 pt缩图。导入支援.heiban／.blackboard.json；侧栏切换全部、收藏与垃圾桶。 工具列默认为「图示与文字」，常用分页预先包含笔刷与线条样式；可在自订工具列调整。首次使用会加入「操作说明 · 全工具指南」无边界笔记，涵盖全部工具及可编辑范例。用中键拖曳／空白键加拖曳平移，滚轮缩放，开图钉清单可跳到各章。旧范例与已编辑作品不会被覆写；修改或删除新指南後不会每次重建。

04画布格式与页面

笔记本各页独立，底部页码与左右箭头翻页，＋新增页；页码选单可跳页、改名、副本、排序及删页。无边界画布可向任意方向延伸。有边界黑板提供固定纸张边界，适合简报与排版。

无边界不显示尺寸。新有边界黑板首次默认16:9简报（1920×1080），仍可改A4直向、A4横向或1:1；切换格式记住此对话框已选尺寸。新增与画布背景提供空白、横线、点状、方格、五线谱及底色；既有作品按应用才修改，取消保留，修改可单步撤销。

05平移、缩放与视角锁定

滚轮以鼠标位置缩放，Ctrl+滚轮亦同；水平滚轮平移，中键拖曳或空白键加左键拖曳平移。阅读模式左键拖曳平移；倍率控制提供默认比例、适合内容及重设视角。

视角锁定停止平移与滚轮缩放，避免讲解误移。工具列与角落的锁定指示同步变化，解锁後可再次移动视野。

06导览与工具列

上方导览包含首页、阅读／编辑、图钉、＋插入、更多、存档状态及固定开关；未固定时鼠标离开会收合。勾号表示已存，虚线圆表示待存、保存中或尚未完成。

拖工具列握把到四边，上下横排、左右直排。更多→自订工具列可显示、隐藏与排序，隐藏的项目仍在更多工具。「物件图层」有工具列入口与独立面板；屏幕工具列不显示卷轴。

首页设定或「更多 → 自订工具列」可选只有图示，或图示与文字分页。图文模式分成常用、绘图、插入、管理；选择（V）固定常驻。工具只排一行／一列，空间不足用两端箭头切换工具组，不增加工具排数。自订窗口左侧勾选显示，另勾「常用」挑选常用分页；仍可全选、默认及排序。所有应用程序内面板与对话框固定使用黑板的纸白／绿色设计，不随 Windows 亮暗主题切换；系统档案挑选器由 Windows 管理。

工具列默认为「图示与文字」，常用分页预先包含笔刷与线条样式；可在自订工具列调整。首次使用会加入「操作说明 · 全工具指南」无边界笔记，涵盖全部工具及可编辑范例。用中键拖曳／空白键加拖曳平移，滚轮缩放，开图钉清单可跳到各章。旧范例与已编辑作品不会被覆写；修改或删除新指南後不会每次重建。 「清除本页」默认收在常用；更新时只追加这一项，保留其他自订常用。一般画布与屏幕画布的图形选单使用相同描边图示与九宫格。

07画笔与笔刷

选画笔，再点色圆调颜色、粗细、透明度及种类：向量笔、钢笔、铅笔、水彩、萤光笔、蜡笔、书法、油漆。偏好会保存；笔迹为平滑向量，笔刷名称不代表物理材质模拟，完成後可移动或改色。

向量笔近似直线，保持按住且停一秒可吸附直线，移动超过12 pt恢撤销预览；放开才提交一笔可撤销操作。更多工具的遮题胶带可遮住题目，双击或物件设定揭示／遮住，支援撤销。 钢笔、萤光笔及油漆笔刷完成後不会自动选择或显示框线；按V再点选物件可移动、缩放或旋转，双击才开详细属性。板擦保留左高右低，长边缩短20%，厚度不变。

08线段、箭头、形状与曲线

线段／箭头拖曳或先点A再点B建立，线身整体移动、两端独立调整。属性可选线段、向A／B或双向延伸而不改原端点；箭头头部长宽独立，线条粗细也调整头部轮廓。

矩形、圆、菱形、五角与星形拖曳建立；三角／四边形逐点，曲线三点：第一点预览、第二点固定弯曲、第三点提交。选择可调顶点／控制点，Esc取消未完成几何。色圆与属性调整适用的线色、填色、渐层与透明度。

完成後保留原绘图工具，三角／四边形逐顶点预览直线，曲线才预览曲线。圆、菱形、五角与星形从中心开始拖曳，矩形从角开始。磁铁从第一个点就作用，靠近约 10 个画面 DIP 时显示绿圈并吸附；矩形有四角、四边中点及中心共九点；三角形有三顶点与三边中点；其他多边形也含各边中点，直线／箭头有端点与中点。圆与圆规圆弧含中心及上下左右点，圆弧另含起讫点。隐藏物件不参与，锁定形状仍能参考，原物件不会被移动。 磁铁只吸附几何工具的建构点与圆规定位；画笔、萤光笔、油漆笔保留原始手绘轨迹，跨越旧笔迹不吸附。一般画布与屏幕画布一致；尺规投影及停笔一秒直线辨识仍依各自规则作用。

09选择与物件变形

V选择，Ctrl+点击增减物件，套索沿范围选择。空白处拖框左往右为蓝实线，只选完全包含；右往左绿虚线，选碰到的物件；Ctrl／Shift拖框追加。多选可整组移动、复制、粘贴、改样式与删除。

单一形状有八方向缩放与旋转把手，游标显示相对应方向或旋转箭头；线段／箭头为A、B，圆弧有起讫角。图片角落默认等比，Shift自由缩放；旋转Shift吸附15°。锁定物件不参与批次移动／删除，隐藏物件仍留在图层。

建立物件或单击选择时，只显示大小、旋转、端点等控制点，不自动弹出详细调整列。双击物件才开启详细属性；双击文字进入文字编辑。选择工具可随时切换回绘图，绘图工具不会在每一笔结束後切回 V。

10属性、色彩与样式

属性面板只显示所选物件适用项目，可调线色、粗细、适用的填色／渐层／透明度、文字与几何数值。实线、虚线、点线、点划线提供样本，工具列显示目前样式；可先设绘图偏好，修改选择物件也更新後续绘图设定。

按停靠或拖标题到四边，左右直排、上下横排。图层、橡皮擦与尺规有各自入口，避免混入不相关物件属性。延伸直线及箭头头部长宽在对应属性中。

11文字与便条纸

T或便条纸工具後点画布输入，Enter换行，Ctrl+Enter或离开完成，Esc取消，组字不触发工具快捷键。色圆提供字型、粗体、斜体、底线、删除线及对齐；便条纸有折角、纸胶带、猫咪、笔记本、方格及柔和款。

编辑局部文字格式窗口中先选文字再改格式、文字色或标记色，保存为一笔Undo。文字或草稿右键可调整整框样式；更多文字设定只应用修改字段到本页未锁定文字／便条纸，略过其他物件。屏幕文字支援8–144 pt、自订#RRGGBB、字型、对齐与透明度。

12橡皮擦

选橡皮擦，再点目前工具开设定，选物件擦除／局部笔迹擦除及直径；一般与屏幕画布均以半透明圆显示范围。

物件擦除整笔移除碰到的笔画或几何；局部擦除只移除划过的笔迹段。文字、便条纸及图片受到保护，删除请选择後按Delete。

一般画布右下角有原创纸白／雾绿俯视磁吸板擦，按住拖曳依斜放的圆角擦面轮廓擦除，放开回到停靠处并提交一笔可撤销操作；Esc 或失去捕捉会取消整次擦拭。右键板擦选物件或局部笔迹模式，也可隐藏；首页设定→显示板擦可重新开启。擦面以画面大小显示，随缩放换算到作品座标。局部／像素模式只切断笔迹，不修改图片像素或原始 PDF／简报元素；屏幕画布仍使用工具列的圆形橡皮擦。工具列「更多→显示板擦」可随时切换显示并记住选择；板擦呈左高右低，抓取与擦除轮廓同步镜像。 圆形橡皮擦可连续拖曳；擦除预览逐步更新，放开鼠标完成本次擦除并合成一笔撤销操作。Esc或指标捕捉中断会取消尚未完成的擦除。正常保存或退出会等待已放开的擦除完成。

13尺规

启用尺，拖尺身移动，拖端点旋转；金色支点可移到上下划线边或两端，旋转固定该支点。右键尺或尺设定可调边、0–100%支点位置、0.1°角度、透明度及长度。

尺长为画布宽度20–150%，默认90%，随窗口大小调整。画笔在尺缘起笔即锁定该边，整笔保持直线，超出尺长仍沿同轴延伸。

14圆规：准备、锁定、画弧

准备时拖圆心、半径与笔尖调位置、半径和起角，不产生物件。点圆心变亮橘色，锁定圆心与半径。

拖笔尖沿圆周预览有向弧线，跨0°连续计算；放开生成一个可编辑圆弧及一笔Undo。静止点击不产生无效物件；完成弧可等比缩放、旋转与调起讫角。

15雷射笔

工具列或更多工具选雷射，再点目前雷射开设定：光点、短尾迹或线条、颜色、直径、粗细、消退时间与白色光芯。屏幕画布同样提供设定。

雷射是暂态引导，不写入永久物件，不增加Undo操作。

16计算机与计时器

上方＋开计算机或计时器，拖标题移动或收合。计算机提供括号、科学函数、π、e、Ans与键盘／Enter，按插入算式才新增文字物件。

计时器有码表、5／15／25分钟倒数及自订秒数；关闭面板仍计时，到时通知，重新开启保留目前状态。

17图片、截图与裁切

＋或工具列选截图後框选区域，Esc／右键取消；切作品／页面与逾时也取消。结果依原比例置入目前视野中心，不另存截图文件夹。Win+Shift+S图片可用Ctrl+V粘贴。

可从档案总管拖PNG／JPG／BMP到画布，移动、缩放、旋转。选图片後色圆内裁切图片／恢撤销图，以原图像素范围裁切并保留来源。内建截图只使用此次结果，不读无关剪贴簿图。

18图钉与配色

上方图钉保存目前视野中心与倍率，点清单返回该视角。双击图钉或名称改名，Enter／点其他处保存、Esc取消；名称右键也可改名，支援Undo。

右键图钉的图钉与文字配色，或图钉清单的配色，可分别改本体及文字。Windows保存可选配色，旧Mac版本重存作品可能移除此字段。

开启图钉清单时先显示新增字段并聚焦名称，下面才是搜寻与既有图钉。清单使用与画布相同的图钉绘制及各自本体／文字颜色，方便依外观找到位置。

19屏幕画布

首页侧栏、屏幕图示、更多工具或Ctrl+Alt+A启动，先存作品後隐藏主窗口；即时桌面上为独立透明注记层。握把拖四边停靠，仅图示模式不显示卷轴，工作区不足换行／换列；图文分页模式维持单行／单列并用箭头换组，清空与关闭保持可见。色圆、图层与调色盘有入口；图形填色请从「图形」选单设定，橡皮擦／雷射再点开设定。 屏幕画布支援的共用工具沿用一般工具列的显示设定与顺序；不提供图钉与视角锁定。「图形」选单包含相同的九种图形。 使用钢笔画出近似直线并停住一秒，预览会吸附成直线；移动超过12 pt会恢复自由笔迹。

作画／操作或Ctrl+Alt+D切换注记与下层App操作。物件右键改样式、复制、副本、删除、锁定与层级，已多选物件保持整组；空白右键只取消未完成手势。Shift点击／拖框追加，左右框选依包含／碰到规则；套索可圈选相交物件；可移动、缩放、旋转、调端点，Shift限制线段／箭头水平或垂直。

T後点位置输入，Enter换行、Ctrl+Enter／完成提交、Esc取消；双击文字或更多→选择物件→编辑文字。换工具／操作模式、截图、另存、结束前提交草稿。样式只修改未锁定物件与有更动的字段，连续滑杆调整可一次Undo。

截图或Ctrl+Alt+S将含注记区域成为原屏幕位置图片，不另存截图文件夹。更多→另存注记导出透明PNG或.heiban，更多→保存注记手动保存。×或Ctrl+Alt+Q保存独立注记并恢复主窗口，下次可继续；垃圾桶或Ctrl+Alt+K直接清空，可Undo。快捷键被占用时用工具列；屏幕注记不自动合并到主作品。

20保存、数据与导出

首页设定或更多→设定控制自动存档，默认关闭，成功保存後沿用。开启时一般约15秒、屏幕修改停止约1秒保存，手势未完延後；关闭停止定期作品保存。Ctrl+S手动存一般作品，屏幕更多→保存注记手动存。

回首页、切作品／屏幕与正常退出都保存并等待，显示旋转进度；保存失败保持窗口与内容。关闭自动存档後，当机、断电或强制结束可能遗失未保存变更。

导出先选目前页全部内容、选择物件或视野，再选.heiban、JSON、PNG、SVG、PDF、HTML。原稿／JSON保留所有页；图片与阅读格式依范围。PNG用画布renderer，SVG含向量／图片且富文字foreignObject需阅读器支援，PDF需Edge WebView2并附原稿，HTML可离线且含JSON。

安装版数据在%LOCALAPPDATA%\HeiBan\Windows\，Portable在程序旁Data/，Store使用自身App数据位置。迁移前正常关闭并备份完整文件夹，包括作品、垃圾桶及设定；Portable保留整个文件夹，不从ZIP内启动。

首页「导入」可选 PDF、PPTX 或 PPT。每页转为一张锁定背景图片并建立笔记页面，可在上方注记。可选起讫页，一次最多 200 页、图片总量最多 100 MB；取消不建立半份作品。原文字与形状不会转成可编辑元素。

PPT/PPTX 需要本机桌面版 PowerPoint；没有时请先转为 PDF。缺少字型可能改变版面，动画、影片、转场与互动不会保留；加密或损坏档案可能无法转换。导出 PDF 时，选「目前页面／全部内容」并勾选「PDF 导出全部页面」即可输出整本笔记；选择物件或目前视野则依该范围输出。

21快捷键速查

Ctrl+S保存；Ctrl+N新增；Ctrl+Z／Ctrl+Y撤销／重做；Ctrl+C／Ctrl+V复制选择／贴物件或图片；Delete删选择；Esc取消手势、截图与未完成形状。

空白键+拖曳／中键拖曳平移；滚轮／Ctrl+滚轮缩放；V／P／E／T选择／画笔／橡皮擦／文字；Win+Shift+S後Ctrl+V剪取粘贴。屏幕快捷键均加Ctrl+Alt：A启动、D作画／操作、S截图、K清空、Q结束；其他App占用时用工具列。

撤销与重做逐步还原／重新应用操作；清除本页会先要求确认，清除目前页物件，可撤销，其他页不受影响。选择後Delete只删除选择物件。

22程序更新

GitHub版首页→关於→更新设定，或更多→检查更新与更新设定。启动约10秒後背景检查，使用期间每6小时检查，可关闭自动更新／预览或手动检查，只在程序开启时执行；此项与自动存档分开。

下载选正确架构与安装类型，核大小／SHA-256。保存成功且同一安装全部窗口关闭後由独立更新程序安装，下次启动使用，不强制退出或重开。离线、中断、占用档案保留目前版待重试；关闭自动更新後已暂存包也不自动应用。

Portable保留Data、portable.dat与未知档，安装版沿用数据位置；更新有备份，暂存与结果在%LOCALAPPDATA%\HeiBan\Updates\，不传作品。安装期间不要拔碟或断电。Store由商店更新，不替换GitHub档；杂凑不等於Authenticode签章，首次可能有Windows提示。旧版本需先手动升级一次才能取得更新器。

Windows 1.0.16 已获使用者同意制作 Microsoft Store 更新套件。实际上架依商店认证与发布结果；各装置相容性与已知限制请参阅开发纪录。

云端／Google同步、协作、专用心智图、表格、公式、画框及外部PDF／SVG原稿编辑尚未交付。文件未知JSON字段保留；.heiban使用者文字维持原语言，介面切换不翻译作品。

24背景设定操作要点

新增先选格式，再选适用尺寸与背景；无边界不需尺寸，有边界先16:9仍可改。空白、横线、点、方格与五线谱可新增时或之後从画布背景选择。

既有作品应用才提交、取消保留，可Undo；改背景只改纸面，不会改已有笔画与文字颜色。

25图层顺序与操作回馈

工具列或更多开物件图层，上层列在前。按图示左灰色双杠拖到另一列上半／下半，放开插其上／下；原列淡化、图示名称跟随、绿线指示位置。改名不改物件身份，空白名称恢复自动命名。

隐藏物件保留在面板，锁定防批次移动／删除，属性与图层为不同面板。方向／旋转游标、已存／待存图示、多选勾圈与橡皮擦范围表示目前动作；试用遇到异常请回报後再核准正式更新。
