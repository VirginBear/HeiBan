01介面與手冊語言

首頁側欄下方「語言」（收合時為文/A圖示）提供正體中文（預設）、簡體中文、英文、日文、韓文、西班牙文、法文、德文、葡萄牙文（巴西）、阿拉伯文。保存成功立即套用，下次啟動沿用。既有作品名稱與文字不翻譯，新建的預設名稱採當時語言。

使用說明隨目前介面語言開啟；本頁語言選單只切換手冊，不改程式偏好。全部手冊、章節與搜尋均可離線使用。阿拉伯文介面與手冊從右向左閱讀，畫布座標不鏡像。系統選檔與原始錯誤訊息可能使用其他語言，部分內建控制項可能需重新啟動。

02開始使用

首頁按＋新增，選筆記本、無邊界畫布或有邊界黑板，輸入名稱並設定背景色與樣式。畫筆用來手寫，選取工具（V）用來移動及調整物件。

自動存檔預設關閉。Ctrl+S可手動保存，離開作品或正常退出也會保存。匯出.heiban可作為可編輯備份。

03首頁與作品庫

單擊卡片只反白，不顯示批次操作列；雙擊或右鍵「開啟作品」進入。右鍵亦可收藏、改名、副本與移到垃圾桶。垃圾桶保留原稿，雙擊垃圾桶卡片可還原。

按匯入旁虛線圓進入多選，圓圈打勾表示已選；可全選目前結果或逐張選取，再移到垃圾桶，「完成」離開多選。可搜尋名稱、篩選格式、依修改／建立／名稱排序及選160／190／250 pt縮圖。匯入支援.heiban／.blackboard.json；側欄切換全部、收藏與垃圾桶。 工具列預設為「圖示與文字」，常用分頁預先包含筆刷與線條樣式；可在自訂工具列調整。首次使用會加入「操作說明 · 全工具指南」無邊界筆記，涵蓋全部工具及可編輯範例。用中鍵拖曳／空白鍵加拖曳平移，滾輪縮放，開圖釘清單可跳到各章。舊範例與已編輯作品不會被覆寫；修改或刪除新指南後不會每次重建。

04畫布格式與頁面

筆記本各頁獨立，底部頁碼與左右箭頭翻頁，＋新增頁；頁碼選單可跳頁、改名、副本、排序及刪頁。無邊界畫布可向任意方向延伸。有邊界黑板提供固定紙張邊界，適合簡報與排版。

無邊界不顯示尺寸。新有邊界黑板首次預設16:9簡報（1920×1080），仍可改A4直向、A4橫向或1:1；切換格式記住此對話框已選尺寸。新增與畫布背景提供空白、橫線、點狀、方格、五線譜及底色；既有作品按套用才修改，取消保留，修改可單步復原。

05平移、縮放與視角鎖定

滾輪以滑鼠位置縮放，Ctrl+滾輪亦同；水平滾輪平移，中鍵拖曳或空白鍵加左鍵拖曳平移。閱讀模式左鍵拖曳平移；倍率控制提供預設比例、適合內容及重設視角。

視角鎖定停止平移與滾輪縮放，避免講解誤移。工具列與角落的鎖定指示同步變化，解鎖後可再次移動視野。 按住中鍵平移時，游標會顯示握住畫布的手形；放開恢復原游標。

06導覽與工具列

上方導覽包含首頁、閱讀／編輯、圖釘、＋插入、更多、存檔狀態及固定開關；未固定時滑鼠離開會收合。勾號表示已存，虛線圓表示待存、儲存中或尚未完成。

拖工具列握把到四邊，上下橫排、左右直排。更多→自訂工具列可顯示、隱藏與排序，隱藏的項目仍在更多工具。「物件圖層」有工具列入口與獨立面板；螢幕工具列不顯示捲軸。

首頁設定或「更多 → 自訂工具列」可選只有圖示，或圖示與文字分頁。圖文模式分成常用、繪圖、插入、管理；選取（V）固定常駐。工具只排一行／一列，空間不足用兩端箭頭切換工具組，不增加工具排數。自訂視窗左側勾選顯示，另勾「常用」挑選常用分頁；仍可全選、預設及排序。所有應用程式內面板與對話框固定使用黑板的紙白／綠色設計，不隨 Windows 亮暗主題切換；系統檔案挑選器由 Windows 管理。

工具列預設為「圖示與文字」，常用分頁預先包含筆刷與線條樣式；可在自訂工具列調整。首次使用會加入「操作說明 · 全工具指南」無邊界筆記，涵蓋全部工具及可編輯範例。用中鍵拖曳／空白鍵加拖曳平移，滾輪縮放，開圖釘清單可跳到各章。舊範例與已編輯作品不會被覆寫；修改或刪除新指南後不會每次重建。 「清除本頁」預設收在常用；更新時只追加這一項，保留其他自訂常用。一般畫布與螢幕畫布的圖形選單使用相同描邊圖示與九宮格。 選取與雷射固定顯示於所有分頁外，雷射預設納入常用但不重複一顆按鈕；再次點雷射開啟設定。

07畫筆與筆刷

選擇鋼筆、螢光筆或繪圖工具，再點「筆刷」調整顏色、粗細與透明度。先在色輪調色，再按常用色的＋保存；點色票套用，管理或右鍵可移除，還原預設色可重設。色票可全部刪除，重開仍保留；一般與螢幕畫布共用此色盤。只有目前選用的繪圖工具會在圖示下方顯示下一筆描邊色的色線；筆刷面板使用單一捲動區。沒有材質效果的筆刷類型選單已移除，舊作品仍保留原欄位。

向量筆近似直線，保持按住且停一秒可吸附直線，移動超過12 pt恢復原預覽；放開才提交一筆可復原操作。更多工具的遮題膠帶可遮住題目，雙擊或物件設定揭示／遮住，支援復原。 鋼筆、螢光筆及油漆筆刷完成後不會自動選取或顯示框線；按V再點選物件可移動、縮放或旋轉，雙擊才開詳細屬性。板擦保留左高右低，長邊縮短20%，厚度不變。

08線段、箭頭、形狀與曲線

線段／箭頭拖曳或先點A再點B建立，線身整體移動、兩端獨立調整。屬性可選線段、向A／B或雙向延伸而不改原端點；箭頭頭部長寬獨立，線條粗細也調整頭部輪廓。

矩形、圓、菱形、五角與星形拖曳建立；三角／四邊形逐點，曲線三點：第一點預覽、第二點固定彎曲、第三點提交。選取可調頂點／控制點，Esc取消未完成幾何。色圓與屬性調整適用的線色、填色、漸層與透明度。

完成後保留原繪圖工具，三角／四邊形逐頂點預覽直線，曲線才預覽曲線。圓、菱形、五角與星形從中心開始拖曳，矩形從角開始。磁鐵從第一個點就作用，靠近約 10 個畫面 DIP 時顯示綠圈並吸附；矩形有四角、四邊中點及中心共九點；三角形有三頂點與三邊中點；其他多邊形也含各邊中點，直線／箭頭有端點與中點。圓與圓規圓弧含中心及上下左右點，圓弧另含起訖點。隱藏物件不參與，鎖定形狀仍能參考，原物件不會被移動。 磁鐵只吸附幾何工具的建構點與圓規定位；畫筆、螢光筆、油漆筆保留原始手繪軌跡，跨越舊筆跡不吸附。一般畫布與螢幕畫布一致；尺規投影及停筆一秒直線辨識仍依各自規則作用。

09選取與物件變形

V選取，Ctrl+點擊增減物件，套索沿範圍選取。空白處拖框左往右為藍實線，只選完全包含；右往左綠虛線，選碰到的物件；Ctrl／Shift拖框追加。多選可整組移動、複製、貼上、改樣式與刪除。

單一形狀有八方向縮放与旋轉把手，游標顯示相對應方向或旋轉箭頭；線段／箭頭為A、B，圓弧有起訖角。圖片角落預設等比，Shift自由縮放；旋轉Shift吸附15°。鎖定物件不參與批次移動／刪除，隱藏物件仍留在圖層。

建立物件或單擊選取時，只顯示大小、旋轉、端點等控制點，不自動彈出詳細調整列。雙擊物件才開啟詳細屬性；雙擊文字進入文字編輯。選取工具可隨時切換回繪圖，繪圖工具不會在每一筆結束後切回 V。

10屬性、色彩與樣式

屬性面板只顯示所選物件適用項目，可調線色、粗細、適用的填色／漸層／透明度、文字與幾何數值。實線、虛線、點線、點劃線提供樣本，工具列顯示目前樣式；可先設繪圖偏好，修改選取物件也更新後續繪圖設定。

按停靠或拖標題到四邊，左右直排、上下橫排。圖層、橡皮擦與尺規有各自入口，避免混入不相關物件屬性。延伸直線及箭頭頭部長寬在對應屬性中。

11文字與便條紙

T或便條紙工具後點畫布輸入，Enter換行，Ctrl+Enter或離開完成，Esc取消，組字不觸發工具快捷鍵。色圓提供字型、粗體、斜體、底線、刪除線及對齊；便條紙有折角、紙膠帶、貓咪、筆記本、方格及柔和款。

編輯局部文字格式視窗中先選文字再改格式、文字色或標記色，保存為一筆Undo。文字或草稿右鍵可調整整框樣式；更多文字設定只套用修改欄位到本頁未鎖定文字／便條紙，略過其他物件。螢幕文字支援8–144 pt、自訂#RRGGBB、字型、對齊與透明度。

12橡皮擦

選橡皮擦，再點目前工具開設定，選物件擦除／局部筆跡擦除及直徑；一般與螢幕畫布均以半透明圓顯示範圍。

物件擦除整筆移除碰到的筆畫或幾何；局部擦除只移除劃過的筆跡段。文字、便條紙及圖片受到保護，刪除請選取後按Delete。

一般畫布右下角有原創紙白／霧綠俯視磁吸板擦，按住拖曳依斜放的圓角擦面輪廓擦除，放開回到停靠處並提交一筆可復原操作；Esc 或失去捕捉會取消整次擦拭。右鍵板擦選物件或局部筆跡模式，也可隱藏；首頁設定→顯示板擦可重新開啟。擦面以畫面大小顯示，隨縮放換算到作品座標。局部／像素模式只切斷筆跡，不修改圖片像素或原始 PDF／簡報元素；螢幕畫布仍使用工具列的圓形橡皮擦。工具列「更多→顯示板擦」可隨時切換顯示並記住選擇；板擦呈左高右低，抓取與擦除輪廓同步鏡像。 圓形橡皮擦可連續拖曳；擦除預覽逐步更新，放開滑鼠完成本次擦除並合成一筆復原操作。Esc或指標捕捉中斷會取消尚未完成的擦除。正常儲存或退出會等待已放開的擦除完成。

13尺規

啟用尺，拖尺身移動，拖端點旋轉；金色支點可移到上下劃線邊或兩端，旋轉固定該支點。右鍵尺或尺設定可調邊、0–100%支點位置、0.1°角度、透明度及長度。

尺長為畫布寬度20–150%，預設90%，隨視窗大小調整。畫筆在尺緣起筆即鎖定該邊，整筆保持直線，超出尺長仍沿同軸延伸。

14圓規：準備、鎖定、畫弧

準備時拖圓心、半徑與筆尖調位置、半徑和起角，不产生物件。點圓心變亮橘色，鎖定圓心與半徑。

拖筆尖沿圓周預覽有向弧線，跨0°連續計算；放開生成一個可編輯圓弧及一筆Undo。靜止點擊不產生無效物件；完成弧可等比縮放、旋轉與調起訖角。

15雷射筆

工具列或更多工具選雷射，再點目前雷射開設定：光點、短尾跡或線條、顏色、直徑、粗細、消退時間與白色光芯。螢幕畫布同樣提供設定。

雷射是暫態引導，不寫入永久物件，不增加Undo操作。 尾跡使用平滑連續輪廓、漸細尾端及柔光；光點約0.3秒消退，短尾跡限制在0.2–0.8秒，線條依設定時間消退。離開畫布會中斷尾跡，不連接下次進入的位置。

16計算機與計時器

上方＋開計算機或計時器，拖標題移動或收合。計算機提供括號、科學函數、π、e、Ans與鍵盤／Enter，按插入算式才新增文字物件。

計時器有碼表、5／15／25分鐘倒數及自訂秒數；關閉面板仍計時，到時通知，重新開啟保留目前狀態。

17圖片、截圖與裁切

＋或工具列選截圖後框選區域，Esc／右鍵取消；切作品／頁面與逾時也取消。結果依原比例置入目前視野中心，不另存截圖資料夾。Win+Shift+S圖片可用Ctrl+V貼上。

可從檔案總管拖PNG／JPG／BMP到畫布，移動、缩放、旋轉。選圖片後色圓內裁切圖片／恢復原圖，以原圖像素範圍裁切並保留來源。內建截圖只使用此次結果，不讀無關剪貼簿圖。

18圖釘與配色

上方圖釘儲存目前視野中心與倍率，點清單返回該視角。雙擊圖釘或名稱改名，Enter／點其他處保存、Esc取消；名稱右鍵也可改名，支援Undo。

右鍵圖釘的圖釘與文字配色，或圖釘清單的配色，可分別改本體及文字。Windows保存可選配色，舊Mac版本重存作品可能移除此欄位。

開啟圖釘清單時先顯示新增欄位並聚焦名稱，下面才是搜尋與既有圖釘。清單使用與畫布相同的圖釘繪製及各自本體／文字顏色，方便依外觀找到位置。

19螢幕畫布

首頁側欄、螢幕圖示、更多工具或Ctrl+Alt+A啟動，先存作品後隱藏主視窗；即時桌面上為獨立透明註記層。握把拖四邊停靠，僅圖示模式不顯示捲軸，工作區不足換行／換列；圖文分頁模式維持單行／單列並用箭頭換組，清空與關閉保持可見。色圓、圖層與調色盤有入口；圖形填色請從「圖形」選單設定，橡皮擦／雷射再點開設定。 螢幕畫布支援的共用工具沿用一般工具列的顯示設定與順序；不提供圖釘與視角鎖定。「圖形」選單包含相同的九種圖形。 使用鋼筆畫出近似直線並停住一秒，預覽會吸附成直線；移動超過12 pt會恢復自由筆跡。

作畫／操作或Ctrl+Alt+D切換註記與下層App操作。物件右鍵改樣式、複製、副本、刪除、鎖定與層級，已多選物件保持整組；空白右鍵只取消未完成手勢。Shift點擊／拖框追加，左右框選依包含／碰到規則；套索可圈選相交物件；可移動、縮放、旋轉、調端點，Shift限制線段／箭頭水平或垂直。

T後點位置輸入，Enter換行、Ctrl+Enter／完成提交、Esc取消；雙擊文字或更多→選取物件→編輯文字。換工具／操作模式、截圖、另存、結束前提交草稿。樣式只修改未鎖定物件與有更動的欄位，連續滑桿調整可一次Undo。

截圖或Ctrl+Alt+S將含註記區域成為原螢幕位置圖片，不另存截圖資料夾。更多→另存註記匯出透明PNG或.heiban，更多→儲存註記手動保存。×或Ctrl+Alt+Q保存獨立註記並恢復主視窗，下次可繼續；垃圾桶或Ctrl+Alt+K直接清空，可Undo。快捷鍵被占用時用工具列；螢幕註記不自動合併到主作品。

20保存、資料與匯出

首頁設定或更多→設定控制自動存檔，預設關閉，成功保存後沿用。開啟時一般約15秒、螢幕修改停止約1秒保存，手勢未完延後；關閉停止定期作品保存。Ctrl+S手動存一般作品，螢幕更多→儲存註記手動存。

回首頁、切作品／螢幕與正常退出都保存並等待，顯示旋轉進度；保存失敗保持視窗與內容。關閉自動存檔後，當機、斷電或強制結束可能遺失未保存變更。

匯出先選目前頁全部內容、選取物件或視野，再選.heiban、JSON、PNG、SVG、PDF、HTML。原稿／JSON保留所有頁；圖片與閱讀格式依範圍。PNG用畫布renderer，SVG含向量／圖片且富文字foreignObject需閱讀器支援，PDF需Edge WebView2並附原稿，HTML可離線且含JSON。

安裝版資料在%LOCALAPPDATA%\HeiBan\Windows\，Portable在程式旁Data/，Store使用自身App資料位置。遷移前正常關閉並備份完整資料夾，包括作品、垃圾桶及設定；Portable保留整個資料夾，不從ZIP內啟動。

首頁「匯入」可選 PDF、PPTX 或 PPT。每頁轉為一張鎖定背景圖片並建立筆記頁面，可在上方註記。可選起訖頁，一次最多 200 頁、圖片總量最多 100 MB；取消不建立半份作品。原文字與形狀不會轉成可編輯元素。

PPT/PPTX 需要本機桌面版 PowerPoint；沒有時請先轉為 PDF。缺少字型可能改變版面，動畫、影片、轉場與互動不會保留；加密或損壞檔案可能無法轉換。匯出 PDF 時，選「目前頁面／全部內容」並勾選「PDF 匯出全部頁面」即可輸出整本筆記；選取物件或目前視野則依該範圍輸出。

21快捷鍵速查

Ctrl+S保存；Ctrl+N新增；Ctrl+Z／Ctrl+Y復原／重做；Ctrl+C／Ctrl+V複製選取／貼物件或圖片；Delete刪選取；Esc取消手勢、截圖與未完成形狀。

空白鍵+拖曳／中鍵拖曳平移；滾輪／Ctrl+滾輪縮放；V／P／E／T選取／畫筆／橡皮擦／文字；Win+Shift+S後Ctrl+V剪取貼上。螢幕快捷鍵均加Ctrl+Alt：A啟動、D作畫／操作、S截圖、K清空、Q結束；其他App占用時用工具列。

復原與重做逐步還原／重新套用操作；清除本頁會先要求確認，清除目前頁物件，可復原，其他頁不受影響。選取後Delete只刪除選取物件。

22程式更新

GitHub版首頁→關於→更新設定，或更多→檢查更新與更新設定。啟動約10秒後背景檢查，使用期間每6小時檢查，可關閉自動更新／預覽或手動檢查，只在程式開啟時執行；此項與自動存檔分開。

下載選正確架構與安裝類型，核大小／SHA-256。保存成功且同一安裝全部視窗關閉後由獨立更新程式安裝，下次啟動使用，不強制退出或重開。離線、中斷、占用檔案保留目前版待重試；關閉自動更新後已暫存包也不自動套用。

Portable保留Data、portable.dat與未知檔，安裝版沿用資料位置；更新有備份，暫存與結果在%LOCALAPPDATA%\HeiBan\Updates\，不傳作品。安裝期間不要拔碟或斷電。Store由商店更新，不替換GitHub檔；雜湊不等於Authenticode簽章，首次可能有Windows提示。舊版本需先手動升級一次才能取得更新器。

雲端／Google同步、協作、專用心智圖、表格、公式、畫框及外部PDF／SVG原稿編輯尚未交付。文件未知JSON欄位保留；.heiban使用者文字維持原語言，介面切換不翻譯作品。

24背景設定操作要點

新增先選格式，再選適用尺寸與背景；無邊界不需尺寸，有邊界先16:9仍可改。空白、橫線、點、方格與五線譜可新增時或之後從畫布背景選取。

既有作品套用才提交、取消保留，可Undo；改背景只改紙面，不會改已有筆畫與文字顏色。

25圖層順序與操作回饋

工具列或更多開物件圖層，上層列在前。按圖示左灰色雙槓拖到另一列上半／下半，放開插其上／下；原列淡化、圖示名稱跟隨、綠線指示位置。改名不改物件身份，空白名稱恢復自動命名。

隱藏物件保留在面板，鎖定防批次移動／刪除，屬性與圖層為不同面板。方向／旋轉游標、已存／待存圖示、多選勾圈与橡皮擦範圍表示目前動作；試用遇到異常請回報後再核准正式更新。
