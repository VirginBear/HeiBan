介面語言

首頁左下「語言」可選正體中文（預設）、簡體中文、英文、日文、韓文、西班牙文、法文、德文、葡萄牙文（巴西）、阿拉伯文；側欄收起時點文/A圖示。回到首頁再更改語言；儲存成功立即套用，下次啟動沿用。作品名稱與文字不會被翻譯，新建作品的預設名稱採當時語言。

本手冊維持正體中文。阿拉伯文的選單／對話文字由右向左閱讀，畫布座標不鏡像。系統選檔及原始錯誤訊息仍採來源語言，部分WinUI內建文字可能需重啟才更新。

HEIBAN · WRITE / DRAW / EXPLAIN

讓想法，在 Windows 上清晰流動。

從一頁手寫筆記，到整座螢幕上的即時講解。
原生 WinUI 3 與 Win2D Direct2D 加速，為教學與思考量身打造。

離線手冊21 個章節繁體中文Windows 原生無網路可用

沒有符合的章節，請輸入其他關鍵字。

01開始使用

先有一張紙，再讓想法延伸。

  1. 在首頁點選「＋ 新增」，選擇「筆記本」、「無邊界畫布」或「有邊界黑板」。
  2. 輸入作品名稱；畫布底色與格線可在建立時選定，亦可在編輯中隨時更改。
  3. 點選畫筆開始手寫書寫；需要移動或調整形狀時切換到選取工具（V）。
  4. 作品變更會自動儲存於本機；需要分享或備份時，可匯出為標準 .heiban 檔案。
本離線手冊隨程式內建，無需網路連線即可隨時查閱。手冊本身不會向您的作品庫自動生成測試或範例黑板。

單擊卡片只反白，不顯示批次操作列；雙擊或右鍵「開啟作品」進入。按匯入左邊的虛線圓進入多選並逐一勾選，選好後按「移到垃圾桶」批次刪除。垃圾桶保留原稿，可還原。

02首頁與作品庫

用真實內容縮圖直覺辨識作品。

首頁作品卡片即時顯示畫布內容縮圖，並標註筆記本、無邊界畫布或有邊界黑板之格式徽章。雙擊卡片開啟；右鍵可開啟作品、收藏、重新命名、製作副本或移到垃圾桶。

  • 搜尋與篩選：在上方搜尋列即時輸入關鍵字搜尋作品名稱。
  • 開啟文件：點選上方「開啟文件」可直接載入外部 .heiban 或 .blackboard.json 專案。
  • 垃圾桶：可還原誤刪作品，保留原稿資料。
  • 免安裝版：若使用免安裝 Portable 版本，作品與快取資料均獨立存於程式旁的 Data/ 資料夾內。

作品庫左側可切換所有作品、收藏與垃圾桶；側欄可收合。上方提供搜尋、格式篩選、最近修改／建立日期／名稱排序，以及160／190／250 pt縮圖。卡片星號切換收藏，⋯開啟改名、副本與移到垃圾桶；垃圾桶內雙擊作品還原。選取多份作品後，可全選目前結果並移到垃圾桶。

03三種畫布與背景

選擇最適合思考與表達的畫布範圍。

格式適用情境特色與操作
筆記本課堂筆記、會議記錄、多頁教材底部提供頁碼導航、‹ › 翻頁與「＋頁」按鈕；各頁內容獨立維護；點頁碼選單可跳頁、改名、複製、排序與刪頁
無邊界畫布心智圖、架構草圖、自由發想無邊界空間，可朝任意方向平移與無限延伸
有邊界黑板簡報、考卷講解、固定尺寸排版固定紙張邊界（如 A4、16:9），呈現嚴謹板書

右上導覽膠囊「⋯ 更多 → 畫布背景」可隨時切換黑板綠、深色黑、純白板與暖白底色，並支援無格線、橫線條與點陣網格。

04移動畫布與縮放

畫布平移與縮放分開操作。

  • 滑鼠滾輪直接以鼠標位置縮放（Ctrl＋滾輪亦同）；水平滾輪平移；中鍵拖曳或空白鍵＋左鍵拖曳平移。
  • 閱讀模式使用左鍵拖曳平移。右下倍率提供縮放、預設比例、適合內容與重設視角。
  • 更多工具的「視角鎖定」停止平移與滾輪縮放，避免講解時意外更動畫面。

05右上導覽與工具列

浮動膠囊與自由停靠工具列，兼顧沉浸與效率。

右上精簡浮動導覽膠囊：集合了「回到首頁」、「閱讀/編輯切換」、「圖釘導航」、「＋ 插入選單」、「⋯ 更多設定」、「儲存狀態燈號」與「固定開關」。預設滑鼠移入時顯示、移開後自動收合；點擊「固定」可常駐顯示。

主工具列停靠：拖曳工具列前端的抓手（⋮⋮），可自由停靠至視窗上、下、左、右四邊；靠上下自動轉為橫向，靠左右自動轉為直向。

自訂工具列：從「⋯ 更多 → 自訂工具列」可自由勾選常用工具與調整上下順序，隱藏的工具仍可由「更多工具」選單快速呼叫。

06畫筆與筆刷

平滑向量筆跡與個別工具偏好。

點畫筆，再點顏色圓鈕調整色輪、粗細、透明度與筆刷種類：向量筆、鋼筆、鉛筆、水彩、螢光筆、蠟筆、書法、油漆。種類與偏好會保存；目前與 Mac 1.0.12 相同，筆跡以平滑向量線條渲染，尚未提供各材質的物理模擬。每一道筆劃均可事後移動及改色。

更多工具有遮題膠帶：拖曳遮住題目，雙擊揭示／遮住，亦可由選取物件的設定切換；揭示可復原。

07圖形、曲線與頂點

直線以真正的 A、B 端點編輯。

  • 直線與箭頭可先點 A 再點 B，也可拖曳建立；完成切回選取。各端獨立拉動，線身可整體移動。
  • 設定可選線段、向 A／B 延伸、雙向延伸，延伸不改原端點。
  • 矩形、圓形、菱形、五角形與星形拖曳建立；三角形／四邊形逐點建立，曲線三點建立：第一點後跟隨鼠標即時預覽；第二點固定彎曲位置，第三點確認，一次復原。選取可編輯頂點／控制點。
  • Esc 取消尚未完成的幾何；顏色圓鈕及屬性檢查器調整線色、填色、漸層與透明度。

選取工具從空白處拖框：左往右藍色實線框只選完全包含的物件；右往左綠色虛線框選所有碰到的物件。Ctrl／Shift 拖框追加選取，放開後才確定範圍。

08選取、物件與圖層

圖層以內容命名，保留物件身份。

  • 選取工具（V）點物件；空白處拖曳框選。Ctrl＋點擊增減選取，套索工具沿範圍圈選。多選後可整批移動、複製、貼上、改樣式及刪除。
  • 單一物件提供八向縮放及旋轉把手；直線／箭頭以 A、B 把手調整，圓弧有起訖角把手。圖片角落預設等比縮放，Shift 可自由調整；旋轉時 Shift 吸附 15°。
  • 右側圖層列顯示「圓形 1」「圖片 2」或文字摘要；重新命名保存自訂名稱，留白恢復自動命名。選取、排序、鎖定與隱藏不依名稱尋找物件。
  • 圖層可多選；鎖定物件不會被批次移動或刪除。隱藏物件仍留在圖層列，可再次顯示。鎖定／刪除／層級亦可由右鍵與選取操作列使用。

09色彩、填色與線條

屬性檢查器提供最全面的外觀調整。

點選畫布右側的屬性檢查器書籤，可展開完整設定面板：

  • 線條色彩與粗細：即時變更已選物件的邊線外觀。
  • 填色與透明度：可設定實色填滿，並獨立調整填色透明度。
  • 線條樣式：實線、虛線、點線、點劃線直接呈現線段樣本；工具列按鈕顯示目前樣式。可先選顏色與線條，再切換畫筆或圖形開始繪製。選取物件時修改其外觀，修改的顏色／線條亦作為後續繪圖設定。
  • 精確數值輸入：支援旋轉角度（精確至 0.1°）、字體大小與橡皮擦直徑數值微調。

10文字與便條紙

繁體中文輸入與局部文字格式。

文字（T）／便條紙在畫布點擊後直接輸入；中文組字不觸發工具快捷鍵。Ctrl＋Enter 或離開完成，Esc 取消。選取後從顏色圓鈕設定字型、粗體、斜體、底線、刪除線及對齊。

「編輯局部文字格式」開啟文字編輯視窗，先選文字再套用格式、文字色或標記色，儲存後成為一筆可復原交易。便條紙提供經典、紙膠帶、貓咪、筆記本、方格及柔和風格。

文字框右鍵可批次調整大小、顏色、粗體、斜體與底線；更多文字設定只套用修改欄位，跳過本頁鎖定物件及非文字物件。草稿輸入時亦可右鍵調整整框樣式；Enter 換行、Ctrl＋Enter 完成、Esc 取消。

11橡皮擦

物件擦除與局部筆跡擦除雙模式。

  1. 點選橡皮擦工具；再次點擊可切換「物件擦除」或「局部筆跡擦除」並調整直徑。
  2. 畫布上會呈現半透明圓形擦除預覽圈。
  3. 物件擦除：碰觸到線條或幾何時直接整筆移除該物件。
  4. 局部筆跡擦除：只擦除滑鼠劃過的局部筆劃段落。
  5. 文字、便條紙與圖片受到保護，不會被橡皮擦誤擦；如需刪除請選取後按 Delete。

12尺規

支點可移到真正劃線兩端。

  1. 尺規工具啟用，拖尺身移動；拖兩端旋轉把手調角。
  2. 金色旋轉支點可移到上／下劃線邊及最左／最右端；旋轉固定該支點。右鍵精確設定邊、0–100% 支點位置、0.1° 角度、畫布寬度 20–150% 尺長與透明度。
  3. 畫筆起筆靠近尺緣時鎖定該邊，整筆保持直線吸附，超出尺長仍沿同軸延伸。

13圓規：準備 → 鎖定 → 畫弧

兩階段幾何作畫：點擊圓心變色鎖定，拖曳筆尖精確畫弧。

1準備階段

拖曳圓心移動位置，拖曳半徑把手調整半徑 R，拖曳筆尖把手調整起角。此階段純屬輔助導引，不產生物件。

2鎖定圓心

點擊圓心，圓心切換為亮橘色，中心與半徑鎖定，筆尖進入作畫待命狀態。

3筆尖畫弧

拖曳筆尖沿圓周旋轉，即時預覽有向掃角弧線；跨越 0° 連續計算不跳躍；放開時提交單步 Undo 交易生成精確 arc 物件！

生成的圓弧物件支援 8 向等比縮放、旋轉以及「起」「訖」專屬端點把手微調；靜止點擊放開不會生成無效物件。

14雷射筆

暫態引導，不寫入作品。

從更多工具選雷射；點顏色圓鈕設定光點、短尾跡或線條，以及顏色、直徑、粗細、消退時間與白色光芯。雷射不生成永久物件，不影響 Undo。透明螢幕畫布亦有雷射工具及設定。

15計算機與倒數計時

可拖移、收合的浮動面板。

從右上「＋」開啟計算機或計時器，拖標題移動，收合暫時讓出畫布。計算機支援括號、科學函數、π、e、Ans 與鍵盤／Enter，按「插入算式」才加入文字物件。

計時器提供碼表、5／15／25 分鐘倒數，以及自訂秒數。關閉面板仍持續計時，到時通知；重新開啟保留當前計時狀態。

16圖片與截圖置入

區域框選截圖直接置入畫布，隨拖隨放。

  • 截圖置入：點選右上＋選單或工具列「截圖」，拖曳框選螢幕區域，框外覆蓋灰霧，框內保留原始清晰影像；完成後直接將圖片物件以原始比例置入目前視野中心，不另存截圖資料夾。圖片可拖移、縮放與旋轉。外部 Windows 剪取工具（Win+Shift+S）的圖片則可手動 Ctrl+V 貼上。
  • 生命週期守護：非同步解碼期間全程維持逾時監控；按 Esc 或右鍵取消框選；切換文件／頁面與逾時會取消請求。截圖使用本次框選結果，不讀取其他軟體的剪貼簿圖片。
  • 拖曳匯入：直接從桌面或檔案總管將 PNG、JPG、BMP 圖片拖入黑板畫布，立即置入。
  • 圖片裁切：選取圖片，點顏色圓鈕的「裁切圖片／恢復原圖」，輸入原圖像素範圍，不破壞原始圖片。

17圖釘

在廣大畫布上快速標記關鍵視角。

點選右上導覽膠囊的圖釘圖示，可將當前視野中心與倍率儲存為原創斜向圖釘。點擊清單項目切換到該視角。雙擊畫布上的圖釘或名稱，可直接輸入新名稱；Enter／點開別處保存，Esc 取消，修改可復原。右鍵名稱也有改名入口。

18我的螢幕就是我的畫布

桌面保持即時運作，透明層用來講解。

  1. 首頁側欄的「螢幕畫布」、作品右上螢幕圖示，或更多工具可啟動；亦可按 Ctrl＋Alt＋A。原作品先保存，啟動後隱藏主視窗。
  2. 螢幕工具列與 Mac 1.0.12 同樣配置：上／下為 820×60 點單排，左／右為 64×688 點單欄純圖示。拖握把到四邊，放開後停靠；也可從更多選擇位置。模式、色圓、線條、填滿、清空與結束有固定入口，短螢幕只捲動中段；更多可收合工具區。點色圓開啟 280 點寬的顏色／粗細／透明度面板（3×2 色票、直排滑桿），橡皮擦／雷射再次點擊各自圖示開啟設定。狀態從模式提示、色圓面板及更多查看。
  3. 左側「作畫／操作」或 Ctrl＋Alt＋D 把滑鼠交給下方 App，再次切換回作畫；作畫時右鍵點物件開啟編輯選單，提供顏色／粗細／線條／填滿、複製、副本、個別刪除、鎖定與層級；命中已多選的物件會保留整組選取。空白處右鍵只取消未完成手勢，不切換「操作」。選取物件後也可從「更多 → 選取物件」使用相同命令。選取工具可拖移物件、調端點、縮放及旋轉。選取矩形等物件後，點色圓、線條或填滿按鈕即可修改已完成物件；多選會套用到未鎖定物件，滑桿連續調整可單步復原。直線／箭頭繪製及端點調整時按住 Shift，只允許水平或垂直。
  4. 點 T 再點螢幕位置輸入文字；Enter 換行，Ctrl＋Enter／完成提交，Esc 取消。選取工具雙擊文字或「更多 → 選取物件 → 編輯文字內容」可再修改。換工具、切穿透、截圖、另存或結束前會提交草稿。
  5. Shift 點選或拖框追加多個註記；框選左往右只選完全包含的物件，右往左選碰到的物件。曲線與畫筆支援先選顏色／線條再作畫；設定浮窗開啟時可直接點其他工具。選取物件的文字設定提供大小、顏色、粗體、斜體、底線。「更多文字設定」支援 8–144 pt、自訂 #RRGGBB、字體、對齊與不透明度，只套用你修改的欄位到本頁未鎖定文字／便簽，一次修改可單步復原。文字草稿的原生輸入區亦可右鍵設定，完成前不寫入文件。
  6. 「截圖」或 Ctrl＋Alt＋S 框選含註記的螢幕區域，結果直接留在螢幕畫布的原框選位置，成為「截圖」圖片物件；選取後可移動、縮放、旋轉、複製或刪除，不另存截圖資料夾。
  7. 「更多 → 另存註記」保存透明 PNG 或可編輯 .heiban。右側 × 或 Ctrl＋Alt＋Q 保存獨立註記並恢復主視窗；下次啟動可繼續。工具列垃圾桶或 Ctrl＋Alt＋K 一鍵清除全部螢幕物件，不多問一次；按復原可恢復。貼上已複製物件位於更多選單。
快捷鍵可能被其他程式占用，此時使用控制列。註記與截圖物件都保存在獨立螢幕畫布；不自動寫入主作品。多螢幕／混合 DPI／觸控筆仍待實機驗收。

19儲存、暫存與匯出

可編輯原稿與分享格式。

作品自動保存，Ctrl＋S 立即保存。匯出先選目前頁面全部內容、選取物件或目前視野，再選 .heiban、JSON、PNG、SVG、PDF 或 HTML。原稿／JSON 永遠保留所有頁面；圖像與閱讀格式按所選範圍匯出。

  • PNG 使用與畫布相同的 Win2D 渲染。SVG 保留向量及內嵌圖片；富文字使用 foreignObject，閱讀器需支援此元素。
  • PDF 保留中文字與向量，附帶相同原稿資料；需要 Windows Edge WebView2 runtime。此版本不提供外部 PDF／SVG 當原稿編輯。
  • HTML 可離線閱讀，Ctrl＋滾輪縮放，包含可編輯 JSON 原稿資料。
  • 安裝版：%LOCALAPPDATA%\HeiBan\Windows\；Portable：程式旁 Data/。升級前關閉程式並備份整個 Data，包含作品、垃圾桶與設定。

21自動更新

背景下載，正常關閉後安裝，下次啟動使用新版。

從首頁「關於黑板 → 更新設定」或畫布「更多 → 檢查更新與更新設定」開啟。GitHub 版預設啟用背景更新，啟動約十秒後檢查，其後使用期間每六小時檢查；可關閉自動更新或預覽版本，也可手動檢查。這些檢查只在黑板開啟時執行。

下載會選擇正確的 Windows 架構與安裝類型，驗證大小與 SHA-256。作品保存成功、同一份安裝的所有視窗關閉後，獨立更新程式才安裝；不強制關閉作品、不自動重開。離線、下載中斷或檔案被占用時保留目前版本，之後重試。關閉自動更新後，已暫存的更新也不會自動套用。

安裝版沿用原資料位置；免安裝版保留 Data、portable.dat 與未知檔案，只更新發行清單中的程式檔。更新程式會保留備份；遇到更新失敗可從官方下載手動修復。更新期間請勿拔除隨身碟或中斷電源。暫存及結果在 %LOCALAPPDATA%\HeiBan\Updates\；沒有上傳作品。

Microsoft Store 版由商店更新，不執行 GitHub 檔案替換。GitHub 發行檔的完整性驗證不等同 Windows Authenticode 簽章，首次安裝仍可能有系統提示。舊版須先手動安裝一次含此功能的版本。

22限制與後續規劃

版本與驗證範圍。

本版本 1.0.12-preview.6，以 Mac 1.0.12／20261010.4 可操作功能為基準。本批加入 Windows 自動更新；實際建置與更新驗證範圍見 Windows 開發紀錄。完整滑鼠、多螢幕、觸控筆與商店封裝仍待驗收。

雲端同步／Google、協作、心智圖、表格、公式、畫框與外部 PDF／SVG 編輯，在 Mac 基準亦未正式交付。本版本不宣稱這些功能完成。未知 JSON 欄位仍保留。

新增作品與畫布背景

首頁按＋新增作品：無邊界筆記不顯示尺寸；有邊界黑板首次切換預設16:9簡報（1920×1080），仍可選A4直向、A4橫向或1:1。切換格式會記住此對話框中各格式已選尺寸。

新增作品與右上方「畫布背景」（或更多導覽內背景入口）都可選空白、橫線條、點狀、方格子、五線譜及背景顏色。既有作品按套用才更新，取消保留原背景；修改可單步復原。一般畫布形狀控制點顯示對應方向的游標，八方向隨物件旋轉，旋轉點顯示圓弧箭頭。

232026-10-11 操作調整

作品庫：單擊只反白；雙擊或右鍵「開啟作品」進入。按匯入左邊的虛線圓進入多選；作品名稱旁的圓圈打勾表示選中，「完成」離開多選。

向量筆畫近似直線，保持按住並停一秒會吸附直線；移動超過 12 pt 可恢復原笔跡。放開才寫入作品，可用一次復原恢復。

尺：右鍵尺或工具列尺圖示開啟設定；尺長為畫布寬度 20–150%，預設 90%，會隨視窗大小調整。

屬性僅顯示所選物件適用項目。線段／箭頭的「延伸直線設定」在屬性中，箭頭另有頭部長度、寬度；調整線條粗細會同步頭部輪廓線寬，頭部長度／寬度仍獨立設定。便條紙可選經典折角、紙膠帶、貓咪、筆記本、方格、柔和款式。

屬性面板按「停靠」或拖曳標題到四邊：左右直排，上下橫排。工具列「物件圖層」或更多導覽的「圖層」開啟獨立物件圖層面板；上層在前，按住圖示左邊灰色雙槓拖到目標列的上半／下半並放開，可插入其上方／下方。拖曳中原列淡化，圖示與名稱預覽跟隨滑鼠，綠色插入線顯示放開後的位置。

圖釘：右鍵圖釘選「圖釘與文字配色」，或圖釘導覽清單按「配色」，分別設定本體及文字。配色目前由 Windows 保存；Mac 既有版本重存此作品可能移除這兩個可選欄位。

雷射：再次點擊目前雷射按鈕開啟設定。視角鎖定的上下工具按鈕同步切換；右上儲存指示勾號表示已存，虛線圓表示待存／正在儲存／儲存未完成。

螢幕畫布：圖層和調色盤都有工具列／更多選單入口。橡皮擦有半透明範圍圈；再次點橡皮擦開啟設定。工具列隨內容自適應、不顯示捲軸；工作區不足時，上下停靠增加行、左右停靠增加列，清除與關閉保留可見。

調整形狀大小時，八個控制點顯示水平、垂直或斜向箭頭，方向隨物件旋轉；旋轉點顯示圓弧旋轉箭頭。

此批為本機試用，編譯成功不等同實機操作驗收；4K、多螢幕、觸控筆與全部拖曳操作仍待試用。
