01開始使用

先有一張紙，再讓想法延伸。

  1. 在首頁點選「＋ 新增」，選擇「筆記本」、「無邊界畫布」或「有邊界黑板」。
  2. 輸入作品名稱；畫布底色與格線可在建立時選定，亦可在編輯中隨時更改。
  3. 點選畫筆開始手寫書寫；需要移動或調整形狀時切換到選取工具（V）。
  4. 作品變更會自動儲存於本機；需要分享或備份時，可匯出為標準 .heiban 檔案。
本離線手冊隨程式內建，無需網路連線即可隨時查閱。手冊本身不會向您的作品庫自動生成測試或範例黑板。

02首頁與作品庫

用真實內容縮圖直覺辨識作品。

首頁作品卡片即時顯示畫布內容縮圖，並標註筆記本、無邊界畫布或有邊界黑板之格式徽章。點選卡片開啟；右鍵可選擇重新命名、匯出或移至垃圾桶。

  • 搜尋與篩選：在上方搜尋列即時輸入關鍵字搜尋作品名稱。
  • 開啟文件：點選上方「開啟文件」可直接載入外部 .heiban 或 .blackboard.json 專案。
  • 垃圾桶：可還原誤刪作品，或進行永久清理。
  • 免安裝版：若使用免安裝 Portable 版本，作品與快取資料均獨立存於程式旁的 Data/ 資料夾內。

03三種畫布與背景

選擇最適合思考與表達的畫布範圍。

格式適用情境特色與操作
筆記本課堂筆記、會議記錄、多頁教材底部提供頁碼導航、‹ › 翻頁與「＋頁」按鈕；各頁內容獨立維護
無邊界畫布心智圖、架構草圖、自由發想無邊界空間，可朝任意方向平移與無限延伸
有邊界黑板簡報、考卷講解、固定尺寸排版固定紙張邊界（如 A4、16:9），呈現嚴謹板書

右上導覽膠囊「⋯ 更多 → 畫布背景」可隨時切換黑板綠、深色黑、純白板與暖白底色，並支援無格線、橫線條與點陣網格。

04移動畫布與縮放

滑鼠游標在哪裡，就以哪裡為縮放中心。

  • 滑鼠滾輪：預設以滑鼠游標所在的畫布世界座標為中心即時平滑縮放。
  • 滑鼠中鍵按住拖曳：直接平移畫布（Pan Viewport）。
  • 空白鍵＋左鍵拖曳：按住空白鍵時左鍵拖曳可快速平移，放開空白鍵立即恢復原工具。
  • 閱讀模式：右上導覽列點選閱讀模式圖示，此時滑鼠左鍵點擊與拖曳均直接平移畫布，不會意外畫出筆劃。

05右上導覽與工具列

浮動膠囊與自由停靠工具列，兼顧沉浸與效率。

右上精簡浮動導覽膠囊：集合了「回到首頁」、「閱讀/編輯切換」、「圖釘導航」、「＋ 插入選單」、「⋯ 更多設定」、「儲存狀態燈號」與「固定開關」。預設滑鼠移入時顯示、移開後自動收合；點擊「固定」可常駐顯示。

主工具列停靠：拖曳工具列前端的抓手（⋮⋮），可自由停靠至視窗上、下、左、右四邊；靠上下自動轉為橫向，靠左右自動轉為直向。

自訂工具列：從「⋯ 更多 → 自訂工具列」可自由勾選常用工具與調整上下順序，隱藏的工具仍可由「更多工具」選單快速呼叫。

06畫筆與筆刷

硬體加速的向量筆跡，放大縮小始終平滑細緻。

點選畫筆工具，再點選工具列上的色票圓圈即可開啟筆刷設定面板：

  1. 選擇單色向量筆、螢光筆或筆刷模式。
  2. 選擇常用色票或點選自訂調色盤選取精確色彩。
  3. 調整線條粗細（0.5 pt ~ 128 pt）與透明度；游標懸浮於畫布時會即時呈現實際尺寸的光圈預覽。
  4. 拖曳書寫；每一道筆劃均是獨立的幾何向量物件，日後可選取、著色或調整層級。

07圖形、曲線與頂點

精確的向量幾何形狀，支援端點拉動與多點多邊形。

  • 直線與箭頭（A/B 端點）：拖曳落筆建立；選取後可分別拉動起點 A 或端點 B，反向拉動不顛倒箭頭語意。
  • 矩形、圓形、星形、菱形：從圖形選單選取後拖曳成形，完成後自動切回選取工具。
  • 三點三角形與四點多邊形：依序在畫布點下端點，最後一點自動閉合；選取後可拖動個別頂點調整幾何。
  • 曲線：點選各控制點生成平滑曲線，選取後可拖動控制點編輯曲率。

08選取、物件與圖層

物件隨時可選、可變形、可調整圖層。

  • 選取工具（V）：點擊單一物件即可選取；在空白處拖曳可框選範圍；按住 Shift 可連續多選。
  • 控制把手：選取物件外框提供 8 向縮放把手與上方旋轉把手；針對圓弧（arc）更提供起角與訖角把手。
  • 快速操作列：選取物件上方會自動浮現精簡操作列，提供填色、線色、複製、鎖定/解鎖與刪除；鎖定狀態會即時同步按鈕權限。
  • 右鍵選單：提供剪下、複製、貼上、鎖定、圖層上移/下移與刪除。

09色彩、填色與線條

屬性檢查器提供最全面的外觀調整。

點選畫布右側的屬性檢查器書籤，可展開完整設定面板：

  • 線條色彩與粗細：即時變更已選物件的邊線外觀。
  • 填色與透明度：可設定實色填滿，並獨立調整填色透明度。
  • 線條樣式：實線、虛線、點線、點劃線自由切換。
  • 精確數值輸入：支援旋轉角度（精確至 0.1°）、字體大小與橡皮擦直徑數值微調。

10文字與便條紙

直接在畫布上打字，支援繁體中文輸入法（IME）。

選取文字工具（T）或便條紙工具，在畫布目標位置點擊即可開啟編輯方塊。中文組字期間保留輸入法選字，不會觸發畫布背景快捷鍵。完成輸入後點擊畫布空白處即可提交變更並產生單步 Undo 交易。

11橡皮擦

物件擦除與局部筆跡擦除雙模式。

  1. 點選橡皮擦工具；再次點擊可切換「物件擦除」或「局部筆跡擦除」並調整直徑。
  2. 畫布上會呈現半透明圓形擦除預覽圈。
  3. 物件擦除：碰觸到線條或幾何時直接整筆移除該物件。
  4. 局部筆跡擦除：只擦除滑鼠劃過的局部筆劃段落。
  5. 文字、便條紙與圖片受到保護，不會被橡皮擦誤擦；如需刪除請選取後按 Delete。

12尺規

螢幕量角尺，輔助畫出筆直切線。

  1. 點選工具列尺規圖示啟用；拖曳尺身移動位置。
  2. 拖曳旋轉把手調整角度（支援 0.1° 精確步進），亦可在右鍵設定面板直接鍵入數值。
  3. 尺規外觀支援自適應背景配色與半透明度設定。
  4. 畫筆在尺緣附近書寫時會自動吸附並沿著直尺邊緣繪出筆直軸線。

13圓規：準備 → 鎖定 → 畫弧

兩階段幾何作畫：點擊圓心變色鎖定，拖曳筆尖精確畫弧。

1準備階段

拖曳圓心移動位置，拖曳半徑把手調整半徑 R，拖曳筆尖把手調整起角。此階段純屬輔助導引，不產生物件。

2鎖定圓心

點擊圓心，圓心切換為亮橘色，中心與半徑鎖定，筆尖進入作畫待命狀態。

3筆尖畫弧

拖曳筆尖沿圓周旋轉，即時預覽有向掃角弧線；跨越 0° 連續計算不跳躍；放開時提交單步 Undo 交易生成精確 arc 物件！

生成的圓弧物件支援 8 向等比縮放、旋轉以及「起」「訖」專屬端點把手微調；靜止點擊放開不會生成無效物件。

14雷射筆

演講與授課專用的動態聚焦點。

點選雷射筆工具，在畫布上移動即可呈現高亮聚焦點與動態消退尾跡。雷射屬於純暫態視覺引導效果，不寫入作品文件，不影響 Undo 記錄。

15計算機與倒數計時

常駐工作區的實用教學輔助工具。

科學計算機：從右上「＋」選單開啟。提供 7 列完整按鍵面板，支援括號表達式 (2+3)×4、圓周率 π、自然對數底 e、Ans 歷史結果。支援鍵盤直接輸入與 Enter 求值。計算過程不改動作品，點選「插入算式」才會提交單步 Undo 將文字置入畫布。

工作區常駐計時器：提供碼表正計時與倒數計時（5/15/25 分鐘快速預設）。計時服務提升為工作區常駐守護服務，即便收合或關閉計時面板，背景依然依真實時間基準持續精確推進，並在到時觸發即時通知。

16圖片與截圖置入

區域框選截圖直接置入畫布，隨拖隨放。

  • 截圖置入：點選右上＋選單或工具列「截圖」，拖曳框選螢幕區域，完成後直接將圖片物件以原始比例置入目前視野中心，不另存截圖資料夾。圖片可拖移、縮放與旋轉。外部 Windows 剪取工具（Win+Shift+S）的圖片則可手動 Ctrl+V 貼上。
  • 生命週期守護：非同步解碼期間全程維持逾時監控；按 Esc 或右鍵取消框選；切換文件／頁面與逾時會取消請求。截圖使用本次框選結果，不讀取其他軟體的剪貼簿圖片。
  • 拖曳匯入：直接從桌面或檔案總管將 PNG、JPG、BMP 圖片拖入黑板畫布，立即置入。

17圖釘導覽

在廣大畫布上快速標記關鍵視角。

點選右上導覽膠囊的圖釘圖示，可將當前視野中心與倍率儲存為原創斜向圖釘。點擊圖釘清單中的項目即可瞬間平滑跳轉至該視角，是長篇課堂與大型架構講解的最佳導航工具。

18我的螢幕就是我的畫布

在桌面、簡報與播放中的影片上覆蓋透明繪圖層。

開發規劃，preview.5 尚未提供：預定從右上導覽列的螢幕圖示，或首頁「我的螢幕就是我的畫布」按鈕啟動獨立透明繪圖層。預定支援「作畫模式」與「穿透操作模式」，可在桌面、簡報與持續播放的影片上註記；結束回到原作品。從作品啟動的截圖將直接貼回該畫布。目前可用的是普通區域截圖置入（第16節）。

19儲存、暫存與匯出

標準 .heiban 格式，跨平台無損互通。

檔案類型用途說明相容性與特性
.heiban黑板標準專案原稿完整保留向量筆劃、幾何形狀、文字、圖片、頁面結構與圖釘座標
.blackboard.json歷史版本相容格式完整支援向上讀取與無損升級
PNG 圖片課堂筆記發送、作業繳交高解析度 Direct2D 離屏渲染，包含乾淨合成背景
SVG / PDF向量文件匯出清晰向量線條，適合列印與二次編輯

資料儲存路徑：安裝版作品儲存於 %LOCALAPPDATA%\HeiBan\Windows\；免安裝 Portable 版儲存於程式目錄旁 Data/。

20快捷鍵速查

21限制與後續規劃

公開透明的開發規劃進度。

本版本為 0.1.0-preview.4。目前已完整具備向量筆跡繪製、圓規兩階段畫弧、arc 幾何端點編輯、括號計算機、常駐計時服務、截圖自動置入與免安裝可攜架構。

後續批次將陸續推進：心智圖、表格、LaTeX 公式排版、畫框簡報與雲端同步。所有未知 JSON 欄位均具備完整無損保留（JsonExtensionData），升級不遺失資料。
