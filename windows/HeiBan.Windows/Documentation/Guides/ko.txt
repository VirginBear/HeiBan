navigate|이동, 확대 및 시점 잠금|휠이나 Ctrl+휠은 포인터를 중심으로 확대합니다. 가로 휠은 이동합니다. 가운데 버튼 끌기 또는 Space를 누른 채 왼쪽 끌기로 이동하고 읽기 모드에서는 왼쪽 끌기를 씁니다. 배율 컨트롤은 기본 배율, 내용 맞춤, 시점 초기화를 제공합니다.|시점 잠금은 이동과 휠 확대를 막습니다. 도구 모음과 모서리 잠금 표시가 함께 바뀌며 잠금을 풀면 다시 이동할 수 있습니다. 가운데 버튼을 누르고 이동하는 동안 캔버스를 잡는 손 모양 커서가 표시됩니다. 버튼을 놓으면 원래 커서로 돌아갑니다.
workspace|탐색과 도구 모음|위쪽 탐색에는 홈, 읽기/편집, 핀, +삽입, 더 보기, 저장 상태, 고정이 있습니다. 고정하지 않으면 포인터가 나갈 때 접힙니다. 체크는 저장됨, 점선 원은 대기/저장 중/미완료를 뜻합니다.|손잡이를 네 가장자리로 끌면 위아래는 가로, 좌우는 세로입니다. 더 보기→도구 모음 사용자 지정에서 표시, 숨기기, 순서를 바꾸고 숨긴 도구도 더 보기에서 사용할 수 있습니다. 개체 레이어는 별도 패널로 열립니다. 화면 도구 모음은 스크롤바 없이 영역에 맞춰 줄/열을 늘립니다.|홈 설정 또는 더 보기→도구 모음 사용자 지정에서 아이콘만 표시하거나 자주 사용·그리기·삽입·관리 탭과 글자를 표시할 수 있습니다. 선택(V)은 항상 표시됩니다. 도구는 한 행 또는 한 열로 배치되며 공간이 부족하면 양끝 화살표로 도구 그룹을 전환합니다. 왼쪽 체크는 도구 표시, 자주 사용 체크는 해당 탭 추가입니다. 모두 선택·기본값·순서 변경도 가능합니다. 앱의 패널과 대화상자는 Windows 밝게/어둡게 설정과 무관하게 종이색과 녹색 디자인을 사용합니다. 시스템 파일 선택창은 Windows가 관리합니다.|도구 모음은 아이콘과 텍스트가 기본이며 자주 사용 탭에 브러시와 선 스타일이 포함됩니다. 사용자 지정에서 바꿀 수 있습니다. 처음 사용하면 모든 도구 설명과 편집 가능한 예제를 담은 무한 캔버스 사용 설명 · 모든 도구를 추가합니다. 가운데 버튼 또는 Space+드래그로 이동하고 휠로 확대/축소하며 핀 목록으로 각 장에 이동하세요. 기존 예제와 편집한 작품은 덮어쓰지 않으며 이 설명서를 삭제해도 매번 다시 만들지 않습니다. 현재 페이지 지우기는 기본으로 자주 사용에 포함됩니다. 업데이트 시 다른 선택을 유지하면서 이 항목만 추가합니다. 일반 및 화면 캔버스의 도형 메뉴는 같은 윤곽선 아이콘과 9개 버튼 그리드를 사용합니다. 선택과 레이저는 모든 탭 밖에 고정됩니다. 레이저는 기본 자주 사용에 포함되며 중복 표시하지 않습니다. 다시 누르면 설정이 열립니다. 펜과 지우개는 끝/접촉점을 사용하고 도형 도구는 기존 십자 입력점과 옆 도구 아이콘을 사용합니다. 선택은 화살표이며 가운데 버튼 이동과 크기 조절·회전에는 해당 커서를 사용합니다.|1.1.0의 더 보기 아이콘을 녹색 윤곽선으로 통일했습니다. 화면 도구 모음의 적용은 즉시 미리 보기, 저장은 저장 후 닫기입니다. 취소는 적용 전 변경만 버리며 일반 캔버스의 핀과 보기 잠금 등은 유지됩니다.|1.1.2: 도구 모음 사용자 지정에서 기존 윤곽선 또는 A 컬러 듀오톤 아이콘을 선택합니다. 저장하면 두 캔버스와 휠에 함께 적용되며 재시작 후에도 유지됩니다. 취소는 미적용 변경을 버리고 기본값은 기존 스타일로 복원합니다. 화면 모드는 같은 창에 조작은 포인터, 그리기는 펜을 표시합니다. 휠은 전환할 모드를 표시합니다. 회초리는 곧은 모양을 유지하며 선택 도구 아래의 선은 실제 그리기 색상입니다. A 컬러 아이콘은 가는 윤곽선을 사용합니다. 펜과 형광펜 몸체는 현재 브러시 색상을 따르며 밑줄은 활성 도구에만 표시됩니다. 직선, 화살표와 도형은 보라색입니다. 기존 선택 아이콘도 선택 프레임과 포인터를 표시합니다. 좌우에 고정하면 좁은 한 열로 표시됩니다. 이름 표시 모드에서는 현재 탭 이름으로 탭을 선택하고 화살표로 도구를 넘깁니다. 브러시 아래에 빠른 색상 여섯 개가 표시됩니다. 도구 모음 사용자 지정에서 작게·보통·크게를 선택합니다. 버튼, 아이콘, 빠른 색상과 라벨 크기가 함께 바뀝니다. 새 설치와 기본값 복원은 컬러 아이콘을 사용합니다. 저장된 아이콘 선택은 유지합니다.
radial|오른쪽 버튼 도구 휠|왼쪽 버튼을 놓은 뒤 오른쪽 버튼을 약 0.22초 누르세요. 밝아진 칸으로 이동한 뒤 놓으면 도구가 바뀝니다. 바깥으로 빠르게 움직여도 열립니다. 중앙으로 돌아가거나 Esc로 취소합니다. 도구를 바꿔도 휠의 각 칸은 그대로 유지됩니다.|더 보기→오른쪽 버튼 도구 휠에서 위 도구 모음의 아이콘을 칸으로 끌거나 옆 메뉴에서 직선, 화살표, 도형을 지정하세요. 이미 있는 도구는 자리가 서로 바뀝니다. 일반 캔버스와 화면 캔버스의 구성을 따로 저장하며 화면 쪽 조작 칸은 고정입니다. 설정은 유휴 상태에서 저장되고 정상 종료 시 완료를 기다립니다.|화면 캔버스에서 그리는 동안 오른쪽 버튼을 두 번 클릭하거나 조작 칸을 선택하면 뒤의 앱을 조작할 수 있습니다. Ctrl+Alt+D로 그리기로 돌아갑니다. 짧게 오른쪽 클릭하면 개체 메뉴를 유지하며 화면 캔버스는 시스템의 두 번 클릭 판정을 먼저 기다립니다. 레이저와 지시봉에서는 개체를 선택하지 않습니다. 휠을 연속 사용한 것은 조작 전환으로 간주하지 않습니다.|더 보기→도구 휠 설정에서 프리셋을 고른 뒤 도구를 칸으로 끌어 변경합니다. 일반 및 화면 캔버스의 구성은 따로 저장합니다. 현재 획을 마친 뒤 적용하세요.|화면 캔버스의 조작 모드에서도 오른쪽 버튼을 길게 눌러 휠을 엽니다. 짧은 클릭은 원래 앱으로 전달합니다. 도구 위에서 놓으면 그리기로 돌아가며 고정 그리기 칸은 이전 도구를 복원합니다.
