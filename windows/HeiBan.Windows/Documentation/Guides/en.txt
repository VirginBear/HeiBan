language|Interface and guide language|At the bottom of the home sidebar, choose Language (the 文/A icon when collapsed). The ten languages are Traditional Chinese (default), Simplified Chinese, English, Japanese, Korean, Spanish, French, German, Brazilian Portuguese and Arabic. A saved choice applies immediately and is remembered at startup. Existing work names and text are not translated; new default names use the current language.|Help opens in the current interface language. The selector on this page changes only the guide, not the app preference. All guide pages, navigation and search work offline. Arabic menus and help read right to left; canvas coordinates are not mirrored. System file dialogs and original error messages may use another language; some built-in controls may require an app restart.
start|Getting started|On the home page, press + to create a notebook, infinite canvas or bounded board. Enter a name and choose a background color and pattern. Use Pen to draw and Selection (V) to move or adjust objects.|Auto-save is OFF by default. Use Ctrl+S to save manually; leaving a work or exiting normally also saves. Export .heiban for an editable backup. The guide never creates example works in your library.
library|Home and work library|Click a card once to highlight it without showing batch actions. Double-click, or right-click and choose Open work, to enter. Right-click also offers favorites, rename, duplicate and move to trash. Trash retains the editable original; double-click a trashed card to restore.|Use the dashed circle beside Import to enter multi-select; a checked circle identifies a selected work. Select all current results or choose individual cards, then move them to trash; Done exits multi-select. Search by name, filter by format, sort by modification, creation or name, and choose 160/190/250 pt thumbnails. Import opens .heiban or .blackboard.json; the sidebar switches between all works, favorites and trash.
paper|Canvas types and pages|A notebook has independent pages. The bottom page number and previous/next arrows navigate; + adds a page. The page menu can jump, rename, duplicate, reorder or delete pages. An infinite canvas extends in any direction. A bounded board has a fixed page boundary for presentations or structured layouts.|An infinite canvas has no size selector. A new bounded board initially uses a 16:9 presentation (1920×1080); A4 portrait, A4 landscape and 1:1 remain available. Switching types remembers that dialog's chosen sizes. Creation and Canvas background offer plain, ruled, dotted, square grid and staff paper plus color. Apply changes an existing background; Cancel leaves it unchanged; one undo restores it.
navigate|Pan, zoom and view lock|The wheel zooms around the pointer; Ctrl+wheel also zooms. A horizontal wheel pans. Drag with the middle button or hold Space and drag with the left button to pan. In reading mode, left-drag pans. The zoom control offers presets, fit content and reset view.|View lock prevents panning and wheel zoom during explanations. Both the toolbar and corner lock indicators change together. Unlock to move the view again.
workspace|Navigation and toolbars|The upper navigation contains Home, reading/editing mode, pins, + insertion, More, save status and a pin to keep navigation visible. Otherwise it collapses when the pointer leaves. A check marks saved work; a dashed circle means pending, saving or incomplete saving.|Drag a toolbar grip to any of the four sides: horizontal at top/bottom, vertical at left/right. More → Customize toolbar lets you show, hide and reorder tools; hidden tools remain in More tools. Object layers is a toolbar entry and a separate panel. Screen toolbar layout adapts to the available area without scrollbars.
brush|Pen and brush choices|Choose Pen, then the color circle for color, thickness, opacity and brush type: vector pen, fountain pen, pencil, watercolor, highlighter, crayon, calligraphy or paint. Preferences are remembered. Strokes use smoothed vectors; brush names do not imply physical material simulation. Finished strokes can be moved or recolored.|With the vector pen, draw an approximately straight stroke and keep pressing without moving for one second to snap it straight. Moving more than 12 pt restores the original stroke preview. Releasing commits one undo operation. Cover tape in More tools hides a question; double-click or use object settings to reveal/hide it, with undo support.
shapes|Lines, arrows, shapes and curves|Create a line or arrow by dragging, or clicking A then B. Move the shaft or adjust endpoints independently. In Properties, choose a segment, extend toward A or B, or extend both ways without changing the original endpoints. Arrow head length and width are separate controls; stroke thickness also changes the head outline.|Drag rectangles, circles, diamonds, pentagons and stars. Triangles and quadrilaterals use successive points. A curve uses three points: first starts the preview, second fixes the bend, third commits. Selection edits vertices or control points. Esc cancels unfinished geometry. Color and Properties control applicable stroke, fill, gradient and opacity.
selection|Selection and transformations|Use V to select. Ctrl+click toggles objects; lasso selects an enclosed region. Drag a box left to right to select only fully enclosed objects (blue solid border), or right to left to select touched objects (green dashed border). Ctrl/Shift-drag adds selection. Multiple objects can move, copy, paste, change style or delete together.|A single shape has eight resize handles and a rotation handle; the pointer shows the corresponding direction or rotation arrow. Lines/arrows have A/B handles and arcs have start/end handles. Image corners preserve proportions by default; Shift allows free resizing. Shift while rotating snaps to 15°. Locked objects are excluded from batch move/delete; hidden objects stay in the layer panel.
properties|Properties, colors and styles|The Properties panel shows only settings applicable to the selected object. Adjust stroke color, thickness, applicable fill/gradient/opacity, text or geometry values. Solid, dashed, dotted and dash-dot choices show line samples; the toolbar reflects the current style. Drawing defaults can be set before drawing; selected-object changes also update subsequent drawing settings.|Dock the panel by its Dock control or drag its title to an edge: vertical at left/right, horizontal at top/bottom. Layers, eraser and ruler settings have their own entries instead of cluttering an unrelated object's properties. Line extension and arrow head dimensions are in the line/arrow properties.
text|Text and sticky notes|Choose Text (T) or Sticky note, then click the canvas and type. Enter inserts a line break; Ctrl+Enter or leaving the editor finishes; Esc cancels. Composition input does not trigger tool shortcuts. The color circle provides font, bold, italic, underline, strike-through and alignment. Sticky notes have folded-corner, tape, cat, notebook, grid and soft styles.|Edit partial text formatting opens an editor: select text, then apply format, text color or highlight and save as one undo operation. Right-click text or its draft for whole-box style. More text settings applies only changed fields to unlocked text/notes on the current page, skipping other objects. Screen text supports 8–144 pt, custom #RRGGBB, font, alignment and opacity.
eraser|Eraser|Select Eraser; click it again to choose object erasing or partial stroke erasing and adjust diameter. A translucent circle previews its range in both the regular and screen canvas.|Object erasing removes an entire touched stroke or geometric object. Partial stroke erasing removes only the crossed part of a stroke. Text, sticky notes and images are protected; select them and press Delete to remove them.
ruler|Ruler|Enable the ruler, drag its body to move it and drag endpoint handles to rotate. Move the gold pivot onto either drawing edge or either end; rotation stays around that pivot. Right-click the ruler, or use its settings, for the edge, 0–100% pivot position, 0.1° angle, opacity and length.|Length is 20–150% of canvas width, initially 90%, and adapts to window size. A pen stroke started near an edge snaps along that edge for the whole stroke; drawing beyond the ruler still follows the same axis.
compass|Compass: prepare, lock, draw|Prepare by dragging the center, radius handle and pen tip to position the circle and starting angle. These guides create no object. Click the center to turn it bright orange and lock center/radius.|Drag the tip around the circumference to preview an oriented arc; crossing 0° remains continuous. Release to create one editable arc and one undo operation. A stationary click creates nothing. The arc has proportional resize/rotation controls and start/end angle handles.
laser|Laser pointer|Choose Laser from the toolbar or More tools. Click the active laser again for settings; choose a dot, short trail or line, color, diameter, width, fade time and white core. The screen canvas also provides these settings.|Laser marks are temporary pointers. They do not create saved objects or add undo operations.
utilities|Calculator and timer|Open Calculator or Timer from the upper + menu. Drag the title to move or collapse the panel. Calculator supports parentheses, scientific functions, π, e, Ans and keyboard/Enter; only Insert expression creates a text object.|Timer offers a stopwatch, 5/15/25-minute countdowns and custom seconds. Closing its panel keeps it running and it notifies when time is up; reopening shows the current state.
images|Images, screenshots and cropping|Use Screenshot in + or the toolbar, then drag an area. Esc or right-click cancels; switching work/page or a timeout also cancels. The result becomes an image at the current view center with its original proportions; it is not saved into a separate screenshot folder. Win+Shift+S results can instead be pasted with Ctrl+V.|Drag PNG/JPG/BMP files from Explorer onto the canvas. Images can move, resize and rotate. Select an image and use Crop image / Restore original in its color menu; enter a rectangle in original image pixels. Cropping preserves the source image. The built-in capture uses its own result, not unrelated clipboard images.
pins|View pins and colors|The upper pin control saves the current view center and zoom. Select an entry to return to it. Double-click a pin or its name to rename; Enter or clicking elsewhere saves, Esc cancels. Right-click names also offers rename, and edits support undo.|Right-click a pin for Pin and text colors, or choose Colors in the pin list, to set each separately. Windows saves these optional colors; an older Mac version may remove them when resaving the work.
screen|Screen canvas|Start from the home sidebar, the screen icon or More tools; Ctrl+Alt+A also opens it. The current work saves and the main window hides. The desktop remains live beneath an independent transparent annotation canvas. Drag the toolbar grip to four edges; it wraps into rows or columns without scrollbars, keeping clear/close accessible. Colors, line/fill, layers and palette have entries; click Eraser or Laser again for settings. Supported shared tools follow the main toolbar visibility and order; pins and view lock are omitted. The Shapes menu contains the same nine shapes.|Draw/Operate or Ctrl+Alt+D switches between annotation and passing input to the app below. Right-click an object to change style, copy, duplicate, delete, lock or reorder; clicking an already selected object preserves the group. Right-click empty space cancels only the unfinished gesture. Shift-click or box selection adds objects; box direction follows the same enclosed/touched rule. Selection moves, resizes, rotates and adjusts endpoints. Shift constrains lines/arrows to horizontal/vertical.|Choose T and click to type; Enter makes a new line, Ctrl+Enter/Done commits, Esc cancels. Double-click text or use More → Selected objects → Edit text. Switching tool/mode, capturing, exporting or ending commits a draft. Styles apply only changed values to unlocked selected objects and continuous slider edits undo together.|Screenshot or Ctrl+Alt+S captures an area with annotations as an image at its original screen position, without a separate screenshot folder. More → Export annotations saves a transparent PNG or editable .heiban. More → Save annotations saves manually. × or Ctrl+Alt+Q saves the independent session and restores the main window; reopening resumes it. Trash or Ctrl+Alt+K clears all annotations without another prompt; Undo restores them. Shortcuts may be occupied by other apps; use the toolbar then. Screen annotations never automatically merge into the main work.
files|Saving, data and export|Home Settings or More → Settings controls Auto-save, OFF by default. A saved choice persists. ON keeps regular canvas saves around every 15 seconds and screen saves about one second after changes stop; unfinished gestures postpone saving. OFF stops periodic work saves. Ctrl+S saves a regular work; More → Save annotations saves the screen canvas.|Returning home, switching works/screen canvas and normal exit save and wait, showing a spinning progress indicator. A save failure keeps the window and content. With auto-save OFF, a crash, power failure or forced termination may lose unsaved changes.|For export, select all content on the current page, selected objects or the current view, then .heiban, JSON, PNG, SVG, PDF or HTML. Editable work/JSON always keeps all pages; images and reading formats follow the chosen scope. PNG uses the canvas renderer; SVG includes vectors/images and rich-text foreignObject (viewer support required). PDF needs Windows Edge WebView2 and includes editable source data; HTML reads offline and includes editable JSON.|Installed builds store data under %LOCALAPPDATA%\HeiBan\Windows\; portable builds use Data/ beside the app. Store builds use their own app data location. Close the app and back up the complete data folder, including works, trash and settings, before migration. Keep the portable folder together; do not run directly inside a ZIP.
shortcuts|Keyboard reference|Ctrl+S — save; Ctrl+N — new work; Ctrl+Z / Ctrl+Y — undo/redo; Ctrl+C / Ctrl+V — copy selected objects / paste objects or clipboard images; Delete — delete selection; Esc — cancel a gesture/capture/unfinished shape.|Space+drag or middle-drag — pan; wheel or Ctrl+wheel — zoom; V / P / E / T — Selection / Pen / Eraser / Text; Win+Shift+S then Ctrl+V — Windows capture and paste. Screen: Ctrl+Alt+A — start; D — Draw/Operate; S — capture; K — clear; Q — end (each with Ctrl+Alt). Use toolbar controls if another app reserves a shortcut.
updates|App updates|GitHub builds offer update settings under Home → About → Update settings or More → Check for updates and update settings. Background checks begin about ten seconds after startup and repeat every six hours while the app runs. Disable automatic checks or preview versions, or check manually. This is separate from auto-save.|Downloads match architecture/install type and verify size/SHA-256. After saving succeeds and all windows of the installation close, a separate updater installs for the next launch, without forcing close or reopening. Interrupted/offline downloads or occupied files keep the current version for a later retry. Disabling auto-update also prevents a staged update from applying.|Portable updates preserve Data, portable.dat and unknown files; installed updates keep the data location. Backups are retained. Update staging/results are under %LOCALAPPDATA%\HeiBan\Updates\; works are not uploaded. Do not remove a drive or interrupt power during installation. Microsoft Store builds update through the Store, never by GitHub file replacement. Hash checks are not Authenticode signatures; Windows may still warn on first installation. Older builds need a one-time manual upgrade to gain the updater.
status|Scope and known limits|This is the Windows 1.0.14 development candidate, awaiting the complete development-series validation and the user's formal version decision. Building or packaging does not prove mouse/pen, multi-monitor/DPI, language or Store-install behavior. Check the development record for actual verification results.|Cloud/Google sync, collaboration, dedicated mind maps, tables, formulas, frames and editing external PDF/SVG as original works are not delivered features. Unknown document JSON fields are retained. A shared .heiban can contain user text in its original language; changing the UI does not translate it.
canvas-setup|Background settings in practice|For a new work, choose the canvas type before size and background. Infinite canvases do not need dimensions; bounded boards start at 16:9 but can be changed. Plain, ruled, dots, grid and music staff patterns can be selected at creation or later through Canvas background.|For an existing work, use Apply to commit or Cancel to keep the original; the change is undoable. Background settings change the paper, not the color of existing strokes or text.
ux20|Layer order and editing feedback|Open Object layers from the toolbar or More. Top rows are in front. Drag the gray double bar to the left of an icon onto the upper/lower half of another row to insert above/below it. The original row fades, a name/icon preview follows the pointer and a green insertion line marks the drop location. Rename layers without changing object identity; an empty name restores automatic naming.|Hidden objects remain available in the panel; locked objects resist batch move/delete. Properties and Object layers are separate panels. Directional resize/rotation cursors, saved/pending indicators, checked multi-select circles and eraser range previews help explain the current action. Report unexpected behavior from this trial before a formal update is approved.
