# Windows 1.1.5 文字、筆刷吸直與箭頭

依使用者要求改善兩種 Windows 畫布。開工保留既有三份已修改及三份未追蹤的文件。先查原生文字選區、筆跡提交及箭頭繪製與匯出。

## 實作進度

既有普通畫布另有局部文字格式的儲存對話框，螢幕畫布只有整框格式。改用共用 RichEditBox 格式列，原生選區直接格式化，字型由 Win2D 查詢本機安裝清單。離開編輯時同步文字片段與其大小、字型；畫布及 SVG／PDF 共用文件屬性。原畫布的輸入仍獨立於文件，結束才建立 Undo。文件契約增加可選欄位，既有作品不需遷移。

螢光筆／油漆筆刷吸直後依原型儲存兩點，保留原透明度與筆寬。新箭頭使用七點封閉輪廓，矩形尾桿在接合處收在箭頭底邊內，短箭頭限制頭部比例。畫布、命中／框選、擦除及匯出使用同一輪廓。舊箭頭保留原外觀。

執行十語目錄與手冊生成成功，Core.Tests Release 6,898 項通過。第一輪 WinUI 編譯因漏匯入工具列命名空間失敗，補上後建置為 0 警告、0 錯誤。首輪螢幕畫布診斷等待真實時間時混入桌面指標移動，改用同一 timer 回呼接收模擬時間，令合成輸入序列可重現。
