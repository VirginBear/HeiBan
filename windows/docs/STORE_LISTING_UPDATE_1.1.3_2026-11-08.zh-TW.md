# Microsoft Store 1.1.3 清單更新文字

各語言「此版本的新增功能」可使用下列對應內容。

## 正體中文（zh-TW）

- 預設採用彩色圖示，工具列提供大、中、小尺寸與更精簡的側邊配置。
- 鋼筆停筆約 0.5 秒可拉直；按住 Shift 建立水平、垂直、45 度直線與正形。
- 一般畫布與螢幕畫布共用尺尺寸，拖曳尺端即可伸縮。
- 新增六色快速切換與常用色拖曳排序，活動工具以無外框色線提示目前筆色。
- 改進選取、游標與工具操作，新增藤條連敲裂紋與碎屑效果，更新十語操作說明。
