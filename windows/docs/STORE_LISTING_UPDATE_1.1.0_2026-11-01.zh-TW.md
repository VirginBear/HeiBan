## runFullTrust 簡短說明（如後台再次要求）

HeiBan is a WinUI 3 desktop whiteboard packaged as MSIX. runFullTrust is required to run HeiBan.exe as a packaged desktop app at the user’s normal permission level. It supports local drawing, user-selected file import/export and a screen annotation overlay. It does not require administrator rights.
