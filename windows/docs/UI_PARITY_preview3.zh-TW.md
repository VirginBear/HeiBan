# Windows preview.3：介面與筆刷／尺規修正

日期：2026-10-08。Windows 程式、文件與發行包維持在 `windows/`；本輪沒有修改 Mac 程式。以目前 Mac 的 ToolbarView、InspectorView、TopNavView、RulerOverlayView 與 RulerSettingsView 為實作對照，不把尚未實作的概念圖當成已完成的 Mac 功能。

## 原因與修正

| 使用者回報 | 找到的問題 | preview.3 處理 |
| --- | --- | --- |
| 工具列白字、文字標籤、黑色側欄不像 Mac | 工具使用字串；控制項繼承系統深色主題，畫布卻固定為淺色 | 暖白／深綠介面、統一原創向量圖示、圖形集中在圖示選單，屬性收為右側書籤 |
| 沒有可用的色盤、筆刷無法改色／粗細 | 顏色藏在文字按鈕；屬性需要另按套用；工具寬度另有隱藏倍率 | 工具列顏色圓鈕直接開啟 ColorPicker Ring、快捷色、alpha、筆寬；設定即時生效，六種預設，預覽使用 width × zoom |
| 尺可移動卻不能旋轉 | 尺身命中優先於旋轉把手，旋轉區域被移動分支攔截 | 兩端把手先命中，再判斷旋轉參考點與尺身；旋轉使用按下時角度差，避免左端瞬間翻轉 |
| 尺太小 | 原來採用固定短尺 | 預設長度與 Mac 相同為 1200 pt，尺厚 64 pt；依小視窗限制，可調 400–1800 pt |
| 工具列難拖、難直排、長度不足 | 操作入口及版面未對齊 | 握柄與可捲動工具內容分開，拖動只更改 transform；放開時停靠並改方向，浮動位置限制在畫布內 |

## 操作入口

1. 工具列的顏色圓鈕：目前筆刷的色輪、快捷色、粗細、透明度與實際大小預覽。鋼筆、螢光筆、油漆筆及圖形各自保留設定。
2. 右側書籤：已選物件的線條、填色與 alpha、粗細、透明度、線型、旋轉角度、文字大小；沒有選取時調整目前工具。設定無需套用。
3. 尺圖示：顯示／收起尺。拖尺身平移；兩端綠色圓形把手旋轉；細小圓點移動旋轉參考點。
4. 點尺上的角度、右鍵尺或右鍵工具列尺圖示：輸入到小數一位、尺長、透明度、自適應或自訂刻度／文字色。
5. 左側點狀握柄：拖至畫布左右邊，放開後直排；上下邊則橫排。也可由停靠按鈕明確選擇四邊。
6. 截圖圖示：啟動系統剪取工具，完成後 Ctrl+V 置入剪貼簿圖片；圖片檔亦可拖入。

## 結構

- `Views/ToolIcons.cs`：Windows 原創向量圖示。畫布、圖釘列表與工具列沿用同款 PinIcon／DrawPin 造型。
- `MainWindow.Chrome.cs`：工具列組合、筆刷預設、色輪、即時屬性交易與拖移。
- `MainWindow.Ruler.cs`：尺的顯示、尺寸、旋轉／參考點、角度設定與投影。
- `MainWindow.Input.cs`：指標事件路由、真正筆寬、截圖及剪貼簿圖片。
- `MainWindow.xaml`：首頁、導航、工具列與預設收起的屬性面板。

原生 WinUI 3 管理控制項與色輪；Win2D 畫布沿用已提交幾何／即時筆跡快取。拖尺與工具列不建立文件 Undo 快照；已選物件的連續屬性更新合併為交易，保存或切換操作前提交。

螢光筆現在直接使用文件內的 opacity；新筆刷預設 18 pt、45%。舊版曾將螢光筆文件 opacity 再乘 0.35，因此舊 Windows 文件的螢光筆可能顯示得較深，可從屬性調整。沒有以猜測來源的方式批次改寫原作品。
