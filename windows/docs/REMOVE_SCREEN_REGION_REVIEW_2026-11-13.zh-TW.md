# Windows 1.1.4 — 移除區域螢幕畫布與整體檢視

使用者確認區域作畫無法解決 OBS 單一視窗合成需求，要求移除「螢幕畫布（區域）」及檢查 Windows 全部主要模組。已讀開發索引、狀態、架構、問題、決策、Windows AGENTS 並保存開工狀態。Graphify 既有索引用於辨識畫布與呈現邊界，近期變更一律核對現行原始碼。

本批會還原全螢幕入口、移除區域模式與其視窗配置，同時保留區域產生的作品、獨立 OBS 白底輸出、畫布範圍截圖與桌面框選截圖。

## 移除範圍與檢視進度

- 清除首頁及一般畫布選單的區域入口、螢幕畫布的區域 HWND／彈窗布局、座標限定、區域右鍵篩選與四個區域專用詞條。全螢幕入口直接啟動。OBS 保留同一註記影格輸出；保留擷取期間停止全域輪盤與過期另存請求的保護。
- 檢查原生區域截圖與一般畫布範圍截圖的呼叫，兩者繼續有效。十語目錄重新產生，722 詞條缺漏 0；十語指南各 26 章、84 段。
- 既有圖譜是 10 月索引，未包含近期 OBS 與區域批次；以現行 C#、封裝記錄及二進位大小補足。主要候選是直播來源合成、PDF 圖片解碼峰值、螢幕畫布讀回成本、文件交易與商店套件體積。各項量測及驗收條件見下。
