## 階段1：開工

使用者希望設定自動存檔，新的模式預設關閉；開啟沿用原定期存檔，關閉不在繪画間隔存作品，正常退出先顯示儲存動畫、完成後關閉。另詢問能否像小畫家流暢。沿用Windows開發／兩庫紀錄同步授權；App／tests未新增授權，不執行測試。開工963f2d0，git status只原.vscode/，讀開發索引、Windows状态／架構／問題及根規則。Mac／Web、已發布／Store1.0.12.0與1.0.13.0包、Data及歷史保留。

先檢視一般15秒autosave、螢幕1秒debounce恢復保存與正常關閉／回首頁／作品切換的保存流程；需保留Ctrl+S、離開作品保存、失败不關閉與update-after-saved-exit。保存偏好只管理作品定時保存，不把偏好／工具UI設定寫入誤作畫布定期保存。實作前記錄方案，編譯／封裝另記實際結果，不套用舊驗收數字。

## 階段2：設定契約與流程

MainWindow.Saving管理Settings/saving.json的autoSaveEnabled布林，缺檔／缺欄位／讀取失敗皆false，使用者明確開啟後保存成功才改記憶體，之後啟動沿用；JsonExtensionData保留未知欄位，WriteAtomic沿用tmp／Flush／Replace＋.bak，semaphore防止同視窗設定寫入競爭。現有用戶未設過此新值也預設false。不改作品文件契約或偏好language.json。

入口：首頁側欄齒輪「設定」、作品右上更多「設定」；螢幕更多有自動存檔勾選與「儲存註記」。同一owner偏好控制主15秒及螢幕1秒debounce；off停止timer並保留已開始的原子寫入完成，未來tick／Changed也守護false。手動Ctrl+S、主離開作品、切換螢幕畫布及螢幕結束保留保存。關閉thumbnail定時器但保留pending，離開／關閉時flush，不因off丟已排縮圖。

一般Root兩ContentControl輸入容器，在保存邊界disable（保留子控制項既有停用值），最上層ProgressRing＋文字；32ms讓首個動畫frame顯示再Clone／background IO。Main close先取消擷取／完成文字與屬性，等主／螢幕保存、縮圖、update prepare，再Close；重入攔截，失敗恢復輸入，不關閉。SaveBeforeLeaving共用回首頁／新作品／匯入／螢幕切換；補匯入前保存旧作品，避免off時轉作品丢變更。Root快捷鍵及晚到圖片置入在边界禁止；不把對作品的未完成高頻預覽改成永久交易。

螢幕Stop暫停save／render／dock timer、關閉Flyout、完成文字與style，Native pointer／hotkey／bounds在stopping守護；chrome暫時換成ring／「正在儲存」，調320×72 DIP以保持四邊停靠可見，結束恢复尺寸／原Content。成功才藏視窗／釋放資源；失敗保留IsActive與作品，恢復timer政策並顯示錯誤Flyout，所有主開關一樣取owner設定。真實動畫／焦點／DPI／磁碟失敗流程仍未實機驗收。

## 小畫家流暢度目標與後續

目前WindowsInkCoordinator仍在UI input thread收coalesced points，非InkPresenter；Win2D GPU renderer已共用。關閉存檔可減少定期clone／序列化／flush與縮圖，但持續筆跡預覽、整場景pan／zoom重建、選取／擦除仍影響延遲。不能宣稱小畫家等級或FPS改善。

下一階段依序：輸入→顯示延遲與4K負載量測、筆跡預覽僅更新新增尾端與frame合併、平移／縮放圖塊cache、命中索引、低延遲獨立ink/composition路徑。既有可編輯vector／Undo／座標／像素契約要保留。官方[UI thread responsiveness](https://learn.microsoft.com/en-us/windows/apps/develop/performance/keep-ui-thread-responsive)、[Win2D GPU渲染](https://learn.microsoft.com/en-us/windows/apps/develop/win2d/in-a-core-app)、[Windows Ink低延遲wet ink](https://learn.microsoft.com/en-au/windows/apps/develop/input/pen-and-stylus-interactions)已查閱；Windows Ink範例的UWP宿主不能直接當作WinUI3 drop-in實作。新量測／App／tests本輪未執行。
