## 作品與本機設定

程式在本機保存使用者建立的筆跡、文字、插入的圖片、多頁作品、縮圖、垃圾桶與操作設定。目前没有帳戶登入、雲端作品同步或由 HeiBan 自行加入的使用分析服務。

螢幕註記與區域截圖由使用者啟動；取得的影像用於當次註記／作品保存或匯出，不作為自動背景蒐集作品上傳的功能。使用者選擇匯出時，檔案寫到使用者指定的位置。PDF 匯出使用 Microsoft Edge WebView2 Runtime 處理本機產生的頁面。

安裝方式影響資料位置與生命週期。Portable 作品位於程式旁 Data；獨立安裝版使用使用者 AppData；商店版的 AppData 可能受套件重新導向與重設／解除安裝管理。移除、重設或更換安裝管道前，使用者應先匯出並備份作品。本批未驗證商店解除安裝的保留行為。

## 網路與第三方服務

GitHub 獨立版啟用背景更新時會請求 GitHub Release 中繼資料、版本包及檔案完整性資訊，傳送版本識別 User-Agent 等一般 HTTP 資訊。GitHub 可接收到網路連線必要的 IP 位址等資訊；更新功能不將作品加入請求。使用者可以在更新設定停用背景更新，手動檢查仍會產生更新請求。

Microsoft Store 版停用上述 GitHub 程式更新，更新由 Microsoft Store 管理。使用者主動開啟程式內 GitHub 超連結、在支援頁提交內容，或使用 Windows／Store／WebView2 本身服務時，相關網站及 Microsoft 元件的資料處理由各自的政策與使用者設定管理。本說明不承諾作業系統或第三方元件完全沒有網路行為。

## 診斷與支援

程式啟動失敗時可能在本機建立診斷紀錄，內容包括版本、啟動階段、程序架構及錯誤／堆疊；錯誤可能含本機路徑。程式沒有自動上傳這些啟動紀錄的功能。

目前可用公開支援入口為 https://github.com/VirginBear/HeiBan/issues 。發行者須確認是否採用此入口；公開 issue 中使用者主動提供的資料會出現在 GitHub，提交前應移除私人作品、敏感路徑與帳戶資料。
