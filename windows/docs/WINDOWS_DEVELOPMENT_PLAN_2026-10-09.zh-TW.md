## 2. 範圍、平台與資料邊界

1. 只修改 `windows/` 的程式、資源、腳本與文件。Mac／Web 作為唯讀參考；不連結 Swift、不引入整個網頁畫布、不替其他平台建置或封裝。跨平台契約有缺漏時先在 Windows 文件記錄提案／fixture，列明需要共同文件更新的內容。
2. 沿用目前 C#／.NET、WinUI 3、Win2D 基線，不為介面改版順便升級依賴。純計算、文件、命令放 Core；Win32／WinRT、IME、視窗、GPU 放 Windows adapter／renderer；新面板與服務獨立檔案，不繼續塞大段到 MainWindow.Input／Chrome。
3. 永久物件、手勢預覽與工作區工具分開。arc／遮題／導圖進作品；圓規虛線／HUD／雷射是暫態；計算機／計時器及工具位置存偏好。只有完成編輯或按「插入結果」才提交一筆 Undo。
4. 保留 `.heiban`／JSON v1、未知欄位、未知物件、作品／頁面／圖釘 ID、資產與備份。未知物件提供不可編輯提示，不能悄悄畫成矩形或另存時刪掉。新增結構型別先寫欄位語意、遷移與往返案例，再接 UI。
5. 安裝版資料保持 `%LOCALAPPDATA%\HeiBan\Windows\`；Portable 維持 `portable.dat` 與程式旁 `Data/`。設定經同一 DataDirectory 路由；不可寫時有可見回饋，不能偷偷改用另一作品庫。
6. 保留繁體「黑板」品牌、原創斜向圖釘、三種畫布與 Windows Ctrl 快捷鍵。原作品庫不得自動生成測試／範例；驗收使用隔離資料目錄。
7. 每批先記 git status 與開發日誌，交付更新 CURRENT_STATUS、DEVELOPMENT_LOG、ISSUE_HISTORY；架構決定記 DECISIONS。測試寫實際命令和結果，未做寫「未執行」。完成勾選必須區分核心、UI、建置、互動、性能、封裝。

## 4. 產品布局與輸入要求（W-N01／02）

- 預設右上精簡浮動導覽：作品庫、閱讀／編輯、圖釘、＋插入、更多；搜尋可用後接上。標題移到筆記資訊；保留儲存入口與小狀態指示，保存錯誤不可藏掉。
- 保留使用者要求的上方控制自動收合：可見喚回入口、滑鼠移入／點擊顯示、離開延遲隱藏、固定開關。互動中或文字／Flyout 聚焦時不消失；透明空間不吞畫布事件。沉浸模式 Esc 可恢復。
- 繪圖列預設選取、筆刷群、橡皮擦、圖形、尺、Undo／Redo、更多；顯示／隱藏／排序與導覽偏好分開。四邊停靠、浮動，放開才決定方向；上下屬性面板採橫向分組、左右直式，選取物件不自動展開大側欄。
- 倍率／＋−／適合內容／原點／視角鎖放左下；筆記本頁面導航下方中央或可收合側欄。無邊界／固定畫布不顯示筆記本翻頁。
- 普通滑鼠滾輪預設以游標為中心縮放，另提供「滾輪平移」偏好，保留中鍵與空白拖曳平移。舊配置遷移有說明。IME 組字、TextBox、表格、公式及計算機輸入時不觸發背景快捷鍵／縮放。
- 驗收 960×640、1280×800、大視窗／全螢幕與 100／150／200% DPI；控制區採 DIP，物件採世界座標，多螢幕捕捉明確轉換實體像素。必要功能全可到達，不用空按鈕充數。

### W-N04 文件相容的第一個必要案例

Mac 現有 arc 是 `type: "arc"`，`x/y` 為完整圓外接框左上，`width/height` 為直徑，另有 `arcRadius`、`arcStartAngle`、`arcSweepAngle`。Windows 模型目前無這些具名欄位，renderer／命中沒有 arc 分支。應先核對 Mac 角度方向、rotation 及 bounds 語意，再建立 fixture／C# 模型與解析幾何；不要創造同名但不同座標的 schema。橢圓式非等比縮放與半徑限制須先定規則，不能產生互相矛盾的 width／radius。共用契約未補齊是待辦，不能因未知欄位能保存就宣稱 arc 已支援。

## 8. 驗收證據與性能門檻

- Core：幾何／狀態機／parser／時間與非法值、ID 重映射、序列化及真實保存重開測試；可在 Mac 跑純 C#，但不測 WinUI／clipboard／GPU。
- Windows：x64、ARM64 各自 Release build／publish，記 OS、SDK、架構與完整 log。ARM64 上模擬執行 x64 不能等同 x64 真機；沒有相應機器寫待驗收。不同 DPI、繁中 IME、滑鼠／觸控板／筆分開記錄。
- 原需求回歸與 W-N00 截圖矩陣必做。每新增一類永久物件都測建立→編輯→Undo／Redo→保存重開→副本／跨文件→縮圖→全部適用匯出；暫態不進文件。
- 以 A01／A02 的 F01／F02／F03 負載與 Windows W02／W03 為基準，記 p50／p95／max、GC／峰值記憶體與測試機。輸入收到至預覽提交 p95 目標 ≤20ms；一般板呈現間隔 p95 ≤16.7ms，壓力板 ≤33.3ms，無 >100ms UI 停頓；F03 可操作 ≤5 秒、峰值記憶體目標 ≤1.5GB。120Hz ≤8.3ms 為額外目標，不能由 GPU 加速字樣推導。
- 10分鐘筆跡／雷射／計時並行、10,000物件／200圖片負載、大圖快速切板及500作品首頁。先留數據再選空間索引、分區、差異歷史、背景解碼，不能以拆檔或斷言數稱性能達標。
- 端到端可見筆跡延遲需要相應錄影證據，無設備則待驗收。先前 349／1267／355 等報告數字不套用為新批證據；無關 Mac／Web 測試不自動列為 Windows 開發必跑。
- 文件安全：未知型別／欄位、arc／頁面／圖釘、資產相對路徑與缺失、磁碟滿／唯讀／外部修訂／中途退出／USB移除。跨平台往返用固定檔案副本，幾何容差依契約 ≤1e-6。
