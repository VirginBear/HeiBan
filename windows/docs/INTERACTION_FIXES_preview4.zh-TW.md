# Windows preview.4 操作修正

日期：2026-10-08（Asia/Taipei）。本輪僅修正 Windows 原生端；Mac／Web 程式碼未修改。

## 修正範圍

1. **直線／箭頭**：以 A／B 世界座標保存；兩次點擊或拖曳建立。完成後顯示 A／B 端點把手，拖移單端時另一端保持原位；旋轉過的舊線先將旋轉套用到端點，再修改邊界。線身選取按實際線段／箭頭頭部判定，不再把空白方框全當線。
2. **圖片與物件變形**：圖片置入／貼上完成後切到選取；八個尺寸把手及旋轉把手。角落縮放保持圖片比例，Shift 可自由變形；旋轉按 Shift 以 15° 吸附。相反把手固定，選取框、把手與命中判定採用相同旋轉幾何。
3. **形狀色彩**：工具列顏色面板在有選取物件時修改該物件，未選取時修改目前工具設定；形狀同一面板提供填滿、快捷填色與自訂色輪。右側屬性面板仍可調整。取消填滿再開啟時記住本次操作的填色；自訂實色會移除舊漸層。
4. **上方作品列**：改為畫布上的浮動列，預設收起；中央頁籤點擊／懸停顯示，離開 0.8 秒收合。編輯作品名稱、選單開啟或按「固定」時保留。繪圖工具列仍能四邊停靠與自由拖移。
5. **尺規支點**：比例可達 0–100%；支點可以位於上劃線邊、尺身中線、下劃線邊。滑鼠旋轉及輸入角度共用固定支點計算，支點優先命中，避免兩端旋轉把手攔截。

`ObjectHandles` 與 `RulerGeometry` 放在 Windows 純 C# 核心，UI 與 Direct2D 選取繪製共用幾何，不引用 Mac 或 Web 執行碼。

## 使用者驗收步驟

1. 選直線，依序點 A／B；拖 A 時 B 不動，再拖 B；箭頭重做一次。向左／向上、水平與垂直均可操作；Esc 可取消未完成的線。
2. Ctrl+V 貼圖片，拖圖片移動；四個角與四個邊調大小，拖上方圓形把手旋轉；確認旋轉後可再次選取／縮放，Undo／Redo、儲存重開均保持。
3. 畫矩形／圓形，完成後保持選取，點工具列顏色圓鈕改線色／填色；切到形狀工具後改色再畫，確認新圖形採用該工具設定。
4. 由上方中央頁籤顯示作品列；移到畫布後收起，點「固定」則保留；輸入名稱及開啟背景／匯出時不要突然消失。
5. 開尺，把金色支點拖到上劃線邊的左端／下劃線邊的右端；旋轉時該點不位移。右鍵指定邊及 0%／100%，再輸入角度確認同樣固定。
