# HeiBan 黑板隱私權原則

更新日期：2026年10月15日
適用範圍：由「純潔的熊」發行的 HeiBan 黑板 Windows 版。

## 1. 本機資料與用途

HeiBan 使用您建立或選取的筆跡、文字、圖片、文件、螢幕截圖及操作設定，提供繪圖、筆記、匯入、匯出與螢幕註記功能。作品、縮圖、垃圾桶內容及設定主要保存在您的裝置。Windows 版目前不提供 HeiBan 帳號登入、雲端作品同步、廣告追蹤或由開發者加入的使用分析服務；開發者不透過這些功能自動接收您的作品。

## 2. 文件匯入與螢幕功能

PDF 在本機轉換為可註記的頁面圖片。PPT／PPTX 匯入會呼叫您電腦上已安裝的桌面版 Microsoft PowerPoint 進行轉換。PDF 匯出使用 Microsoft Edge WebView2 處理本機產生的頁面。HeiBan 不為上述轉換將文件傳送至開發者的伺服器或線上轉檔服務。

螢幕註記、截圖及剪貼簿匯入由您操作啟動；取得的內容用於本機作品、註記或匯出。畫面可能包含其他應用程式的私人資訊，分享前請自行檢查。

## 3. 儲存、匯出與刪除

您可以管理、匯出及刪除本機作品；移至垃圾桶不等於永久刪除。免安裝版與 Microsoft Store 版可能使用不同的資料位置。移除、重設應用程式或更換安裝方式前，請先匯出並備份作品。

目前匯出的 .heiban、JSON、PDF 及 HTML 會保留完整可編輯作品資料，包含其他頁面與隱藏物件；匯出範圍或可見頁面不會限制其中原稿資料的範圍。如僅需分享目前可見內容，請使用 PNG 匯出並檢查成品。作品與匯出檔未由 HeiBan 提供額外加密，請妥善保護儲存位置與分享對象。

您選擇將作品存入雲端硬碟或主動分享後，該服務的同步、儲存及資料處理依其政策與您的設定進行。

## 4. 更新、網路與第三方元件

Microsoft Store 版由 Microsoft Store 管理程式更新，停用 HeiBan 的 GitHub 背景程式更新。GitHub 獨立版在啟用背景更新或手動檢查時，會向 GitHub 請求版本資訊與下載更新，包含版本識別及一般連線資料；更新請求不包含您的作品，背景更新可在設定中停用。

您主動開啟外部連結、使用 GitHub 支援頁，或使用 Windows、Microsoft Store、PowerPoint、WebView2 等第三方服務與元件時，相關資料處理依其提供者的隱私權原則及您的設定進行。本原則不表示作業系統或第三方元件完全沒有網路連線或診斷行為。

## 5. 診斷與支援

程式啟動失敗時，可能在本機產生含版本、啟動階段、程序架構、錯誤與本機路徑的診斷紀錄。HeiBan 沒有自動將這些啟動紀錄上傳給開發者的功能。

如需支援或提出隱私相關問題，可透過 https://github.com/VirginBear/HeiBan/issues 聯絡發行者。此為公開頁面，您主動提交的內容會公開，請勿附上密碼、私人作品、敏感路徑或其他不願公開的個人資料。

## 6. 原則更新

若未來新增帳號、雲端同步、分析或其他資料處理功能，我們會依實際功能更新本原則與商店資訊，並標示更新日期。
