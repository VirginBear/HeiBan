# 右鍵輪盤／螢幕橡皮擦實測表 — 2026-10-31

本批維持1.0.18，標籤 `radial-eraser-2026-10-31-r1`；不是進版或上架。請完整解壓ZIP，從獨立資料夾的 `HeiBan.exe` 啟動。試用包使用空白獨立 Data；舊作品與試用資料夾保留。測自己的作品請匯入副本。`PracticeFiles/` 內含100／5000物件的生成測試檔，有部分刻意鎖定／隱藏。

觀察流暢度請用同一作品副本、相同縮放與顯示器條件，比較舊 `optimization-final-2026-10-31-r1` 與新試用。可用隨包 `Capture-InputLatency.cmd` 留診斷；先正常關閉另一個使用相同Data的程式。診斷 CPU stage 的 P95 不等於滑鼠到螢幕端到端延遲；若錄影估算，必須標示影格率及錄影本身限制。這批沒有宣稱已達50ms。
