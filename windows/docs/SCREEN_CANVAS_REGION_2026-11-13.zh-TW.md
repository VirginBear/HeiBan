# Windows 1.1.4 — 螢幕畫布（區域）

使用者希望框選直播畫面內的區域，將 HeiBan 螢幕註記、輸入和工具列留在框內。Windows 開發版本維持 1.1.4。已查開發索引、狀態、架構、問題及決策，保存開工 Git 狀態。

既有 Win32 分層視窗以整個虛擬桌面為界，截圖服務已有框選及混合 DPI 座標。區域模式將直接縮小 HWND 和繪製表面，避免全桌面透明層攔截框外。區域選取沿用框選視窗，僅回傳座標。全螢幕註記及區域註記用各自的本機檔案。

## 實作進度

- 延用原生框選手勢，新增只用半透明選擇層的座標路徑。區域截圖只讀所選區域像素。分層視窗、Win2D 目標與全域操作輪盤皆遵守同一實體像素框。顯示配置變更先隱藏區域，再正常保存和結束。
- 工具列與附屬工具視窗以區域定位，工具列改使用區域可容納的換組方式。顯示工具選單時，暫把 XAML 根擴至框內，保留工具列畫面位置，讓 WinUI 彈出內容以該根為界。
- 首次 x64 建置中彈出選單的 Position 為 nullable Point，CS1061 連帶 XAML 掛接編譯錯誤，已改 nullable 檢查。

- 第二輪及後續 Release x64 編譯通過。進一步在首次顯示前先呈現新區域影格，避免露出上一個會話的分層視窗內容。
- 每組座標和尺寸保存各自的區域註記。區域編輯的懸浮選單、文字及小工具以同一矩形為界；系統開啟／另存檔案選擇器依 Windows 方式顯示。
- 最小區域為 360 × 250 DIP，較小區域顯示重新框選提示。顯示配置變更結束區域會話。OBS 擷取／裁切由使用者設定。

- 檢閱彈窗合成時發現桌面 Acrylic backdrop 會套在展開後的整個根視窗。開啟區域彈窗時改用透明根，收合再恢復原背景。首次封裝已開始，保留其產物，正式交付本批修正後的 r2。
