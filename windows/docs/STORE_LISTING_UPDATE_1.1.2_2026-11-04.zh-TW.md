- 新增可切換的彩色細描邊圖示，保留原本風格；操作與作畫使用一致的螢幕圖示。
- 鋼筆與螢光筆圖示跟隨目前筆刷顏色，直線與箭頭改用形狀類的紫色識別。

- Refined the Select icon with a selection frame and updated the straight rattan cane artwork for clearer tool recognition.
- Updated user guides in all ten supported languages.
