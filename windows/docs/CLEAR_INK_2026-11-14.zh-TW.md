# Windows 1.1.5 清除筆跡

依使用者要求，加入能保留圖面並清掉手寫標註的功能。開工已查平台索引、狀態、架構、決策及問題紀錄，保留三份已修改及三份未追蹤文件。

## 實作與驗證

EditorSession 共用刪除條件及單一 Undo 交易。一般畫布在確認後比對文件 epoch 和頁碼，螢幕畫布沿用既有即時清除入口與復原。清除鋼筆、螢光筆、油漆筆刷及有來源標記的吸直筆跡，維持圖形、圖片、文字方塊、鎖定與其他頁資料。筆跡與圖形工具均可能產生 line，舊未標記線段無從可靠判定來源，因此保留。BoardObject 增加可選來源欄位，文件契約已更新，無需遷移。
