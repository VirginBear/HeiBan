# Windows 1.1.6 螢幕畫布與文字編輯

## 開工

2026-11-21 使用者回報螢幕畫布選取後 Delete 無效、右側工具列使用中無法拖曳，要求文字編輯以色圓顯示色彩、參考提供的 PDF-XChange Editor 畫面補齊文字方塊細節，並支援從其他軟體貼上文字即建立文字方塊。

沿用 1.1.6，僅調整 Windows。先核對平台狀態、架構、問題與既有未提交內容。三份已修改文件及三份未追蹤文件原樣保留。附件是視覺與操作參考，實作以 HeiBan 既有工具列／文字格式模型為基礎。

追查確認文字編輯時 AttachScreenTextToolbar 原本會隱藏含握把的整個起始區與結束區，能使右側工具列看起來無法拖動。改為編輯時保留握把與關閉入口，只隱藏模式切換，量測時計入固定兩端的空間。自訂握把改用同一組桌面實體像素追蹤，移動時不重建 UI，放開才停靠及寫偏好。

首次增量編譯抓到本地方法捕捉尚未初始化的按鈕變數，改為先宣告 UI 參考、建立後再訂閱狀態更新。這輪僅為編譯排錯，尚未記為驗收成功。

外部文字貼上改成可直接接收 DataPackageView 的實際入口，原有快捷鍵仍讀系統剪貼簿；原生檢查使用獨立 DataPackage，不覆蓋使用者剪貼簿。貼上先進入文字草稿，點畫布提交為一筆復原，既有黑板物件編碼的貼上路徑保留。新增文字邊框三個 optional 欄位與 justify 對齊，文件契約同步更新，邊框留在物件外框內。

## 實作結果與原因

- Delete 原本會因 routed event 已處理或焦點留在 native 疊加層而漏接。螢幕工具列以 handledEventsToo 接收按鍵；選取後將焦點送回自有視窗，文字輸入與對話框期間保留原生編輯行為。
- 右側握把改成 pointer capture，桌面指標與 AppWindow 全用實體像素。拖曳只搬視窗，放開才重新停靠和寫偏好；取消時解除捕獲。文字編輯保留握把及關閉區，避免原本隱藏整個區段造成卡住。
- 兩畫布使用同一份 TextDraftEditor 格式列。文字色為圓形按鈕，字型來自已安裝字型；提供字級與增減、B/I/U/刪除線/標記、四向文字對齊、清除／複製／套用格式，以及背景、邊框色／粗度／樣式及透明度。格式複製是程式內暫存，不改系統剪貼簿。
- 兩畫布外部純文字貼上建立隔離文字草稿，保留換行及 Unicode，點畫布一次提交；一筆 Undo 可還原。原黑板物件與圖片貼上路徑保留；這批未實作外部 HTML/RTF 格式匯入。
- 色圓實測曾顯示預設黑色，而文字是紅色。原因是重新套用字元片段不會更新 RichEdit 的插入格式。載入完成後以相鄰字元的格式同步折疊插入點，再更新工具列。新貼上文字增加初始高度留白，避免兩行文字原生編輯時底部裁切。
- 新增三個 optional 邊框欄位及 justify 對齊，文件版本沿用 1.0.0，契約／序列化／復原／Win2D 與 SVG 同步。其他平台只要求保留未知資料，本批沒有修改其程式或驗收其顯示。
- 參考圖的上下標、預設格式保存、全套多物件幾何排版未列為已交付功能。

## 使用者試用

1. 螢幕畫布畫矩形，選取後按 Delete，應只刪除選取物件；文字輸入時 Delete 應只刪字。
2. 將工具列停右側，切工具、雙擊文字，按住頂部握把拖動；應保持可拖，放開停靠且重新開啟保留位置。
3. 複製其他軟體的兩行文字，回到畫布 Ctrl+V；應立即進入文字方塊編輯，點畫布提交，Undo 一次移除該次貼上。
4. 反白部分文字改色、大小及粗斜體，選對齊與外觀；點畫布後再雙擊，內容及格式應保留，色圓應與插入點格式一致。
