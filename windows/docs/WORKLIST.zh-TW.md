## 第一輪人工驗收目標（待使用者要求執行）

1. 乾淨 x64、ARM64 Windows 解壓雙擊，無外加 .NET 安裝；Setup 安裝／卸載完成且作品保留。
2. Portable 的作品／縮圖／垃圾桶皆留 Data，唯讀位置顯示說明，不偷偷切 AppData。
3. 建立三種畫布、保存關閉重開、垃圾桶還原，舊資料與未知欄位往返。
4. 中文手寫快速曲線無回折、懸停範圍與實際筆刷／橡皮擦一致、擦拭不影響圖片與文字。
5. 文字／便簽輸入／捲動、三點三角形與頂點拖拽、尺與圖釘、圖片拖入和縮圖。
6. 120Hz 與 4K 實機做效能量測並記錄設備、驅動、資料規模與 frame／latency 分布。
