# Microsoft Store 1.1.4 更新說明

## 正體中文（zh-TW）

- 多頁 PDF 按頁載入可見圖片。螢幕畫布減少畫筆、橡皮擦和雷射的重繪範圍。
- 物件可水平或垂直翻轉。一般畫布可從右鍵選單新增圖釘；切換工具時，輪盤格位維持原設定。

## 简体中文（zh-CN）

- 多页 PDF 按页加载可见图片。屏幕画布缩小画笔、橡皮擦和激光笔的重绘范围。
- 对象支持水平和垂直翻转。普通画布可从右键菜单新增图钉；切换工具时保留转盘位置。

## English（en）

- Multi-page PDFs load visible images one page at a time. The screen canvas redraws smaller areas when using the pen, eraser, and laser.
- Flip objects horizontally or vertically. Add pins from the canvas context menu, and switch tools without rearranging wheel slots.

## 日本語（ja）

- 複数ページの PDF は表示ページの画像を読み込みます。画面キャンバスのペン、消しゴム、レーザーの再描画範囲を縮小しました。
- オブジェクトの左右・上下反転に対応しました。通常のキャンバスでは右クリックからピンを追加でき、ツール切り替え時もホイールの配置を保持します。

## 한국어（ko）

- 여러 페이지의 PDF는 현재 페이지에 표시되는 이미지를 불러옵니다. 화면 캔버스에서 펜, 지우개, 레이저를 사용할 때 다시 그리는 영역을 줄였습니다.
- 개체를 가로 또는 세로로 뒤집을 수 있습니다. 일반 캔버스의 오른쪽 클릭 메뉴에서 핀을 추가할 수 있으며, 도구를 바꿔도 휠의 배치는 유지됩니다.

## Español（es）

- Los PDF de varias páginas cargan las imágenes visibles página por página. El lienzo de pantalla redibuja áreas más pequeñas al usar el lápiz, el borrador y el láser.
- Voltea objetos horizontal o verticalmente. Añade marcadores desde el menú contextual del lienzo y cambia de herramienta sin alterar la posición de la rueda.

## Français（fr）

- Les PDF multipages chargent les images visibles page par page. Le canevas d’écran redessine une zone plus petite lors de l’utilisation du stylet, de la gomme et du laser.
- Retournez les objets horizontalement ou verticalement. Ajoutez des repères depuis le menu contextuel du canevas. Les outils conservent leur place dans la roue.

## Deutsch（de）

- Mehrseitige PDFs laden sichtbare Bilder seitenweise. Auf der Bildschirm-Leinwand werden beim Einsatz von Stift, Radierer und Laser kleinere Bereiche neu gezeichnet.
- Objekte lassen sich horizontal und vertikal spiegeln. Markierungen können über das Kontextmenü hinzugefügt werden. Die Belegung des Werkzeugsrads bleibt beim Wechsel erhalten.

## Português (Brasil)（pt-BR）

- PDFs com várias páginas carregam as imagens visíveis página por página. A tela de desenho sobre a tela redesenha áreas menores ao usar a caneta, a borracha e o laser.
- Inverta objetos na horizontal ou na vertical. Adicione marcadores pelo menu de contexto e troque de ferramenta mantendo as posições da roda.

## العربية（ar）

- تُحمّل الصور الظاهرة في ملفات PDF متعددة الصفحات صفحةً بصفحة. تعيد لوحة الشاشة رسم مساحة أصغر عند استخدام القلم والممحاة والليزر.
- اقلب العناصر أفقيًا أو عموديًا. أضف دبابيس من قائمة السياق، وبدّل الأدوات مع بقاء خانات العجلة في أماكنها.

## runFullTrust

HeiBan is a WinUI 3 desktop whiteboard app. runFullTrust is required to run its packaged desktop executable and use desktop APIs for local files, clipboard images, global shortcuts, screen annotation, and an optional right-button tool wheel in screen operation mode. It runs at medium integrity without requesting administrator privileges.
