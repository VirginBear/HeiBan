# HeiBan 1.0.15 Microsoft Store 更新

## 此版本的新增功能（可貼入商店欄位）

- 支援 PDF 頁面匯入與多頁 PDF 匯出；安裝桌面版 PowerPoint 時，可匯入 PPT／PPTX 為可註記圖片頁。
- 改善磁鐵吸附、連續繪圖、圖形參考點與雙擊調整物件的操作。
- 提供圖示／圖文分頁工具列、自訂常用工具與圖層拖曳位置提示。
- 新增原創磁吸板擦，工具列「更多」可切換顯示；擦除範圍跟隨斜放輪廓。
- 更新十種介面語言與離線使用說明，統一紙白與綠色介面。
- 提供自動存檔開關，預設關閉；正常離開時顯示存檔進度。
