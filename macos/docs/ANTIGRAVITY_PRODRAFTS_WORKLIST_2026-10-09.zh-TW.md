## 2. 開工規則與架構決定

1. 先記錄 `git status`，讀目前程式與上述文件；保留所有未提交內容。已有工具列自訂、附近操作列、HUD 和圖釘搜尋程式，先整合和補缺。
2. 程式、資源、腳本與產物放在 `macos/`。不得修改 `windows/`、Windows 發行產物、Web 程式或替它們重新打包。文件契約新增內容可以記錄未來相容要求，但不在本輪同步實作其他平台。
3. 沿用 Swift＋SwiftUI＋AppKit：SwiftUI 管浮動面板，AppKit 管桌面輸入，`HeiBanCore` 管幾何、文件、命令與保存。保持原生離線工作流程。
4. **把永久內容、操作中的預覽、桌面工具分開。** 圓弧、膠帶、畫框、導圖等屬永久內容；圓規輔助線、雷射軌跡、游標、HUD 屬暫時圖層；計算機／計時器與工具列位置屬工作區狀態。只有使用者插入結果或完成內容編輯才修改作品。
5. 在目前架構上按功能增加小模組；建議 `Compasses/Calculator/Timer` 對應獨立 coordinator／model，視圖放 `HeiBanMac/Views/Tools/`。不得把全部新 UI、計時 tick、運算 parser 和媒體解碼繼續塞進 `BoardEngine.swift`。
6. 所有工具入口使用共同命令註冊，覆用右鍵／附近列／快捷鍵；將「內容可編輯」「可以作為預設工具」等能力明訂，不用一長串字串判斷湊出假入口。
7. 新物件採文件契約的可版本化擴充。先定欄位、遷移、未知欄位保留、資產引用和舊版讀取行為，再接保存。不能只畫一張不可編輯圖片冒充導圖、表格或圓弧。
8. 每批都有可編譯 Mac 成品、操作證據和未通過項。編譯成功、舊斷言數、程式檔存在，都不能替代互動／效能驗收。此工作單本次未執行程式測試，也未重新打包 App。

### 邊界與資料流

```text
工具列／＋／右鍵／鍵盤
          ↓ 共同命令與輸入路由
暫時工具 coordinator → 局部預覽 overlay（不修改作品）
          ↓ 完成一次編輯交易
文件物件＋資產引用 → 畫布 renderer → 自動保存／載入
                                  → 縮圖／PNG／SVG／PDF
計算機／計時器 → 工作區面板（獨立更新）
              →「插入結果」才提交文字物件
```

## 3. 介面規格：頂列要直接改版

### 正常編輯時的布局

- **右上膠囊**：回到作品庫、閱讀／書寫切換、統一圖釘、畫布搜尋、＋插入、更多。首版可先接目前已可用功能；尚未實作的搜尋不得顯示可按的空入口。
- 標題不再以常駐大文字輸入框撐開頂列；放在「更多 → 筆記資訊」中改名。保存狀態用固定位置的小狀態指示，滑鼠停留／點開看詳情，錯誤必須可見，不隱藏保存失敗。
- **＋插入**：文字、便簽、圖片／截圖、畫板、思維導圖、表格、公式、貼紙、影音、附件／PDF、圓規、計算機、計時器；分「內容」與「輔助工具」兩組。隨各功能真正可用才開放入口。
- **更多**：筆記資訊／改名、背景／格線、圖層、屬性、文件開啟／另存／匯出、工具列自訂、沉浸模式、偏好。文件鎖定等尚未完成項按階段接入。
- **繪圖工具列**：預設只顯示選取、筆刷群組、橡皮擦、圖形、尺規、復原／重做、更多；曲線、螢光、油漆等由群組到達，仍可固定到常用列。保留四邊停靠與浮動。
- **左下膠囊**：倍率、＋／−、適合內容、回原點、視角鎖定。筆記本翻頁移到下方中央或可收合頁面側欄，無邊界黑板不顯示翻頁。
- 選取物件才顯示附近操作列；詳細屬性維持右側書籤，點開才展開。閱讀模式保留小導航，沒有大側欄。

### 尺寸、事件與自適應

初始設計目標：頂列高度約 44 pt、常駐按鈕點擊區至少 32×32 pt、一般預設寬度不超過 280 pt；這些是待驗收的 HeiBan 規格，並非從影片精確測得。用視窗剩餘寬度計算溢出，次要項收進更多。使用者自訂較多項時不超出可用區域。

在 960×640、1280×800、大視窗與全螢幕均查核：導覽、頂端停靠工具列、尺、附近操作列不互擋；透明空間不攔截畫布事件。拖曳繪圖列時不反覆變換排列，放開後才確定左右直排／上下橫排。

### [ ] AGM-01 — 精簡右上頂列與畫布布局

依第 3 節直接修改 `TopNavView`、`ReadingNavigationView`、`MainWindowView`，搬移筆記本頁面控制與改名入口；保留圖釘搜尋、背景、匯出、圖層、屬性等現有能力。沉浸模式可暫藏控制，Esc／可見喚回入口恢復，避免使用者找不到操作。

**驗收 M01**：預設畫面沒有滿寬導航背景與大標題輸入框。上述四種視窗情境與工具列四邊停靠都不遮擋；所有舊功能有可到達入口；保存文字變更不推動其他控制；保存失敗明確呈現。閱讀／編輯／沉浸切換不改內容，文字編輯的滾輪仍交由文字視窗。

### [ ] AGM-02 — 導覽／繪圖工具註冊與自訂

沿用 `ToolbarPreferences` 與 `ToolbarCustomizeSheet`；新增頂列常用入口的獨立偏好。設定顯示、隱藏、排序、恢復預設；預設繪圖列不再把 18 項全部攤開。已註冊的功能即使隱藏仍能從更多／＋啟用；新加入功能不覆寫使用者排序。

**驗收 M02**：重新開啟保留兩列各自的配置；不存在重複／未知 id 導致空白按鈕；必要退出／選取入口可到達。窄視窗溢出能操作，拖曳沒有排列閃動；快捷鍵與按鈕呼叫同一命令。

### [ ] AGM-03 — 真正可用的浮動計算機（第一批）

建立獨立 `CalculatorModel` 與可移動、可收合／關閉的原生面板。先完成小數、正負、百分比、加減乘除、等號、清除／清一項、退格，支援滑鼠與鍵盤；再在同項目完成括號、平方／次方、平方根、倒數、科學模式的 sin／cos／tan／log／ln 與角度／弧度設定。提供運算歷史、拷貝結果、把結果／算式插入文字物件。

用明確的運算狀態機／parser 計算，訂定優先順序、重複等號、百分比及捨入規則；基本十進位避免顯示 `0.30000000000000004`。超出有效範圍／除零／非法函數輸入顯示錯誤，不能出現無窮或崩潰。影片未展開換算圖示；單位換算不算本項已確認需求，完整科學功能是黑板開發規格。

**驗收 M03**：`89×63=5607`、`0.1+0.2=0.3`、`(2+3)×4=20`、`200+10%=220`、`200×10%=20`、`sqrt(9)=3`，角度模式 `sin(30)=0.5`；除零可恢復。面板聚焦時數字／刪除／空白不操作畫布。移動／運算不觸發作品自動保存；插入結果可一次復原、保存重開仍為可編輯文字。科學模式未完成時本項只能標為部分完成。

### [ ] AGM-04 — 圓規與可編輯圓弧（第一批）

定義精確圓弧資料：世界座標中心、半徑、起始角、帶方向的掃角；完整圓可覆用現有 circle，圓弧新增有版本的型別／欄位。幾何命中、bounds、變形和輸出共用計算，不能用自由手繪點列冒充可調精確圓弧。

圓規操作：拖中心平移；拖半徑端點調半徑；點 R 輸入值；顯示虛線圓周、中心與半徑端點；在繪製模式以拖動沿圓周畫弧，明確區分「調半徑」與「落筆」。提供畫完整圓指令、正／反向、起角／掃角數值到 0.1°。放開提交物件，依使用者要求回選取；可保留圓規參數再次啟用。

**驗收 M04**：100%／400%／800% 縮放下中心／半徑使用相同世界座標，控制點維持可點尺寸。圓弧跨越 0° 不跳；近中心輸入不產生 NaN；半徑 0／負值／無限值被拒絕。生成後可拖中心、半徑、弧端點和改線色、粗細、透明度、虛線；一次手勢一次復原。保存／重開仍可編輯；SVG／PDF／PNG／縮圖結果一致。輔助虛線不進文件／匯出，圓規可移動且不吞掉空白鍵／中鍵平移。

### [ ] AGM-05 — 正計時與倒數計時（第一批）

獨立 `TimerCoordinator` 管理正計時開始／暫停／續行／重設與倒數時分秒設定、5／15／25 分鐘預設，到時提示及關閉。浮窗可移動／收合，讀數等寬。訂定切換筆記、背景、睡眠喚醒時的行為：同一工作區計時繼續；睡眠時間計入經過時間；暫停時間不計。

使用可校正的時間基準與明確 deadline，不靠每個 tick 累加；重啟恢復要處理剩餘時間和時鐘變更。只更新面板，避免整個 `BoardEngine` 每 10ms 發布變化。時間是工作區狀態；需要時可「插入本次用時」成文字。

**驗收 M05**：60 秒正／倒計時、暂停10秒、背景與睡眠喚醒，時間符合已定規則；0／負值／超界輸入有回饋，到時不重複提示。開著計時器能正常畫線／改字；工作區計時不修改作品，也不降低 A01／A02 的表現。

### [ ] AGM-06 — 雷射筆與臨時指示圖層

完成光點、短尾跡、線條模式；色彩、粗細、白色光芯與淡出時間可設定。使用局部暫時 overlay，不經持久物件清單；模式切換、換頁、返回首頁、視窗失焦要有清理規則。

### [ ] AGM-07 — 遮題膠帶與揭示操作

新增遮題物件，包含直線帶、自由筆帶、矩形帶；可調尺寸、粗細、顏色、透明度、樣式、移動、旋轉、圖層和鎖定。點一下顯示底下內容，再點遮回；全部顯示／全部隱藏。保留底下原始文字、圖片與筆跡，不能把它們擦掉或烘焙成一張圖。

**驗收 M07**：遮題範圍與外觀相符，揭示不啟動文字輸入；編輯與閱讀模式的點擊語意清楚。保存重開保留膠帶形狀與設定；全局臨時揭示狀態不使原內容失真。匯出提供「目前遮題狀態／展開內容」，縮圖遵守同一選擇；新型別不默認加入橡皮擦可擦清單。

### [ ] AGM-08 — 筆刷、尺規、橡皮擦與色盤補齊

把筆刷放入統一就近面板：線色、粗細、透明度、圓形色盤、常用色；填色具有獨立透明度與漸層。筆刷類型分為向量／單線、鋼筆、鉛筆、水彩、螢光、蠟筆、蘆葦／書法與油漆；使用原生可用的壓力／筆尖方向資料，滑鼠有穩定預設。各類外觀與預覽要有可辨識差異，不能只換名字。新增紋理型筆刷需記錄點／樣式種子，重開可重現。

保留螢幕空間尺的移動、旋轉、0.1° 數值輸入、刻度、白／暗底自適應及自訂字色；旋轉支點不要擋數字。另加世界座標標尺（R10），可關閉、隨平移縮放正確更新。尺邊吸附在一筆內穩定，游標超出尺身不突然畫歪；與舊 A13 的端點描述有衝突時，以使用者最新的直線穩定需求記錄並修訂驗收規格。

**驗收 M08**：每種筆刷能改樣式、記住偏好、重開／輸出一致；畫筆大小預覽與實際點徑在同倍率相符。兩種橡皮擦在按下前都有半透明範圍，大小等於實際命中範圍；僅擦筆畫／幾何，不擦圖片、文字、便簽或新增結構化物件。尺身拖曳不頓、角度可輸入，旋轉中心與標字不重疊；白／暗底可讀。混合螢光註記不遮住文字；A01、A13、A14 持續適用。

### [ ] AGM-09 — 幾何、多邊形、連接線與辨識偏好

保留三角形3次點、四邊形4次點建立與後續頂點拖曳；矩形／菱形／五角形／星形可調長寬與旋轉。補圓角矩形、可調邊數多邊形、折線／連接線，箭頭大小、端點型別與多種虛線。連接線可附著物件並隨它移動，移除目標有明確處理。

形狀辨識、完成後選取、自動填色獨立設定；預設完成幾何物件回選取。自由曲線仍可編輯，與圓規精確圓弧分開。直線／箭頭保留獨立 A/B 端點與不延伸、A 延伸、B 延伸、雙向延伸，不以矩形選取框取代端點，也不在反向拖曳時交換方向。

**驗收 M09**：逐點有連線預覽，Esc 取消不留物件；拖頂點不誤移整體。筆跡辨識不誤轉正常書寫；端點、虛線、箭頭與旋轉可保存、復原、匯出，附近 HUD 不遮控制點。完成一次圖形會回選取。

**驗收 M15**：系統截圖拖入、桌面 PNG 打開、貼入與保存重開均可；圖片／貼紙可移動、縮放、旋轉、裁切與調透明度。刪原始桌面檔後作品仍可用；另存／搬移文件資產不遺失，損壞圖檔有回饋。首頁、選取截圖與輸出顯示內容，橡皮擦保護圖片和貼紙。

### [ ] AGM-16 — 影片、GIF、相機、錄音與掃描

分段交付且保留同一工作狀態明細：

1. 影片／GIF：畫布上的媒體物件、縮圖／海報、播放／暫停／定位、聲量、離開可見區／作品時停止或依設定暫停。

3. 錄音：開始、暫停、結束、命名、列表、播放／定位、0.75／1／1.25／1.5／2 倍速，原始音檔保存。降噪另外保留處理後衍生檔與撤回入口；效果另驗收，不以錄影的無參考價值聲音判斷。
4. 掃描文稿：先完成匯入相片／PDF、裁切、透視校正和多頁排序；相容硬體可提供系統掃描來源，不將 iPad 專用入口照搬為空按鈕。
