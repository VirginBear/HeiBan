01開始使用

先有一張紙，再讓想法延伸。

  1. 在首頁按「＋」，選擇筆記本、無邊界畫布或有邊界黑板。
  2. 輸入名稱；尺寸與背景的進階設定收在新增視窗。
  3. 選畫筆開始寫畫；需要整理時切到選取工具。
  4. 內容會自動存到本機；需要帶走作品時，另存 .heiban。
這份手冊不會建立任何示範作品。需要示範時，再從首頁「使用說明 → 建立功能示範黑板」主動開啟。

02首頁與作品庫

用內容縮圖辨識作品。

首頁縮圖顯示內容，類型圖示區分筆記本、無邊界畫布、有邊界黑板。按作品開啟；按作品旁的更多選單可重新命名、收藏或移到垃圾桶。

  • 搜尋／篩選：以名稱找作品，依格式縮小範圍。
  • 批次選取：進入選取模式，勾選作品，再移到垃圾桶。
  • 收藏：常用作品可加入收藏，從左側快速開啟。
  • 垃圾桶：可還原作品，或永久刪除；永久刪除前請保留備份。
  • 側欄：左上側欄按鈕可收合，留出更多縮圖空間。
  • 新增：用＋開啟精簡建立介面，不需在首頁保留大幅設定區。

03三種畫布與背景

選擇適合內容的範圍。

格式適用情境操作
筆記本會議、課程、多頁筆記底部切換、增加頁面；頁面內容各自保存
無邊界畫布草圖、腦力激盪、大型整理可往各方向平移與延伸
有邊界黑板單張圖、簡報與固定尺寸在既定紙張範圍內組織內容

上方更多選單可改背景主題，或開啟自訂背景與格線。支援黑板、深色、白板、網格、點陣、橫線、五線譜與純空白等設定；尺寸預設包括 A4、A3、B5、16:9、4:3、1:1、9:16 與自訂。

筆記本由底部頁碼與＋頁導覽；刪頁請使用頁面選單，並留意該頁內容。

04移動畫布與縮放

滑鼠在哪裡，就以哪裡為縮放基準。

  • 滑鼠滾輪：以游標下的畫布位置為中心放大／縮小。
  • 中鍵按住拖曳：平移畫布。
  • 空白鍵＋左鍵拖曳：暫時平移，放開空白鍵回到原工具。
  • 觸控板：兩指平移，雙指捏合縮放。
  • 縮放鎖定：鎖定後避免操作時誤改視角；需要導覽時先解鎖。
  • 閱讀模式：瀏覽內容，避免誤畫或改物件。
  • 沉浸模式：由更多選單開啟，減少介面遮擋。
編輯文字與便條紙時，滾輪只作用於文字編輯區；游標放回畫布後才縮放畫布。

05安排工具列與屬性

把常用工具放在手邊。

拖曳工具列的握把移動；靠上下邊緣變橫排，靠左右變直排。也能由停靠選單直接指定四邊。工具列會依可用長度安排，工具多時可捲動或從更多工具選取。

「自訂工具列」可調整顯示工具及順序。隱藏的工具仍可從工具列更多選單使用。

「屬性」預設可收成小標籤，點開才顯示。拖曳屬性標籤／標題可停靠四邊：左右是直向面板；上下使用橫向分區，把色彩、線條、物件分欄。窄視窗可橫向捲動，各欄長內容能垂直捲動。

屬性只改已選取物件；畫筆按鈕旁的色彩與粗細則是下一筆的設定。兩者用途不同。

06畫筆與筆刷

粗細預覽會跟著目前縮放顯示。

點畫筆，再點工具列的顏色圓點開啟筆刷設定。可選向量單線、鋼筆、鉛筆、水彩、螢光筆、蠟筆、書法與油漆刷；不同筆刷對壓力與紋理的處理不同。

  1. 選筆刷類型。
  2. 選色票、最近色彩，或自訂顏色。
  3. 設定筆寬與透明度；預覽圓會換算目前畫布縮放，標示畫布上實際直徑。
  4. 拖曳繪製。完成的筆畫仍是可選取物件。

繪圖板有提供 NSEvent 筆壓時，壓感筆刷使用壓力；普通滑鼠無法提供真正的筆壓。畫完後可選筆畫調整色彩與粗細。

筆畫停留識別可協助拉直與辨識簡單圖形；若要精確可編輯幾何，請用圖形工具。

07圖形、曲線與頂點

先生成，再調整。

  • 直線／箭頭：拖曳定義兩端；選取後移動端點，屬性中設定線條和箭頭大小。
  • 矩形、圓、圓角矩形、菱形、多邊形與星形：從圖形工具選取，拖曳建立；完成後自動回到選取。
  • 三角形：依序點第一點、第二點、第三點；第二點起可看到連線，第三點完成物件。
  • 四點圖形：依序點四個點，最後一點閉合。
  • 頂點：選取三角形或四點圖形，拖曳頂點調整形狀。
  • 連接線：從幾何形狀選單選連接線，拖曳建立，再調整端點。
  • 曲線：用曲線工具建立弧線，選取後拖曳其控制點調整。
  • 尺寸／旋轉：選取物件後拖曳控制點，或從屬性調整角度。

線段／箭頭的延伸選項可設定兩端是否延伸。生成過程按 Esc 取消尚未完成的圖形。

08選取、物件與圖層

物件是可以再編輯的。

用選取工具點物件；拖曳空白處框選，或使用套索。Shift 可搭配多選。拖物件移動；邊界控制點調整尺寸，旋轉把手調整角度。

  • 右鍵：依位置與選取狀態提供複製、剪下、貼上、克隆、刪除等操作。
  • 複製／克隆：複製搭配貼上；克隆直接產生另一份。
  • 群組：多選後群組，一起移動；解組可再逐一調整。
  • 物件快速列：選取後顯示精簡操作，完整設定放在屬性。
  • 圖層：更多 → 物件圖層；調整排序、名稱、可見與鎖定，便於處理重疊物件。
  • 復原／重做：修改失誤可復原；重新開啟作品不保留整段操作歷史。

09色彩、填色與線條

先選物件，才會有可調整的屬性。

屬性中的圓形色票、系統色彩選擇器可改線條色與填色；填色可選無填色，並獨立調整填色透明度。另有物件整體透明度。

  • 線條：粗細、實線、虛線、點線、點劃線。
  • 箭頭：可調箭頭頭部長度與寬度。
  • 漸層：屬性中的「漸層填色」開關與起點／終點色；適用可填色的圖形，實際呈現依物件種類。
  • 多選：不同值會顯示「混合」；調整後套用到支援此屬性的選取物件。
  • 便條紙：樣式、底色色盤、文字溢出與自動擴展。
圖片的透明度與位置可調整；筆刷是用於畫新的內容，不會把 PNG 原本的像素拆成可編輯向量。

10文字與便條紙

直接在物件上輸入。

選 T 文字工具，點畫布建立文字。便條紙工具先建立實體便條紙，再於紙上輸入；雙擊已有文字或便條紙再次編輯。

編輯區提供字體、大小、文字顏色及基本排版；輸入法組字期間保留中文輸入，文字選取與編輯快捷鍵由文字區處理。按 Esc 完成或退出目前編輯，再回畫布操作。

文字太多時可調整物件尺寸；便條紙屬性可自動擴展高度。編輯區捲動不會帶動畫布縮放。

11橡皮擦

先看範圍，再決定要擦多少。

  1. 點橡皮擦；再次點擊開啟模式與大小設定。
  2. 游標即使未按下，也顯示半透明擦除範圍。
  3. 物件擦除：碰到可擦筆畫／圖形時移除該物件。
  4. 像素擦除：只擦筆畫的局部範圍，保留其餘部分；目前以向量筆畫切割實作，不是修改圖片像素。

圖片、文字和便條紙受到保護；要移除它們，請選取後 Delete 或使用右鍵刪除。橡皮擦大小可調整，範圍依畫布縮放換算。擦錯可用 ⌘Z。

12尺規

拖位置、轉角度，再沿邊畫線。

  1. 啟用尺規；拖尺身移動。
  2. 拖旋轉把手調整角度；設定中亦可直接輸入角度，精度到小數點後一位。
  3. 尺上有刻度；配色預設自適應背景，也可自行指定，亮底與暗底均需保持可讀。
  4. 用畫筆沿尺邊繪製，尺規會約束線段方向。

尺規設定可從工具按鈕的設定入口開啟；輔助尺是暫時工具，不會出現在匯出圖片中。

13圓規：準備 → 鎖定 → 畫弧

點圓心是開始繪製的明確分界。

1準備

拖圓心改位置，拖半徑把手改半徑，拖筆尖設定弧線起點。此時不會畫線。

2鎖定

點一次圓心，圓心變橘色。中心和半徑鎖住，筆尖準備繪製。

3畫弧

拖筆尖順時針或逆時針畫弧；放開後建立可選取的圓弧，工具回到選取。

起點不會因第一個滑鼠移動取樣而改變；跨越 0° 時連續計算弧度。鎖定後再次點圓心可退回準備。單純拖準備中的筆尖、不動筆尖或按關閉，均不會偷偷建立整圓。

需要整圓可明確按「整圓」。生成物件使用目前色彩與粗細，後續可從屬性調整。

14雷射筆

工具在哪裡，設定就在那裡。

  1. 點雷射筆啟用；移動滑鼠即可顯示光點與尾跡，按住拖曳也可以。
  2. 再點一次雷射筆按鈕，開啟設定；右鍵也有設定入口。
  3. 選光點、短尾跡或線條；光點模式刻意沒有尾跡。
  4. 調整光點直徑、尾跡粗細、消退時間、色彩和白色亮芯。
  5. 切換其他工具即可停止。

光點以螢幕 pt 顯示，不因畫布縮放變大或變小。短尾跡最長 0.8 秒；線條可保留到設定的消退時間。設定保存在本機偏好。

雷射是暫時演示效果，不加入作品、不作為永久筆畫匯出。螢幕截圖則會捕捉截圖當下仍可見的光點。

15計算機與倒數計時

從＋輔助工具開啟。

遮題膠帶：工具列的眼睛遮蔽圖示可建立膠帶，拖曳覆蓋答案。閱讀模式點膠帶揭示／再次遮住，適合講課提問；編輯模式可選取調整範圍。

計算機：上方＋ → 計算機。浮動面板提供一般／科學計算與歷史；拖標題移動，點按鍵操作。關閉後仍可再從＋呼叫。

計時器：＋ → 計時器。選倒數／計時、輸入時間或選預設，按開始、暫停、重設；關閉後可再次叫回。計時狀態與面板顯示分開管理。

移動面板請拖標題區；按輸入區或按鈕只操作內容，不會觸發整個面板的移動。

16圖片與截圖置入

把電腦上的素材放進作品。

將桌面圖片或 macOS 截圖浮動縮圖拖進畫布；亦可用＋ → 圖片匯入，或從剪貼簿貼上圖片。

常見 PNG、JPEG、GIF、BMP、TIFF、WebP 等由 macOS 圖片解碼支援；個別檔案仍可能因格式變體或損壞無法開啟。GIF 不作為持續播放動畫。HEIC 等拖放是否可用依系統解碼，匯入對話框目前有格式限制。

圖片是一個可移動、縮放、旋轉、調透明度與疊加註記的物件；不提供完整照片像素修圖器。保存 .heiban 可保留圖片與其上的筆畫；匯出 PNG 則得到合成結果。

App 內截圖：＋ → 截圖置入。若已有有效錄製權限可直接擷取；否則使用 macOS 系統螢幕選取器授權這次擷取，再選取區域置入。Esc 取消。

開發版更新後，舊版權限可能不再對應目前的 App；可使用系統選取器，或在「隱私權與安全性 → 螢幕與系統音訊錄製」確認目前這份黑板。DRM 保護影像可能無法擷取。

17圖釘導覽

讓重要區域隨時回得去。

圖釘會出現在畫布上，並採用一致的斜向圖釘圖示。可設定名字、調整位置，從圖釘導覽清單返回該位置與視角。

新增圖釘前先移到想標記的區域；從圖釘面板新增並命名。之後選取或拖曳圖釘調整位置，透過清單改名或刪除。圖釘是導覽標記，與便條紙的裝飾圖案用途不同。

18我的螢幕就是我的畫布

在直播、影片或講解上加一層透明紙。

從上方＋輔助工具、首頁使用說明、macOS「螢幕畫布」選單或選單列圖示開啟。黑板保持運行時，也可直接按全域快捷鍵。

快捷鍵動作
⌘⌥⇧D首次開啟；之後切換「作畫／操作」
Esc畫布收到鍵盤焦點時暫停作畫
⌘⌥⇧S截取目前螢幕與註記，另存 PNG
⌘⌥⇧X結束透明畫布並保存註記
畫作畫

透明畫布接收滑鼠。用畫筆、螢光筆、線條、箭頭、矩形、圓、橡皮擦或雷射演示。

用操作

註記仍可見，滑鼠穿透到背後程式。可播放、捲動、切換投影片，再回到作畫。

存保存

PNG 包含螢幕畫面；.heiban 保存可編輯註記，沒有背後螢幕影像。

  • 背後程式繼續運行，黑板不會暫停影片或動畫。空白區域也可直接落筆，第一次點擊不需先啟動黑板。為維持原生透明視窗的輸入覆蓋，螢幕會有約 1% 的淡色遮罩。
  • 控制列保持可點擊，可拖空白握把區移動；更多選單可清除、儲存註記與開手冊。
  • 每個顯示器有獨立透明畫布；滑鼠移到另一螢幕會切換其復原／重做操作對象。
  • 註記會獨立自動暫存，結束時也保存；再次開啟可還原。下一場講解可先清除舊註記。
  • 切換作畫狀態前請放開滑鼠，避免取消尚未完成的筆畫。切回作畫會保留工具、顏色與粗細；在操作模式點畫筆或形狀，也會直接恢復作畫。
  • 顯示器配置改變時結束本次疊層，以免座標錯位，重新開啟即可。
  • 快捷鍵被其他 App 佔用時用控制列／選單操作；此功能不要求輔助使用或輸入監控權限。截圖仍需系統允許。
疊層使用高於普通浮動視窗的位階，並加入其他 App 的全螢幕空間；多顯示器與特殊全螢幕仍需實機確認。系統安全畫面、受保護影片或特殊獨佔全螢幕可能不顯示。螢幕分享請選整個顯示器：只分享單一 App 視窗時，外部透明疊層未必包含在分享內容中。

19儲存、暫存與匯出

保留原作，才有下一次編輯。

檔案用途重新編輯

PNG合成圖片可置入註記，但原物件會合成

⌘S 或更多 → 另存黑板專案，預設產生 .heiban。Finder 雙擊 .heiban 可交由黑板開啟。開啟外部作品會載入本機工作階段；後續自動儲存寫本機作品庫，不會持續覆寫原外部檔，需要更新外部檔請再次另存。

.heiban 第一版是有版本欄位的 UTF-8 JSON，圖片內嵌，檔案單獨攜帶即可。它不是把螢幕拍成一張圖片，也不依賴 Swift 私有序列化，為未來跨平台讀取保留空間。

本機資料位於 ~/Library/Application Support/HeiBan/：作品在 Boards，最近工作在 current.blackboard.json，備份在 Backups；螢幕註記另外放在 ScreenAnnotations/display-顯示器ID.heiban。一般作品暫存沿用既有名稱，避免破壞舊資料。

自動儲存有短暫延遲；新筆畫完成後約 0.7 秒排程，螢幕註記約 0.8 秒。寫檔使用原子替換。重要作品仍請另存並備份；不要只依賴最近工作檔。註記暫存無法解析時會保留原檔，不用空白內容覆蓋。
