# macOS 1.0.9 · 螢幕畫布工具列與清空

日期：2026-10-10。Build：20261010.1。本機開發版，尚未更新 GitHub 下載版。

## 操作

- 拖曳螢幕畫布工具列的左上握把，到螢幕上／下／左／右後放開；左右自動直排、上下橫排。
- 也可按「⋯ → 工具列位置」直接選停靠邊；下次開啟記住邊、沿邊位置與顯示器。
- 拖動中維持原尺寸，放開才轉向；短螢幕的直排工具區可捲動，清空與結束始終保留。
- 垃圾桶按鈕是「一鍵清空畫布」：清空所有螢幕的註記與暫態預覽，不跳首頁、不結束透明畫布、不切換作畫／穿透模式。
- 已提交物件可在各螢幕復原；雷射與尚未完成筆畫不屬於歷史。清空後立即寫恢復檔，若寫入失敗顯示訊息。
- 清空亦可從更多、macOS「螢幕畫布」選單與選單列圖示操作；「×」才是結束。
