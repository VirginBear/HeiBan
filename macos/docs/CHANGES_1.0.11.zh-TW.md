# macOS 1.0.11 · 共用筆色設定與單列工具列

日期：2026-10-10。Build：20261010.3。本機開發版，GitHub 公開下載版未更新。

## 改善與操作

- 螢幕畫布四邊均點色圓開啟顏色／粗細／透明度設定。
- 設定面板改為 280 pt 寬、3×2 色票與直排全寬滑桿，面板內明訂純色圓按鈕樣式及自然內容尺寸，修正兩端裁切的排版缺口。
- 上／下工具列改為一列，高度由 132 pt 降為 60 pt；移除常駐色盤、滑桿與狀態列。色圓／清空／結束固定可見，其他工具可捲動。
- 左／右繼續為 64 pt 純圖示窄版。狀態訊息可從色圓設定面板、更多選單或模式按鈕提示查看。
- 四邊拖曳、位置記憶、一鍵清空與復原沿用既有命令；目前螢幕樣式仍由同一個 engine 保存。

## 交付與限制

本機成品位於 macos/dist/HeiBan.app；先 ⌘Q 正常退出舊行程再開新版。只保留最新 App，舊成品依既有清理政策處理；Windows 不改。
