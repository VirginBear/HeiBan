# macOS 1.0.12 · 螢幕畫布文字與右鍵設定

日期：2026-10-10。Build：20261010.4。本機開發版；GitHub 公開下載尚未更新。

## 使用方式

- 「我的螢幕就是我的畫布」工具列新增 **T**。作畫模式點 T，再點螢幕位置輸入；Enter 換行、⌘Enter／完成提交，Esc 取消。
- 完成後用選取工具雙擊文字框，或右鍵 → 編輯文字內容，可再次修改。
- 文字框右鍵提供文字大小、文字顏色、粗體、斜體與底線。「更多文字設定」可輸入 8–144 pt、自訂 #RRGGBB、字體名稱、對齊與不透明度。
- 先框選或 Shift 點選多個文字框，再右鍵其中已選取的文字框，即可批次調整。選取集合保留，只修改本頁未鎖定的文字／便簽；圖片及圖形不受文字命令影響。
- 更多設定只套用修改的欄位，不把混合值默默設為第一個物件的值；一次套用是一筆可復原修改。
- 輸入中可對原生文字區右鍵，調整目前草稿整個文字框；完成前不寫文件。輸入區收起常駐格式列，普通 Mac 畫布亦共用此入口。
- 暫停螢幕作畫、換工具、儲存原稿、截圖或結束前先提交文字；保留 .heiban 格式與獨立螢幕恢復檔。Esc 在文字輸入時先由文字區處理。

## 交付與限制

最新版位於 macos/dist/HeiBan.app；先 ⌘Q 正常退出舊行程再開新版。只保留最新 App，原始碼／開發文件／作品保留。Windows 未修改。
