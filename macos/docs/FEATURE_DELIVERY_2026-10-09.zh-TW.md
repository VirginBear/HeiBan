# Mac 1.0.6：圓規、屬性、雷射、螢幕畫布與手冊交付

日期：2026-10-09。成品：`macos/dist/HeiBan.app`，版本 1.0.6（20261009.5），Apple Silicon 原生 Release。

本頁記錄本輪實作與觀察，不能代替完整效能、長時間使用或所有 ProDrafts 工作項目的驗收。既有 Windows／Web 變更屬先前工作，本輪只修改 `macos/`。

## 已實作

- [x] 圓規準備時移動圓心、調半徑、設定筆尖起點，不提交筆畫。
- [x] 點圓心切換作畫鎖定，圓心橘色；再次點擊回到準備。
- [x] 作畫保留準備好的起點，跨 0° 累計弧度；放開才提交可編輯 arc，沒有移動不產生整圓。整圓為獨立按鈕。
- [x] 圓規預覽放入實際畫布座標空間，避免視窗頂部安全區造成偏移。
- [x] 屬性上下停靠使用色彩／線條／物件三欄橫向布局，最大高度 264 pt；左右仍為直式。
- [x] 雷射移動與拖曳採樣，Canvas 每次畫面更新讀取新取樣；淡出批次渲染、有容量上限。
- [x] 再按已選用的雷射按鈕開啟附近設定，亦可右鍵；模式、光點大小、尾跡粗細、色彩、白芯、消退時間保存為偏好。
- [x] 每個顯示器建立透明原生螢幕畫布，作畫接收滑鼠，操作時滑鼠穿透，註記仍可見。
- [x] 螢幕控制列提供筆、螢光、線／箭頭、矩形／圓、橡皮擦、雷射、色彩、粗細、透明度與復原／重做。只有握把可移動控制列。
- [x] 固定全域快捷鍵、App 選單、macOS 選單列入口；衝突有可見回饋與按鈕替代。
- [x] 註記獨立自動保存、重開恢復，停止／退出先保存；保存失敗保留畫布，不丟棄內容。
- [x] 截圖隱藏控制列，保留透明註記，使用既有 ScreenCaptureKit／系統選取器服務；可另存 PNG 或可編輯註記。
- [x] 對外可編輯格式 `.heiban`，v1 UTF-8 JSON，舊 JSON 文件可開啟；文件版本與未知欄位保留、原子寫入、Finder 類型登記。
- [x] 內建離線、可搜尋使用手冊，21 章、原創圓規流程圖；涵蓋目前功能及未交付功能的界線。

## 操作入口

| 操作 | 入口／快捷鍵 |
|---|---|
| 螢幕畫布開始／作畫與操作切換 | `⌘⌥⇧D`；「螢幕畫布」選單；首頁使用說明；畫布＋輔助工具 |
| 截圖並另存 PNG | `⌘⌥⇧S`；螢幕控制列更多 |
| 結束並保存註記 | `⌘⌥⇧X`；控制列 × |
| 暫停作畫 | 畫布收到 Esc；或控制列「作畫」按鈕 |
| 原稿另存 | 普通作品 `⌘S`；螢幕控制列更多 → 儲存可編輯註記 |
| 使用手冊 | 首頁「使用說明 → 使用手冊」；輔助說明 → 黑板使用手冊 |

快捷鍵需黑板仍在執行。操作模式會把焦點交回最近使用的其他 App；一般 App 的 `⌘S` 不會被截走。螢幕分享請選整個顯示器，分享單一 App 視窗不一定包含外部註記。

## 實際確認與限制

Release 編譯、App 封裝與簽章驗證成功；已開啟最後成品。未新增或執行測試套件。

原生介面觀察已確認：

- 圓規準備時拖筆尖未產生物件；點圓心變橘，鎖定後拖曳形成 arc；復原回到原作品。
- 底部屬性為並列三欄，雷射按鈕設定可開啟，拖曳顯示消退尾跡。
- 螢幕畫布從 App 快捷鍵啟動；控制列有作畫／操作切換，切至操作顯示滑鼠穿透狀態；結束後回到作品庫。
- 使用手冊本機載入與「圓規」搜尋正常。

尚未完成真實使用驗收：

- [ ] 真實鍵盤在其他 App 前景時使用三組全域快捷鍵；自動化的按鍵送到指定 App，不能代替此驗收。
- [ ] 透明畫布在外部 App 上落筆、點選、持續播放影片與操作穿透的完整端到端流程。
- [ ] 螢幕註記 PNG 同時包含底層畫面與筆畫，且沒有浮動控制列。
- [ ] 多螢幕、顯示器拔插、Spaces、專用全螢幕與實際螢幕分享。
- [ ] 有筆畫的螢幕註記關閉／重開、檔案另存／Finder 開啟與跨平台往返。
- [ ] 端到端輸入延遲、長時間效能、不同解析度、大量圖片與大量註記。

未完成上述流程前，不宣稱所有螢幕分享／全螢幕情境已驗收，也不以編譯結果宣稱流暢度達標。這些限制不影響已交付的操作入口，但使用時應先在需要的場景確認。
