# Mac 1.0.13 公開預覽

版本：1.0.13 / 20261011.1。2026-10-11起本機開發，2026-10-13以同版本公開Mac DMG／ZIP；Windows成品不變。

## 新操作

- **右上導覽**：編輯／閱讀畫布預設收起；滑鼠移到右上原膠囊附近即顯示，也可按細箭頭。離開700ms後收起；眼睛按鈕固定／取消固定，偏好留在本機。設定或選單開著時保持顯示。
- **圖層拖曳**：從圖層按鈕／更多選單開啟面板，拖每列左側六點握把。游標帶著圖示與名稱，原列淡化；目標列上半部插上方，下半部插下方，藍線標示位置。放開才重排，Esc或列表外放開取消；⌘Z復原排序。鎖定物件先解鎖，一次移動一個物件，只操作當前頁。
- **首頁螢幕畫布**：帳號與設定上方新增入口，側欄收合後保留圖示；主作品與螢幕註記資料仍分開。

## 10/12 後續改善與公開成品

- 一般與螢幕工具列共用工具清單、圖示、自訂排序、雷射／橡皮擦／筆刷面板。螢幕排除縮放平移與圖釘，其餘工具走相同元件；清空與退出固定尾端。
- 螢幕畫布加入普通畫布的尺、圓規、便條、套索、遮題、圖片、快速列、屬性、計算機及計時器；恢復互動命中，保留原生文字輸入生命週期。
- 系統圖片貼上、線段／箭頭AB端點、旋轉點避讓、頂列收合協調、標題列雙擊普通zoom、十語入口及Mac官方發行檢查。
