## 原生架構與資料

- `HeiBanCore/Engine/BoardEngine+Navigation.swift` 管理閱讀／鎖定／縮放與作品庫移除、還原。
- `HeiBanCore/Engine/LibraryShelf.swift` 管理收藏。使用獨立 `Settings/library_shelf.json`，原子寫入；無法解析的設定原件不覆寫。
- `HeiBanMac/Views/HomeView.swift` 管理作品庫篩選、多選與視覺布局；沿用已有縮圖載入流程。
- `HeiBanMac/Views/WorkspaceNavigationView.swift` 管理閱讀與縮放控制；圖釘按鈕採用 `HeiBanPinIcon`。
- `NativePointerSurface.swift` 繼續接收 AppKit 滑鼠與鍵盤事件，不增加 WebView 或跨平台 UI 框架。
- 正式作品仍存於 `~/Library/Application Support/HeiBan/`；開發隔離目錄仍可用 `HEIBAN_DATA_DIRECTORY` 指定。
- 檔案 schema 與現有向量筆跡、尺規、橡皮擦、文字、便簽、圖片、圖層功能保持相容。

## 成品確認與尚待驗收

本輪完成 Release 編譯與 App bundle 產出，並實際檢視 Mac 首頁、已有筆記本的編輯介面、閱讀模式。曾發現縮放列伸展過寬及閱讀圖釘按鈕漏顯示，已修正。

沒有新增或執行測試套件。編譯器仍有既有警告。以下是後續驗收目標，不代表本輪已量測通過：

- [ ] 日常鼠標、觸控板與文字輸入來回切換：文字滾動不改視角、空白鍵放開恢復操作，中鍵不誤畫線。
- [ ] 在三種畫布上開關閱讀模式，確認圖片、便簽、筆跡與幾何物件內容不改變；筆記本可翻頁。
- [ ] 在閱讀與編輯模式分別鎖定視角，所有導航入口保持位置與倍率；解除後恢復。
- [ ] 收藏跨啟動保留，多選移除與還原的物件、頁面、圖片內容一致；磁碟錯誤時不誤報成功。
- [ ] 960×640 小視窗及大視窗：工具列四邊停靠與導航列不互相遮擋。
- [ ] 首頁大量作品的載入與記憶體、無限畫布連續平移與書寫的 frame pacing／延遲：依根目錄 A01、A02 指標量測，不能僅以編譯成功宣稱流暢或 120 FPS。
- [ ] 更多圖形、旋轉、漸層、文字格式與圖片裁切的縮圖完整度。現有縮圖 renderer 並未完全共用畫布 renderer，此為後續優先項目。

## 下一步工作清單（仍只針對 Mac）

### P1：日常操作與性能

1. 將縮圖與輸出共用物件渲染能力，避免畫布有內容而首頁漏顯示特定形狀／樣式。縮圖背景載入、有限快取，避免圖片反覆解碼。
2. 長時間筆跡、尺規拖曳、工具列拖曳與大文件平移的效能定位；保留使用者畫出的尖角，按既有 A01／A02 條件驗收。
3. 閱讀／編輯切換的快捷鍵與短提示；平移邊界、視角鎖定、物件操作的游標回饋統一。
4. 整理現有筆刷常用色與粗細入口；保持尺寸預覽與實際畫布縮放一致，兩種橡皮擦都在落筆前顯示範圍。

### P2：整理能力

1. 作品資料夾／分類、頁面縮圖側欄；沿用可收合模式，不預設佔用畫布。
2. 群組、多選、對齊與吸附、連線整理；保留三角形／四邊形逐點建立與可調頂點。
3. 黑板自己匯出 PDF 的可編輯文件恢復；外部 PDF 插入與註記，遵照使用者已確認的範圍。

### 最新正式擴充工作（取代原 P3 僅評估安排）

依使用者最新要求，圓規、計算機、計時器列入第一批交付，並直接改版頂列。子畫板、思維導圖、表格、公式、膠帶、雷射筆、貼紙、影音、附件等均有正式工作。完整功能、架構、順序與驗收見 [最新 Antigravity Mac 工作單](ANTIGRAVITY_PRODRAFTS_WORKLIST_2026-10-09.zh-TW.md) 與 [錄影盤點 R01–R58](PRODRAFTS_FEATURE_INVENTORY_2026-10-09.zh-TW.md)。這是新開發目標，不代表 1.0.2 成品已包含它們；仍採 Mac 桌面操作。

## 仍適用的既有要求

繁體中文黑板 Logo、原創一致的斜向圖釘；筆記本／無邊界／有邊界畫布；可調背景；圖片與截圖拖入；可編輯便簽與文字；圖層及右鍵；曲線與可調頂點；筆刷／填色透明度與漸層；尺規拖曳、旋轉、自適應配色與 0.1° 輸入；可收合屬性；工具列左右直排、上下橫排；橡皮擦只處理筆跡與圖形；自動保存狀態不擠動控制項。完整驗收仍以根目錄既有功能對照表與驗收文件為準。
