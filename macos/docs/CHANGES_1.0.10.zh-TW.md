日期：2026-10-10。Build：20261010.2。本機開發版，尚未更新 GitHub 下載版。

## 操作

- 左／右側工具列改為單欄純圖示，寬度由 152 pt 縮為 64 pt；不再顯示工具名稱、模式文字、滑桿文字或常駐狀態文字。
- 滑鼠停留可查看名稱；頂部橘色筆尖表示作畫、綠色游標表示滑鼠穿透，點擊切換模式。
- 點色圓開啟顏色、粗細與透明度面板。橡皮擦／雷射再次點各自圖示開啟專用設定。
- 狀態訊息可在更多選單、色圓設定面板或模式按鈕提示查看。
- 工具直排；短螢幕可捲動中段。清空、更多及結束固定在底部；頂端握把仍可拖到四邊。
- 上／下保持橫排與直接可見的顏色／粗細／透明度設定。停靠位置記憶與可復原一鍵清空沿用 1.0.9。
