# 黑板 Mac 1.0.15 本機開發版

Build：20261016.1；對照Windows1.0.15，2026-10-16。

## 這次可以從哪裡開始

1. 工具列「更多 → 自訂工具列」選「圖示與文字（分頁）」，調整常用、顯隱與順序；選取工具固定保留，空間不足按箭頭換組。一般／螢幕畫布使用同一偏好。
2. 點「磁鐵」，移近既有形狀參考點查看綠圈；第一點也可吸附。圓、菱形、五角形、星形由中心往外拖；矩形由角拖，三角形仍點三個頂點。
3. 圖形完成保留工具以便連續畫；切選取後單擊顯示把手，雙擊才開詳細屬性與快速列。文字維持雙擊原地輸入與右鍵字體／顏色。
4. 一般畫布右下拖曳原創磁吸板擦，右鍵選物件／局部筆跡或隱藏；更多→顯示板擦可恢復。放開一筆Undo、Esc取消；圖片、文字、便簽與鎖定物件受保護。局部擦除切向量筆跡，不修改圖片像素。
5. 首頁「匯入」選PDF或PPT／PPTX／Keynote。PDF選頁碼，每次最多200頁、圖片100MB；簡報需Keynote與macOS自動化允許，也可先轉成PDF。來源不修改，結果為鎖定圖片頁可註記。自己的PDF可選恢復完整原稿為新作品，避免覆蓋庫內同ID。
6. 匯出PDF時筆記本可選目前／全部頁面。**PDF附完整可編輯原稿，包括隱藏物件與其他頁面**；只分享可見內容時請用PNG，並保留.heiban作再編輯檔。
7. 新使用者預設關閉自動存檔；既有偏好保留。手動與正常退出仍保存；退出時顯示保存進度。
8. 使用手冊依介面語言開啟，支援離線搜尋與頁內語言切換；正體中文21章圖解，其他語言13主題總覽。

## 試用界線

編譯／封裝不等於全部功能已驗收。本批沒有執行測試套件、UI或真實文件往返；四邊工具列、板擦手感／Undo、PDF頁序／圖形外觀／跨平台恢復、Keynote字型與各種投影片、多顯示器／筆裝置及翻譯仍需實際回報。Google雲端協作與結構筆記原型沒有因此成為已交付功能。
