## 下批優先順序

1. 保全與一致性：M09 設定接線、M10 備份／索引失敗回饋、M07 session 正式整合。
2. 真實使用流程：依 M12／M14／M15 與 1.0.10 補純圖示側欄／彈出設定／四邊拖曳、清空／復原、透明螢幕畫布與重開保存驗收；按使用者需求執行回歸。
3. 性能：採樣／渲染／解析／圖片／匯出量測，再拆 publisher 或背景處理；保留目前事件邊界。
4. 功能：依 Antigravity 工作單接入結構化筆記及 PDF／SVG，不以原型檔案充當完成。
