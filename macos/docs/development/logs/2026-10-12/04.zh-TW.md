# 2026-10-12 · 螢幕畫布自訂色彩、圖層與曲線入口

狀態：自訂色彩／選取樣式、曲線與圖層入口已實作並通過 Debug 編譯；完整屬性及操作驗收未完成。平台：macOS。

## 目的與授權範圍

使用者先前要求螢幕工具列的色彩、粗細、透明度與形狀設定跟上 Windows，並要求選取物件的樣式調整清楚一致。本批處理 TB06 的自訂色彩入口與已選取物件線條樣式，以及 TB07 的曲線工具／圖層面板入口；只改 Mac，不改 Windows／版本／發行。

## 起始狀態

來源 HEAD `148d427`，本機開發版仍 `1.0.13 / 20261011.1`。既有 AnnotationBrushSettings 只有六色、粗細與透明度；Controller 對所有 Session 一律改未來筆刷，沒有已選取物件命令。

## 進行紀錄

- 色圈面板新增 macOS ColorPicker，色票／自訂色使用同一 setColor 命令。選取物件時用當前顯示器的 activeEngine 選取樣式交易；空選取才更新各螢幕未來畫筆顏色／雷射顏色。
- 粗細／透明度沿同一邊界切換：選取時更新所選物件，空選取時改未來畫筆預設。面板讀取選取混合狀態的首個物件作滑桿起點，不改其他顯示器選取。
- 六色視覺反映選取線色，自訂色能轉成 #RRGGBB；手冊與TB06清單標示缺少屬性及待操作驗收，不宣稱完整色輪／填色／漸層已完成。
- 螢幕工具按鈕新增曲線，沿用 Core 可編輯曲線工具；更多選單開啟既有 `LayerPanelView`，綁目前顯示器 engine。圖層／曲線交互尚未操作驗收。

## 變更與證據

修改 `ScreenAnnotationController.swift`、`ScreenAnnotationControls.swift`、`AnnotationBrushSettings.swift`與工具列尺寸列數；更新使用手冊來源與產物、TB06／TB07清單及 M28 問題紀錄。`swift build --package-path macos` 成功；未新增／執行測試，未操作 UI，未產出／安裝App。

## 結果、風險與下一步

色圈自訂與線色／線寬／物件透明度作用目標已接通，尚未驗收混合色、鎖定物件、彈窗方向、undo及取消。TB06仍部分完成：填色／alpha／漸層／虛實線／箭頭大小／直線延伸待做；版本號不變。
