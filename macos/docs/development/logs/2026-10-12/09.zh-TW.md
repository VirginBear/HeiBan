# 2026-10-12 · 一般與螢幕畫布共用工具列，保留螢幕專用操作

狀態：共用實作／Release 封裝完成，功能操作待使用者驗收。平台：macOS。

## 目的與授權範圍

以一般畫布為基準，螢幕畫布排除縮放／平移及圖釘，其他工具與設定共用。只修改 Mac，維持 1.0.13 / 20261011.1，不發布。

## 起始狀態

main 起點已有上一批 Mac 大量未提交變更，全部保留。既有螢幕工具列是固定 11 工具與獨立設定 switch；不能宣稱與一般畫布共用。

## 進行紀錄

1. 盤點 ToolbarView／ScreenAnnotationControls／AnnotationInputView：除工具列重複外，螢幕 renderer 禁用全部 hit testing，不能直接加入尺與圓規，否則只有圖示沒有可操作功能。
2. 共用 ToolbarToolsView 與 ToolbarContentPolicy；一般偏好不覆寫，螢幕只過濾 pins/viewLock，clearAll 固定在視窗尾端。Undo/Redo 拆成共用 32pt 元件以適配網格；More 也渲染真正的工具控制，移除第二套 trigger switch。
3. 把 AnnotationBrushSettings 移到 Views/ToolbarBrushSettings，抽出 engine-aware 樣式命令，並保留一般畫布的筆刷類型與實際尺寸預覽。無選取時不再顯示會無作用的填色／箭頭物件設定。
4. 螢幕 renderer 恢復互動，原生指標面位於尺／圓規／快速列／輔助面板下方。保留原生文字輸入 host 與透明 1% 底層。螢幕 dialogService 需強引用，engine 是 weak service。
5. 第一次編譯命令誤在 repo 根目錄，找不到 Package.swift；改於 macos 執行。編譯發現 PolygonVertexHandlesView 與 CanvasImageDropDelegate 是 private；改為模組內共用，避免複製實作。

## 變更與證據

- Core：新增 ToolbarContentPolicy；AnnotationToolbarLayout 接實際 itemCount，保留舊幾何預設相容；BoardEngine 保存工具偏好發低頻同步通知。
- Mac Views：ToolbarToolsView 共用；新增 ToolbarBrushSettings（由 AnnotationBrushSettings 移出並一般化），ToolbarCustomizeSheet 按模式過濾；CanvasView 的多邊形頂點與圖片 drop delegate 開放模組內重用。
- ScreenAnnotation：Controls 只保留原生拖動、作畫穿透、收合及固定清空／退出；Controller 只留平台行為與動態尺寸，移除獨立樣式命令。Session 強持 dialog adapter；InputView 不再重複裝指標監聽；Canvas 補相同互動工具疊層。
- 使用說明由 `python3 macos/scripts/generate_user_guide.py` 產生並包含於 App；CURRENT_STATUS、ISSUE_HISTORY M37、DECISIONS ADR-M23、每日日誌索引同步。
- 最終命令：`bash scripts/build_app.sh`（工作目錄 macos），Release 成功32.93秒，簽章／成品清理成功；`codesign --verify --deep --strict macos/dist/HeiBan.app` exit0。

## 結果、風險與下一步

工具清單、圖示、More、自訂、雷射／橡皮擦／筆刷樣式改為一份實作；螢幕不提供縮放／平移／圖釘，仍有固定穿透／截圖／清空／退出。共用尺與圓規、文字／便條、套索、遮題、圖片、屬性、計算機及計時器；不變動普通作品或可編輯文件格式。

待實際操作：各停靠方向與不同解析度、長／空工具清單、嵌套設定 popover、原生中文文字組字、尺／圓規命中、圖層快捷鍵、輔助面板、多顯示器樣式切換及穿透恢復。不可只依編譯宣稱這些均已驗收。既有編譯警告（BoardExporter auxInfo、舊SDK框架搜尋路徑及NSParagraphStyle Sendable）未因這批整理而消除，未改不相關代碼。
