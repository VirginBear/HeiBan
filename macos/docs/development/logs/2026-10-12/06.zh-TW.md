# 2026-10-12 · 修正 Mac 圖片貼上、AB 端點與工具列，接通版本及語言設定

狀態：本批實作與部分驗收完成，完整互動追齊仍進行中。平台：macOS。

## 目的與授權範圍

使用者實機回報六項操作問題。本批只修 Mac，版號維持 1.0.13 / 20261011.1；不發布。

## 起始狀態

HEAD d944542，開工工作樹乾淨。上輪 1,713 核心斷言通過，但未量測 SwiftUI 實際按鈕佔位，不能視為操作驗收。

## 進行紀錄

1. 圖片貼上命令只解碼 [BoardObject]，沒有呼叫已有 pasteImageData；internalClipboard 優先導致外部圖片被舊複製資料遮蓋。改系統來源優先、同步 bitmap／本機圖片與非同步 URL 影像讀取；返回前核對作品與頁未切換。加入正式 Cmd+V 命令並保留 NSTextView 原生貼上。
2. 原先 AB SwiftUI 手勢與通用矩形 transform 同時顯示；螢幕畫布只走 AppKit input 更無 AB 手勢。端點改共用 pointer route，overlay 只繪 AB，單線不命中矩形控制；線段排除旋轉屬性。
3. 快速列原底緣位於物件上方 8 pt，覆蓋上方 25 pt 旋轉點。改預留 42 pt 控制區；不足則放下方。
4. 原主工具列 top 固定預留64pt，header隱藏沒有通知外部。以UI可见状态回呼改 topClearance，靠上时12／64，保留拖曳期間原點。
5. 原螢幕上下中段 width-310，而固定按鈕實際合計更寬；左右688亦不足容納16個32pt格＋固定區，核心測試只是重述錯誤常數。改同一格尺寸算法，17個中段格換列，固定清空／退出可達，直排16格依高度換欄。

6. 加入 MacReleasePolicy 與 MacUpdateService：官方 GitHub releases API、macos-v 標籤、CPU 相容資產與版序比較。與 Windows 共用 repository，但不是套用 Windows updater；不降版、不背景安裝。實際官方公開 Mac 最新為1.0.8，發行檢查已顯示保留本地1.0.13。
7. 語言使用 Mac 自有 JSON＋L10n 低頻發布。沿用既有 Windows 詞庫語意作初始材料，另補 Mac 名稱；不引用 Windows build/runtime。UI字串才翻譯、作品名稱／文字／ID不翻譯。實際英文操作暴露非等義 alias（回報誤作手冊、主題誤作顏色等），已逐項改正並保留 MacTranslations 語意來源；移除純 Canvas 視圖多餘語言訂閱。側邊屬性標籤改純圖示，避免長語言斷行。
8. CUA 首輪可確認十語選擇／英文即時刷新、官方版本比較，上方820×60pt及左側64×784pt退出按鈕可達並正常結束疊層。之後原生畫布 drag／快捷鍵驗收未得到物件，CUA曾回報 noWindowsAvailable，重新getApp後啟動未帶資料隔離環境的實例；立即正常退出，不再操作其作品。不能把這段當畫線 UI 已通過，後续隔離 App 改固定 launcher 注入測試路徑，避免工具自動重開落入一般作品庫。

9. 新增鎖定 AB 回歸首次1751/1752，有一項失敗。確認是Undo會清空選取而fixture未重新選取，不是鎖定路由改動失效；補顯式重選後再驗證旋轉／hover／鎖定。原先旋轉命令檢查亦因此增強，不可用空選取的通過代替真實防護。
10. 更多內隱藏dock為沒有方向的no-op，改為四方向Menu；其餘隱藏popover入口仍列後續實機檢查。

11. 最後渲染來源複核發現CanvasObjectsView的drawSelectionOutline仍會替每個選取物件畫cyan矩形；只改SelectionOverlay不足以消除舊框。線段／箭頭排除該外框，AB overlay跟隨整段移動的selectionOffset預覽。此項屬渲染層，Core斷言不能證明已覆蓋，需要實際圖面驗收。
