# 2026-10-24 · Mac 1.0.17 同步 Windows 更新：常用色盤 Store、常駐雷射、筆色底線與手形平移

狀態：Mac 1.0.17 實作、立靶測試驗收與 App 封裝已全部完成；`windows/` 零修改。平台：macOS。

使用者要求核對 GitHub 上最新 Windows 版本的更新內容，並以相同版本號（1.0.17 / Build 20261024.1）進行 Mac 版本同步移植，遵循「先靶後箭」工程紀律，且細節調整將由使用者操作後再行討論修正。
範圍嚴格限定於 `macos/` 與共用文件，嚴禁觸碰 `windows/` 目錄。

## 對齊 Windows 1.0.17 契約與核心實作

1. **常用色盤 Store (`PalettePreferencesStore.swift`)**：
   - 跨一般與螢幕畫布共用，持久化儲存於 `Application Support/com.bear.HeiBan/Settings/palette.json`。
   - 格式對齊 Windows 契約：`schemaVersion: 1`, `colors: ["#RRGGBB", ...]`。
   - 規格化 (`canonical`)：輸入色碼自動轉大寫、`#RRGGBBFF` 與 `#RRGGBB` 等價去重（標準化為 7 碼）、保留有效半透明 alpha。
   - 內建 8 種經典常用色（預設首色 `#22C55E`）、支援新增、移除、管理模式、清空色盤及還原預設色；支援損毀壞檔標記保護（保留原檔不覆寫）。
2. **選取與雷射指標常駐固定**：
   - `ToolbarPreferences`：`select`（第 0 位）與 `laser`（第 1 位）於所有工具列分頁中常駐顯示，不可隱藏，不可被自訂移動取代。
   - 常用工具分頁預設納入 `laser`。
   - `ToolbarContentPolicy`：分頁內容過濾自動排除常駐之 `select` 與 `laser`，避免重疊顯示；水平工具列寬度與固定左側錨點重新校準。
3. **當前繪圖工具色彩色線 (`Active Tool Color Underline`)**：
   - 繪圖類工具（`pen`, `highlighter`, `paint`, `curve`, `shapes`）於圖文分頁與圖示模式下，在圖示下方顯示 22×3 pt 之當前作用色線。
   - 非當前活動之繪圖工具色線以透明度 0 佔位，防止切換時高度與行高抖動。
4. **筆刷與物件設定面板精簡 (`ToolbarBrushSettings.swift`)**：
   - 移除原先易造成混淆的 8 種筆刷材質下拉選單。
   - 整合 `PalettePreferencesStore` 常用色盤網格、一鍵新增當前色、進入管理刪除模式、還原預設色。
   - 採用單一外層垂直滾動容器，杜絕多重巢狀滾動衝突。
5. **中鍵拖曳平移手勢回饋 (`NativePointerSurface.swift`)**：
   - 中鍵拖曳畫布時滑鼠游標設為抓握手形（`closedHand`），釋放時自動恢復。
