## 明確保留的程式

- 導圖／表格／公式／簡報、登入／同步／協作／更新與多文件核心：既有需求、原型與檢查仍有用途；列狀態，不刪成空功能。
- 舊 JSON、未知欄位、`.partial` 橡皮擦等相容語意：是資料契約，不是重複 enum。
- 舊截圖參數／結果 helper：既有檢查仍引用，已註明正式流程使用平台服務，沒有復活命令列擷取。
- MainWindow 的 board／objects 觀察：保護直接 UI 編輯，共用 debounce。
- 設計圖、參考軟體、使用者作品、歷史稽核／工作清單：不屬死碼。
