01開始使用

先有一張紙，再讓想法延伸。

  1. 在首頁按「＋」，選擇筆記本、無邊界畫布或有邊界黑板。
  2. 輸入名稱；尺寸與背景的進階設定收在新增視窗。
  3. 選畫筆開始寫畫；需要整理時切到選取工具。
  4. 一般視窗放大：雙擊視窗最上方空白標題列即可放大，再雙擊還原；也可使用 macOS 選單「視窗 → 放大／還原視窗」或 ⌘⌥0；再按一次還原。也可按住 Option 點左上綠色按鈕。這會放大普通視窗並保留 Dock／選單列，與全螢幕及畫布內容縮放分開。
  5. 新使用者自動保存預設關閉；既有設定保持。自動保存可在「帳號與設定 → 一般設定 → 存檔與安全」開關並調整頻率；關閉後手動保存、切換作品與正常結束仍會保存。需要帶走作品時，另存 .heiban。
新使用者首次啟動會建立一次 Mac 專用操作指南，刪除後不會自動重建；已安裝舊指南的使用者不會被強制新增。首頁「使用說明 → 操作說明 · 全工具指南」開啟上次練習並保留修改；「建立新的操作指南練習」另建一份當前介面語言的新作品，舊版與先前練習都會保留。建立或儲存失敗會顯示訊息，可重試。

02首頁與作品庫

用內容縮圖辨識作品。

首頁縮圖顯示內容，類型圖示區分筆記本、無邊界畫布、有邊界黑板。按作品開啟；按作品旁的更多選單可重新命名、收藏或移到垃圾桶。

  • 搜尋／篩選：以名稱找作品，依格式縮小範圍。
  • 批次選取：進入選取模式，勾選作品，再移到垃圾桶。
  • 收藏：常用作品可加入收藏，從左側快速開啟。
  • 垃圾桶：可還原作品，或永久刪除；永久刪除前請保留備份。
  • 側欄：左上側欄按鈕可收合，留出更多縮圖空間。
  • 螢幕畫布：側欄「帳號與設定」上方可直接啟動透明螢幕註記；側欄收合後仍保留圖示入口。
  • 新增：用＋開啟精簡建立介面，不需在首頁保留大幅設定區。

03三種畫布與背景

選擇適合內容的範圍。

格式適用情境操作
筆記本會議、課程、多頁筆記底部切換、增加頁面；頁面內容各自保存
無邊界畫布草圖、腦力激盪、大型整理可往各方向平移與延伸
有邊界黑板單張圖、簡報與固定尺寸在既定紙張範圍內組織內容

上方更多選單可改背景主題，或開啟自訂背景與格線。支援黑板、深色、白板、網格、點陣、橫線、五線譜與純空白等設定；尺寸預設包括 A4、A3、B5、16:9、4:3、1:1、9:16 與自訂。

筆記本由底部頁碼與＋頁導覽；刪頁請使用頁面選單，並留意該頁內容。

04移動畫布與縮放

滑鼠在哪裡，就以哪裡為縮放基準。

  • 滑鼠滾輪：以游標下的畫布位置為中心放大／縮小。
  • 中鍵按住拖曳：平移畫布。
  • 空白鍵＋左鍵拖曳：暫時平移，放開空白鍵回到原工具。
  • 觸控板：兩指平移，雙指捏合縮放。
  • 縮放鎖定：鎖定後避免操作時誤改視角；需要導覽時先解鎖。
  • 閱讀模式：瀏覽內容，避免誤畫或改物件。
  • 沉浸模式：由更多選單開啟，減少介面遮擋。
編輯文字與便條紙時，滾輪只作用於文字編輯區；游標放回畫布後才縮放畫布。

05安排工具列與屬性

把常用工具放在手邊。

編輯／閱讀畫布的右上導覽列預設收起；將滑鼠移到右上細箭頭附近即可顯示，離開約 0.7 秒後收起。點眼睛按鈕可固定顯示，再點一次恢復自動隱藏。選單或設定彈窗開啟時不會收起。

拖曳工具列的握把移動；靠上下邊緣變橫排，靠左右變直排。也能由停靠選單直接指定四邊。工具列預設開啟全部 29 項工具並採用「圖示與文字」分頁模式（常用／繪圖／插入／管理），常用分頁預先包含畫筆、螢光筆、橡皮擦、筆刷顏色、實線／虛線、復原／重做、磁鐵與清空黑板。空間不足時可以箭頭切換工具組。

「自訂工具列」提供圖示模式或圖文分頁（常用／繪圖／插入／管理），可調整顯示工具、順序、全選與恢復預設，並獨立勾選常用。選取、雷射筆與藤條三項教學工具固定在所有分頁前方，不可隱藏且不在分頁內重複；隱藏、其他分頁及下一組的工具仍可從更多選單使用，色圈／圖形／橡皮擦設定也能由此開啟。水平工具列以「繪圖」頁寬度偏左置中，切換分頁維持同一左錨點。圖文工具列依分頁緊湊平鋪，空間不足以箭頭換組；純圖示模式仍可捲動。圖示與文字區使用相同操作，停靠是整塊選單，復原／重做各有獨立按鈕。工具設定使用固定面板入口，不因隱藏或換組而消失。

「屬性」預設可收成小標籤，點開才顯示。拖曳屬性標籤／標題可停靠四邊：左右是直向面板；上下使用橫向分區，把色彩、線條、物件分欄。窄視窗可橫向捲動，各欄長內容能垂直捲動。

單擊物件只顯示把手，雙擊才開詳細屬性與快捷列。色圈有選取時改適用物件，沒選取時才設定下一筆；文字格式集中在右鍵。

06畫筆與筆刷

粗細預覽會跟著目前縮放顯示。

筆刷面板只有一個捲動區，直接調顏色、粗細與透明度，沒有筆刷材質下拉。常用色按＋保存目前色，管理或右鍵移除，還原預設色可恢復八色；可刪到空列表並保存。一般／螢幕畫布共用 Settings/palette.json；載入失敗保留原檔，保存失敗會顯示提示。Hex 支援 #RRGGBB 與 #RRGGBBAA（最後兩碼透明度），大小寫及FF透明度等價去重。

點畫筆，再點工具列的顏色圓點開啟筆刷設定。只有目前選用的繪圖工具顯示筆色色線；切到選取、雷射或橡皮擦時不顯示其他筆色線。面板以色彩、粗細與透明度為主，不顯示筆刷材質下拉；舊筆跡的 brushKind 資料與既有渲染仍保留。

  1. 選擇畫筆、螢光筆或油漆工具，再按色圈調整樣式。
  2. 選色票、最近色彩，或自訂顏色。
  3. 設定筆寬與透明度；預覽圓會換算目前畫布縮放，標示畫布上實際直徑。
  4. 拖曳繪製。自由手繪筆刷不會被磁鐵吸附拉扯，完成後也不自動跳出選取框，方便連續書寫。

繪圖板有提供 NSEvent 筆壓時，壓感筆刷使用壓力；普通滑鼠無法提供真正的筆壓。畫完後可選筆畫調整色彩與粗細。

筆畫停留識別可協助拉直與辨識簡單圖形；若要精確可編輯幾何，請用圖形工具。

07圖形、曲線與頂點

先生成，再調整。

1.0.16：繪圖與曲線工具完成物件後保持啟用，可連續作畫。一般畫布與螢幕畫布共用 3×3 九宮格描邊圖形選單與自動填滿開關。矩形從角拖曳，圓／菱形／五角形／星形從中心向外拖曳。三角形與四邊形依序點選頂點，預覽是直線。磁鐵按鈕專門吸附幾何建構工具、曲線筆與圓規圓心（自由手繪筆刷不套用磁鐵吸附）：頂點、邊中點、矩形中心、線段端點／中點、圓弧中心與四向點（弧另含起訖點）；隱藏物件排除，鎖定圖形仍可參照。hover綠圈提示約10畫面點內的目標，不修改原物件。

  • 直線／箭頭：拖曳定義兩端；選取後移動端點，屬性中設定線條和箭頭大小。
  • 矩形、圓、圓角矩形、菱形、多邊形與星形：從圖形工具選取，拖曳建立；完成後保持目前繪圖工具。
  • 三角形：依序點第一點、第二點、第三點；第二點起可看到連線，第三點完成物件。
  • 四點圖形：依序點四個點，最後一點閉合。
  • 頂點：選取三角形或四點圖形，拖曳頂點調整形狀。
  • 連接線：從幾何形狀選單選連接線，拖曳建立，再調整端點。
  • 曲線：用曲線工具建立弧線，完成後保持曲線工具且不自動顯示選取框；選取後可拖曳其控制點調整。
  • 尺寸／旋轉：選取物件後拖曳控制點，或從屬性調整角度。

線段／箭頭的延伸選項可設定兩端是否延伸。生成過程按 Esc 取消尚未完成的圖形。

08選取、物件與圖層

物件是可以再編輯的。

用選取工具點物件；拖曳空白處框選，或使用套索。Shift 可搭配多選。拖物件移動；邊界控制點調整尺寸，旋轉把手調整角度。

  • 右鍵：依位置與選取狀態提供複製、剪下、貼上、克隆、刪除與四向圖層順序調整（移至圖層頂端、上移圖層、下移圖層、移至圖層底端）。多選調整圖層時會保持所選物件彼此的相對前後順序。
  • 複製／克隆：複製搭配貼上；克隆直接產生另一份。
  • 群組：多選後群組，一起移動；解組可再逐一調整。
  • 物件快速列：單擊只顯示把手，雙擊才顯示精簡操作與詳細屬性。
  • 圖層：工具列圖層按鈕或更多 → 物件圖層；列表上方代表前景。拖曳每列左側六點握把時會出現跟隨游標的圖示／名稱預覽，原列淡化；目標列上／下半部顯示插入線，放開才提交排序。Esc 或拖出列表放開取消；鎖定物件須先解鎖。排序限定目前頁面，單次復原可還原。雙擊名稱改名，右側按鈕控制可見與鎖定。
  • 復原／重做：修改失誤可復原；重新開啟作品不保留整段操作歷史。

09色彩、填色與線條

先選物件，才會有可調整的屬性。

屬性中的圓形色票、系統色彩選擇器可改線條色與填色；填色可選無填色，並獨立調整填色透明度。另有物件整體透明度。

  • 線條：粗細、實線、虛線、點線、點劃線。
  • 箭頭：可調箭頭頭部長度與寬度。
  • 漸層：屬性中的「漸層填色」開關與起點／終點色；適用可填色的圖形，實際呈現依物件種類。
  • 多選：不同值會顯示「混合」；調整後套用到支援此屬性的選取物件。
  • 便條紙：樣式、底色色盤、文字溢出與自動擴展。
圖片的透明度與位置可調整；筆刷是用於畫新的內容，不會把 PNG 原本的像素拆成可編輯向量。

10文字與便簽

直接輸入內容，右鍵集中調整文字。

點 T／文字工具後在畫布點一下開啟原生文字輸入；中文組字由 macOS 輸入法處理。便簽先建立實體便簽物件，再輸入文字。

  1. 輸入內容，Enter 換行，按完成或 ⌘Enter 提交；Esc 取消草稿。
  2. 完成後用選取工具雙擊文字框再次編輯，或右鍵 → 編輯文字內容。
  3. 對文字框按右鍵，使用文字大小、文字顏色、粗體、斜體、底線；更多文字設定可輸入 8–144 pt、自訂 #RRGGBB 顏色、字體名稱、對齊與不透明度。
  4. 先框選或 Shift 點選多個文字框，再右鍵其中已選取的文字框，可一起調整。混合選取只修改未鎖定的文字／便簽，圖片與圖形不變；更多設定只套用你修改的欄位，一次套用可一次復原。
  5. 輸入中也可對文字區按右鍵，調整目前草稿整個文字框的格式；完成前不寫入作品，取消不提交。

文字輸入視窗只保留內容、完成與取消，不常駐整排格式設定。編輯期間捲輪由文字區處理，不縮放畫布。原生貼上與文字選取仍可使用；長文字可捲動。便簽樣式與填色由物件設定處理，右鍵文字色不會改便簽底色。

11橡皮擦

先看範圍，再決定要擦多少。

原創磁吸板擦：一般畫布右下角可拖曳 45° 斜角板擦（長軸縮短至 80%，與右下藤條快捷底部對齊、靈巧不遮擋視線）；圖片、抓取與擦面共用對齊輪廓，不以外框擦除。右鍵切物件／局部筆跡或隱藏，更多→顯示板擦可恢復。拖曳只顯示預覽，放開才提交一筆復原；Esc或切到其他程式會取消未完成的板擦預覽。板擦與圓形橡皮擦並存；圖片、文字、便條與鎖定物件受保護。

  1. 點橡皮擦；再次點擊開啟模式與大小設定。
  2. 游標即使未按下，也顯示半透明擦除範圍。圓形橡皮擦在拖曳時只顯示預覽；放開才提交一筆復原交易。Esc、失去視窗焦點、切工具或切作品會取消未完成擦除；儲存、截圖與退出也不保存尚未放開的擦除預覽。
  3. 物件擦除：碰到可擦筆畫／圖形時移除該物件。
  4. 像素擦除：只擦筆畫的局部範圍，保留其餘部分；以線段與圓的交點切割，旋轉筆跡先轉成世界座標，曲線以細分線段近似。保留筆刷、壓力及擴充資料；不是修改圖片像素。

圖片、文字和便條紙受到保護；要移除它們，請選取後 Delete 或使用右鍵刪除。橡皮擦大小可調整，範圍依畫布縮放換算。擦錯可用 ⌘Z。

12尺規

拖位置、轉角度，再沿邊畫線。

  1. 啟用尺規；拖尺身移動。
  2. 拖旋轉把手調整角度；設定中亦可直接輸入角度，精度到小數點後一位。
  3. 尺上有刻度；配色預設自適應背景，也可自行指定，亮底與暗底均需保持可讀。
  4. 用畫筆沿尺邊繪製，尺規會約束線段方向。

尺規設定可從工具按鈕的設定入口開啟；輔助尺是暫時工具，不會出現在匯出圖片中。

13圓規：準備 → 鎖定 → 畫弧

點圓心是開始繪製的明確分界。

1準備

拖圓心改位置，拖半徑把手改半徑，拖筆尖設定弧線起點。此時不會畫線。

2鎖定

點一次圓心，圓心變橘色。中心和半徑鎖住，筆尖準備繪製。

3畫弧

拖筆尖順時針或逆時針畫弧；放開後建立可選取的圓弧，工具回到選取。

起點不會因第一個滑鼠移動取樣而改變；跨越 0° 時連續計算弧度。鎖定後再次點圓心可退回準備。單純拖準備中的筆尖、不動筆尖或按關閉，均不會偷偷建立整圓。

需要整圓可明確按「整圓」。生成物件使用目前色彩與粗細，後續可從屬性調整。

14雷射筆與藤條教學工具

工具在哪裡，設定就在那裡。

  1. 點雷射筆啟用；按住滑鼠左鍵並移動即可顯示光點與尾跡，放開左鍵立即消失。
  2. 再點一次雷射筆按鈕，開啟設定；右鍵也有設定入口。
  3. 選光點、短尾跡或線條；光點模式刻意沒有尾跡。常用色與筆刷共用 Settings/palette.json。
  4. 調整光點直徑、尾跡粗細、消退時間、色彩和白色亮芯。
  5. 點藤條（或右下角藤條快捷）切換教學拍打工具：握柄跟隨游標並呈 45° 斜角，左鍵點擊即觸發揮動、琥珀色震波環與清脆拍打音效，不會選取、移動或修改任何畫布物件，也不會寫入復原紀錄。
  6. 工具列藤條按鈕或右下角藤條快捷可按右鍵隱藏右下快捷，從「更多 → 顯示藤條」可隨時恢復。

光點以螢幕 pt 顯示，不因畫布縮放變大或變小。短尾跡最長 0.8 秒；線條可保留到設定的消退時間。設定保存在本機偏好。

尾跡使用連續平滑輪廓與柔和光暈，不以離散透明度分段。雷射與藤條皆為暫時教學演示效果，不加入作品、不作為永久筆畫匯出。藤條音效衍生自 freesound.org #446128（inspectorj，CC BY 3.0）。

15計算機與倒數計時

從＋輔助工具開啟。

遮題膠帶：工具列的眼睛遮蔽圖示可建立膠帶，拖曳覆蓋答案。閱讀模式點膠帶揭示／再次遮住，適合講課提問；編輯模式可選取調整範圍。

計算機：上方＋ → 計算機。浮動面板提供一般／科學計算與歷史；拖標題移動，點按鍵操作。關閉後仍可再從＋呼叫。

計時器：＋ → 計時器。選倒數／計時、輸入時間或選預設，按開始、暫停、重設；關閉後可再次叫回。計時狀態與面板顯示分開管理。

移動面板請拖標題區；按輸入區或按鈕只操作內容，不會觸發整個面板的移動。

16圖片與截圖置入

把電腦上的素材放進作品。

將桌面圖片或 macOS 截圖浮動縮圖拖進畫布；亦可用＋ → 圖片匯入，或從剪貼簿貼上圖片。

常見 PNG、JPEG、GIF、BMP、TIFF、WebP 等由 macOS 圖片解碼支援；個別檔案仍可能因格式變體或損壞無法開啟。GIF 不作為持續播放動畫。HEIC 等拖放是否可用依系統解碼，匯入對話框目前有格式限制。

圖片是一個可移動、縮放、旋轉、調透明度與疊加註記的物件；不提供完整照片像素修圖器。保存 .heiban 可保留圖片與其上的筆畫；匯出 PNG 則得到合成結果。

App 內截圖：＋ → 截圖置入。若已有有效錄製權限可直接擷取；否則使用 macOS 系統螢幕選取器授權這次擷取，再選取區域置入。Esc 取消。

開發版更新後，舊版權限可能不再對應目前的 App；可使用系統選取器，或在「隱私權與安全性 → 螢幕與系統音訊錄製」確認目前這份黑板。DRM 保護影像可能無法擷取。

17圖釘導覽

讓重要區域隨時回得去。

圖釘會出現在畫布上，並採用一致的斜向圖釘圖示。可設定名字、調整位置，從圖釘導覽清單返回該位置與視角。

新增圖釘前先移到想標記的區域；從圖釘面板新增並命名。之後選取或拖曳圖釘調整位置，透過清單改名或刪除。圖釘是導覽標記，與便條紙的裝飾圖案用途不同。

18我的螢幕就是我的畫布

在直播、影片或講解上加一層透明紙。

從上方＋輔助工具、首頁使用說明、macOS「螢幕畫布」選單或選單列圖示開啟。黑板保持運行時，也可直接按全域快捷鍵。

快捷鍵動作
⌘⌥⇧D首次開啟；之後切換「作畫／操作」
Esc畫布收到鍵盤焦點時暫停作畫
⌘⌥⇧S截取目前螢幕與註記，另存 PNG
⌘⌥⇧X結束透明畫布並保存註記
畫作畫

透明畫布接收滑鼠。工具與一般畫布共用：畫筆、螢光筆、油漆筆刷、曲線、幾何圖形、T 文字、便條紙、橡皮擦、套索、遮題膠帶、雷射筆、尺與圓規；計算機、計時器與屬性面板也可在透明畫布操作。縮放／平移及圖釘不提供於螢幕畫布。圖層只管理目前顯示器的註記。

用操作

註記仍可見，滑鼠穿透到背後程式。可播放、捲動、切換投影片，再回到作畫。

存保存

PNG 包含螢幕畫面；.heiban 保存可編輯註記，沒有背後螢幕影像。

  • 背後程式繼續運行，黑板不會暫停影片或動畫。空白區域也可直接落筆，第一次點擊不需先啟動黑板。為維持原生透明視窗的輸入覆蓋，螢幕會有約 1% 的淡色遮罩。
  • 控制列保持可點擊。橫排握把旁的「操作螢幕」會切成滑鼠穿透，按「繼續作畫」恢復；左右窄列以相同功能圖示呈現。右上選取箭頭只選註記物件，不代表穿透。找不到工具列時，用 macOS「螢幕畫布 → 顯示螢幕畫布工具列」；該選單也有獨立操作螢幕／繼續作畫入口。工具圖示、順序、顯示／隱藏設定及「更多 → 自訂工具列」與一般畫布共用；在任一模式修改工具清單，另一路同步。原有一般畫布的偏好保留，螢幕模式只略過圖釘及視角鎖定。隱藏工具從更多面板點相應圖示啟用或開設定。拖曳握把到上／下／左／右，放開後停靠；採與一般畫布相同的圖文分頁／純圖示格式、圖示、內距與面板外觀；左右直排、上下橫排。圖文分頁依內容調整尺寸並維持左／上錨點，工具太多時以箭頭換組，純圖示模式捲動。展開時穿透操作與結束固定可見，清空在常用／更多。更多 → 工具列位置直接選四邊；收合後保留模式、清空、更多、展開與結束。色圈在四個方向都開相同設定：筆刷類型、預設／最近顏色、Hex、自訂色輪、粗細、透明度與實際尺寸預覽。有選取時改所選物件；沒有選取時改之後的筆刷。填色透明度／漸層及箭頭大小／線段延伸只在相應物件選取時提供。雷射與橡皮擦設定沿用一般畫布。螢幕截圖按鈕仍是另存含背景畫面的 PNG；圖片匯入可加入註記，也可拖入或貼上圖片。
  • 螢幕畫布點 T，再點螢幕位置輸入文字；輸入區有獨立原生命中範圍，背後影片繼續播放。完成後雙擊編輯，右鍵改大小／顏色，多選可一起套用文字樣式。暫停、換工具、儲存原稿、截圖或結束前會先提交草稿；輸入中 Esc 取消，不直接切成穿透模式。
  • 每個顯示器有獨立透明畫布；滑鼠移到另一螢幕會切換其復原／重做操作對象。
  • 工具列的垃圾桶按鈕是一鍵清空畫布，會立即清除所有螢幕的註記、未完成筆畫與雷射尾跡，不顯示確認視窗、不返回首頁，也不結束透明畫布；工具／色彩／粗細／作畫或穿透狀態保持。更多選單與 macOS 螢幕畫布選單亦有入口。按該螢幕的復原按鈕可還原已提交的物件（未完成筆畫與雷射不屬於歷史）。
  • 註記會獨立自動暫存，清空後立即寫入空白狀態；停止時也保存，再次開啟可還原最近狀態。工具列位置保存於本機偏好，不寫入作品，若上次顯示器不在則回到目前螢幕。
  • 切換作畫狀態前請放開滑鼠，避免取消尚未完成的筆畫。切回作畫會保留工具、顏色與粗細；在操作模式點畫筆或形狀，也會直接恢復作畫。
  • 顯示器配置改變時結束本次疊層，以免座標錯位，重新開啟即可。
  • 快捷鍵被其他 App 佔用時用控制列／選單操作；此功能不要求輔助使用或輸入監控權限。截圖仍需系統允許。
疊層使用高於普通浮動視窗的位階，並加入其他 App 的全螢幕空間；多顯示器與特殊全螢幕仍需實機確認。系統安全畫面、受保護影片或特殊獨佔全螢幕可能不顯示。螢幕分享請選整個顯示器：只分享單一 App 視窗時，外部透明疊層未必包含在分享內容中。

19儲存、暫存與匯出

保留原作，才有下一次編輯。

文件交換：首頁匯入支援PDF與PPT／PPTX／Keynote簡報。Mac簡報由已安裝Keynote轉臨時副本為PDF，需系統自動化授權；原始／已開簡報不更動，也可先自行轉PDF。可選頁碼，每次200頁／圖片100MB，取消不安裝半份作品。外部文件是鎖定圖片頁，原文字元素與動畫影片不保留。黑板自己的PDF可恢復完整原稿。PDF匯出筆記本可選目前／全部頁面，並以有效PDF增量資料流附完整原稿（包括其他頁及隱藏物件）；只分享可見內容請用PNG。正常退出會顯示保存進度。

檔案用途重新編輯

.blackboard.json / .json舊版相容文件仍可從開啟專案讀入
PNG合成圖片可置入註記，但原物件會合成

⌘S 或更多 → 另存黑板專案，預設產生 .heiban。Finder 雙擊 .heiban 可交由黑板開啟。開啟外部作品會載入本機工作階段；後續自動儲存寫本機作品庫，不會持續覆寫原外部檔，需要更新外部檔請再次另存。

.heiban 第一版是有版本欄位的 UTF-8 JSON，圖片內嵌，檔案單獨攜帶即可。它不是把螢幕拍成一張圖片，也不依賴 Swift 私有序列化，為未來跨平台讀取保留空間。

本機資料位於 ~/Library/Application Support/HeiBan/：作品在 Boards，最近工作在 current.blackboard.json，備份在 Backups；螢幕註記另外放在 ScreenAnnotations/display-顯示器ID.heiban。一般作品暫存沿用既有名稱，避免破壞舊資料。

關閉自動保存後，修改作品仍會顯示「尚未儲存」；文字清空、板擦及尚未完成的繪圖也不會被誤報為已儲存。返回首頁或正常退出前會先完成正在編輯的文字及板擦交易；保存失敗會保留畫布供重試。自動保存依「帳號與設定 → 存檔與安全」的開關與頻率排程；普通作品與螢幕註記使用同一偏好。寫檔使用原子替換。重要作品仍請另存並備份；不要只依賴最近工作檔。註記暫存無法解析時會保留原檔，不用空白內容覆蓋。

20快捷鍵速查

輸入文字時，文字編輯優先。

在畫布按 ⌘V，可貼上系統剪貼簿裡的截圖、PNG／TIFF 影像或複製的本機圖片檔案。瀏覽器只提供圖片網址時會嘗試下載影像；需登入或不允許下載的來源可能無法取得。輸入文字時 ⌘V 優先貼進文字編輯器；先完成文字，再貼到畫布。

單獨選取直線或箭頭，只顯示 A、B 兩個端點。拖曳端點調整線段位置與方向，屬性不顯示旋轉；其他圖形保留包圍框及旋轉點。快速調整列預留旋轉控制空間，上方不足時移到下方。

繪圖工具列停靠上方時，右上導覽收合後上移；導覽展開時下移讓出空間。螢幕畫布展開時，清空由共用常用工具或更多提供，退出固定留在尾端；收合時仍保留清空與退出，避免同一列重複兩個垃圾桶。純圖示模式在空間不足時可捲動。

21帳號、限制與後續功能

清楚區分目前可使用的工具。

一般設定 → 介面語言可切換正體／簡體中文、英語、日語、韓語、西班牙語、法語、德語、巴西葡語與阿拉伯語。切換不會翻譯作品內容或改變文件；部分動態提示與樣式名稱尚未完整翻譯；離線手冊隨介面語言開啟，正體中文21章圖解、其餘語言13主題總覽。頁內切換手冊語言不改App偏好。

關於黑板 → GitHub 更新可手動檢查，也可開啟啟動時檢查及包含預覽版。只比對相容 Mac 套件，Windows 發行版不會被當成 Mac 更新。本機開發版高於公開版時保持本機版；安裝由官方發行頁手動下載，不在背景替換 App。

帳號與設定位於首頁側欄。目前 Google 登入介面標示「準備中」，並不等同已實現 Google 雲端同步；作品以本機儲存為主。

這份手冊涵蓋目前 macOS 介面可操作的主要功能。核心另有心智圖、表格、公式、框架簡報等程式基礎，但尚未完成一致的可用入口，不能視為已交付工具。

外部PDF圖片頁與註記、HeiBan PDF原稿恢復及多頁匯出已接線；入口可讀.heiban／JSON／PDF及簡報。SVG向量匯入編輯尚未交付；全部往返相容仍需實際文件驗收，請保留原稿。

雷射屬於暫時效果，復原歷史只在當次工作階段存在。巨幅內嵌圖片會增加 .heiban 大小；未來資產封裝版本會走明確格式升級，不只改副檔名。
